## 📍 阶段定位

**战略专业选修阶段**是 ACCA 战略专业的最后 2 科，从 4 门中任选 2 门，根据职业方向深化专业技能。

| 科目 | 难度 | 建议时长 | 适用人群 |
|------|------|----------|----------|
| **AFM** | ⭐⭐⭐⭐⭐ | 150-180 小时 | 跨国公司财务、投行、并购 |
| **APM** | ⭐⭐⭐⭐ | 140-170 小时 | 管理咨询、企业战略规划 |
| **ATX** | ⭐⭐⭐⭐ | 140-170 小时 | 税务顾问、四大税务组 |
| **AAA** | ⭐⭐⭐⭐⭐ | 150-180 小时 | 高级审计、事务所合伙人方向 |

> **主流选择**：AFM + AAA（与 SBR 衔接紧密，应用面广）

## 📝 内容大纲（待补充）

### AFM (Advanced Financial Management)
- [ ] 跨国公司财务管理
- [ ] 高级投资评估（实物期权）
- [ ] 公司重组与并购
- [ ] 外汇风险与利率风险管理
- [ ] 衍生品与套期会计
- [ ] 国库管理与营运资本

### APM (Advanced Performance Management)
- [ ] 战略规划与业绩管理框架
- [ ] 高级业绩度量（EVA、BSC）
- [ ] 变革管理与组织绩效
- [ ] 高级预算技术（零基、作业基础）
- [ ] 质量管理与持续改进
- [ ] 信息技术在业绩管理中的应用

### ATX (Advanced Taxation)
- [ ] 个人税务规划
- [ ] 公司税务规划
- [ ] 资本利得与遗产税
- [ ] 跨境税务
- [ ] 增值税高级应用
- [ ] 税务合规与申报

### AAA (Advanced Audit and Assurance)
- [ ] 高级审计程序与风险评估
- [ ] 复杂集团审计
- [ ] 审计中的信息技术应用
- [ ] 鉴证业务（环境、可持续报告）
- [ ] 审计完成与高级报告
- [ ] 监管与职业道德
