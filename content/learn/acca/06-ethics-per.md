## 📍 本章定位

通过全部 13 科考试只是 ACCA 持证的一部分。要成为 ACCA 正式会员，还必须完成：

1. **EPSM（Ethics and Professional Skills Module）**：职业道德与专业技能模块
2. **PER（Practical Experience Requirement）**：36 个月相关工作经验

## 📝 EPSM 模块（待补充）

| 项目 | 信息 |
|------|------|
| **形式** | 在线学习与评估 |
| **时长** | 约 20 小时 |
| **费用** | 一次性约 £75 |
| **完成要求** | 通过全部 7 个单元的评估 |
| **完成时间** | 建议在战略专业阶段前完成 |

### EPSM 七个单元
- [ ] 单元 1：伦理与职业道德
- [ ] 单元 2：个人效能
- [ ] 单元 3：创新与怀疑思维
- [ ] 单元 4：商业意识、领导力与战略思维
- [ ] 单元 5：沟通与商业数据
- [ ] 单元 6：评估与finale模拟
- [ ] 单元 7：综合案例评估

---

## 📝 PER 实践经验（待补充）

| 项目 | 信息 |
|------|------|
| **总时长** | 36 个月（3 年） |
| **可累计时间** | 在 ACCA 注册后开始的工作经验 |
| **工作类型** | 会计、审计、税务、财务管理等相关岗位 |
| **督导要求** | 由 ACCA 会员作为 supervisor 督导与签字 |
| **能力要求** | 9 大Performance Objectives（5 必选 + 4 选项） |

### 9 大 Performance Objectives

**5 个必选（Essential）**：
- [ ] PO1：职业操守与道德
- [ ] PO2：个人效能
- [ ] PO3：创新与怀疑思维
- [ ] PO4：商业意识
- [ ] PO5：领导力与战略思维

**4 个可选（Options，需选 4 个）**：
- [ ] PO6：财务管理
- [ ] PO7：财务报告
- [ ] PO8：审计与鉴证
- [ ] PO9：税务
- [ ] PO10：管理会计
- [ ] PO11：商业风险与控制
