# 🌍 ACCA · 特许公认会计师

> **ACCA（Association of Chartered Certified Accountants，特许公认会计师公会）** 是全球最大的国际性专业会计师组织之一，总部位于英国伦敦。ACCA 资质在全球 180+ 国家获得认可，是进入跨国公司、四大、外企财务岗的"国际通行证"。

## 🎯 路径概览

| 阶段 | 科目数 | 内容 |
|------|--------|------|
| **应用知识阶段** | 3 科 | BT、MA、FA（基础会计） |
| **应用技能阶段** | 6 科 | LW、PM、TX、FR、AA、FM（核心技能） |
| **战略专业核心** | 2 科 | SBL、SBR（战略思维） |
| **战略专业选修** | 2 科（4 选 2） | AFM、APM、ATX、AAA |
| **职业道德与专业技能模块** | 1 模块 | EPSM（在线完成） |
| **实践经验要求** | 36 个月 | PER（在职累计） |

- **总科目数**：13 科
- **考试语言**：全英文
- **成绩有效期**：专业阶段（SBL/SBR + 选修）**7 年**滚动有效；应用知识/技能阶段无年限限制
- **考试频次**：每年 4 个考季（3/6/9/12 月）
