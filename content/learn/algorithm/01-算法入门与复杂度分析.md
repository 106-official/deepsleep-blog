## 先建立直觉

算法就是 **「解决某类问题的明确步骤」**。同样一个问题（比如「在一堆数里找最大的」），不同写法效率天差地别。

- 傻办法：从头到尾一个个比（看 n 次）；
- 更傻：每两个数都比一遍（比 n² 次）。

我们关心的不是「在你的电脑上跑 0.3 秒还是 0.5 秒」，而是 **「数据量翻 10 倍，时间翻几倍」**——这叫**渐近复杂度**，用大 O 表示。

> 复杂度衡量的是「规模增长时，开销怎么涨」。O(n) 表示数据量 ×10，时间也约 ×10；O(n²) 表示 ×10 时间 ×100。写代码前先想清楚这个，比事后优化重要一万倍。

## 它解决什么问题

1. **选对数据结构/算法**：同样是「查找」，数组顺序找 O(n)，哈希表 O(1)，二叉搜索树 O(log n)；
2. **预估能不能过**：竞赛/面试常卡时间限制，O(n²) 在 n=10⁵ 时必超时；
3. **沟通效率**：说「这题我用了 O(n log n) 的排序 + 一次扫描」比「我用了快排然后遍历」更精准。

```mermaid

    A[问题] --> B{数据规模?}
    B -->|小规模| C[简单 O(n²) 也行]
    B -->|大规模 n=10^5| D[必须 O(n) / O(n log n)]
```

## 核心概念

### 1. 大 O 是什么

大 O 表示**最坏情况下、随输入规模 n 增长的「主导项」**，省去常数和低阶项：

- `O(2n + 5)` → `O(n)`（常数 2 和 +5 都忽略）；
- `O(3n² + 100n)` → `O(n²)`（主导项是 n²）；
- `O(n² + n log n)` → `O(n²)`。

> 口诀：**只留最高次项，系数全扔。** 因为 n 很大时，低阶项和常数根本无所谓。

### 2. 常见量级（从快到慢）

| 复杂度 | 名称 | n=10 | n=1000 | 直觉 |
|--------|------|------|--------|------|
| O(1) | 常数 | 1 | 1 | 不管多大都一步 |
| O(log n) | 对数 | ~3 | ~10 | 每步砍半（二分） |
| O(n) | 线性 | 10 | 1000 | 遍历一遍 |
| O(n log n) | 线性对数 | ~33 | ~10000 | 高效排序 |
| O(n²) | 平方 | 100 | 10⁶ | 双重循环 |
| O(2ⁿ) | 指数 | 1024 | 天文 | 暴力枚举子集 |

### 3. 怎么算时间复杂度

**规则 1：循环看层数**
```python
for i in range(n):        # O(n)
    for j in range(n):    # O(n)
        work()            # 总 O(n²)
```

**规则 2：看循环怎么走**
```python
i = 1
while i < n:
    i *= 2                # 每步翻倍，直到 >= n → 约 log₂n 次 → O(log n)
```

**规则 3：递归看树**
```python
def f(n):
    if n <= 1: return
    f(n//2); f(n//2)      # 每层 2 个分支，深度 log n → 共 O(n) 次（这里实际是满二叉树 2^log n）
```
> 递归复杂度 = 「递归树节点总数」×「单次工作量」。分治（如归并）常是 O(n log n)。

### 4. 空间复杂度

除了时间，还要算**额外用了多少内存**：
```python
def sum_arr(a):
    s = 0                 # O(1) 额外空间
    for x in a: s += x
    return s
# 只用了变量 s → 空间 O(1)

def bad(a):
    b = a[:]              # 复制了整个数组 → O(n) 空间
```
> 递归的「调用栈深度」也算空间。深度为 d 的递归，空间至少 O(d)。

## 常见坑

1. **只看常数不看量级**：觉得「我加个缓存就快了」——缓存是 O(1) 查找没错，但若本来就是 O(n) 遍历不改主项，复杂度不变。
2. **`range(n)` 里改步长误判**：`for i in range(0, n, 2)` 仍约 n/2 次 → O(n)，不是 O(log n)。
3. **忽略隐藏的 O(n)**：Python 里 `sorted()` 是 O(n log n)，`list.index(x)` 是 O(n)，别以为「一行」就免费。
4. **空间算漏递归栈**：写递归别忘了栈深度也吃内存，深度 n 的递归空间 O(n)。

## 小结

- 算法 = 解决问题的步骤；复杂度看「规模增长时开销怎么涨」；
- 大 O 只留最高次项、丢常数与低阶；
- 量级排序：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)；
- 时间看循环层数与递归树，空间算额外内存 + 递归栈；
