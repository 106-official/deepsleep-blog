## 先建立直觉

数组（Array）是**一块连续内存，按下标直接取**——因此「第 i 个」是 O(1)。字符串本质就是「字符的数组」，很多套路两者通用。

这一章的三把利器：
- **双指针**：用两个下标在数组上「相向而行」或「一快一慢」，把 O(n²) 降成 O(n)；
- **滑动窗口**：维护一段「满足条件的连续区间」，窗口左右边界滑动；
- **前缀和**：预先算好「前 i 个的累加」，之后任意区间和 O(1) 得到。

> 双指针像两个人从两端往中间走找答案；滑动窗口像用两根筷子夹住一截香肠，不断调整长度。

## 它解决什么问题

1. **有序数组去重/求和**：双指针避免暴力两重循环；
2. **子数组最大/满足条件的区间**：滑动窗口；
3. **区间求和多次询问**：前缀和；
4. **字符串反转/回文/异位词**：同样靠双指针与计数。

```mermaid

    A[原数组] --> B[双指针: 左右夹逼]
    A --> C[滑动窗口: 维护区间]
```

## 核心概念

### 1. 双指针（对撞）

**例题：两数之和（有序数组）** 找两个数加起来等于 target。

```python
def two_sum(nums, target):
    l, r = 0, len(nums) - 1
    while l < r:
        s = nums[l] + nums[r]
        if s == target: return [l, r]
        elif s < target: l += 1   # 太小，左指针右移增大
        else: r -= 1              # 太大，右指针左移减小
    return []
# 时间 O(n)，空间 O(1)
```

> 前提是有序。无序先排序（O(n log n)）再双指针。无序且要求下标时改用哈希表（见第 4 章）。

### 2. 快慢指针（原地修改）

**例题：移除数组中的某值（原地，O(1) 空间）**

```python
def remove_val(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:
            nums[slow] = nums[fast]   # 慢指针只收集「保留的」
            slow += 1
    return slow                       # 新长度
```

> 快指针探路，慢指针「写」结果。这是很多「原地」题的通用模板。

### 3. 滑动窗口

**例题：最长无重复字符子串**

```python
def length_of_longest(s):
    seen = set()
    l = 0
    ans = 0
    for r in range(len(s)):
        while s[r] in seen:        # 右扩导致重复 → 左缩
            seen.remove(s[l])
            l += 1
        seen.add(s[r])
        ans = max(ans, r - l + 1)  # 当前窗口长度
    return ans
# 时间 O(n)：每个字符进出窗口各一次
```

> 窗口单调性：右边界一直右扩，左边界只在「不合法」时右缩（不会回退），所以整体 O(n)。

### 4. 前缀和

**例题：多次询问区间和**

```python
def build_prefix(nums):
    pre = [0] * (len(nums) + 1)
    for i, x in enumerate(nums):
        pre[i + 1] = pre[i] + x
    return pre

def range_sum(pre, l, r):
    return pre[r + 1] - pre[l]     # [l, r] 的和
# 建 O(n)，每次查询 O(1)
```

### 5. 字符串技巧

| 技巧 | 说明 |
|------|------|
| 反转比对 | 回文：`s == s[::-1]`（Python）或双指针 |
| 计数比对 | 异位词：两串字符计数是否相等（用数组/Counter） |
| 转字符数组 | C++ 字符串不可变，修改先转 `vector<char>` |
| 双指针原地 | 反转、去空格（类似数组） |

```python
from collections import Counter
def is_anagram(a, b):
    return Counter(a) == Counter(b)   # O(n)
```

## 常见坑

1. **边界 l < r 写成 l <= r**：对撞题若允许相等会重复/越界，想清楚是否包含。
2. **滑动窗口左缩条件写反**：应是「不合法时缩」，不是「合法时缩」，否则窗口一直不动。
3. **前缀和索引错位**：`pre[i+1] = pre[i] + nums[i]`，查询用 `pre[r+1]-pre[l]`，差一错误很常见。
4. **C++ 字符串当数组改**：`s[i] = 'a'` 可行但 `s +=` 在循环里是 O(n²)；大量拼接用 `stringstream` 或 `vector<char>`。
5. **忘记数组越界**：Python 切片友好，C++ 必须保证 `0 <= idx < n`。

## 小结

- 数组随机访问 O(1)；字符串≈字符数组，套路通用；
- 双指针（对撞/快慢）把 O(n²) 降 O(n)；滑动窗口维护合法区间；
- 前缀和让区间查询 O(1)；字符串靠反转/计数/原地双指针；
