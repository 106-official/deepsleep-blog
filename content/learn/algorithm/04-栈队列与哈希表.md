## 先建立直觉

这三种是最常用的「辅助结构」，单独考得少，但**几乎每道中难题都靠它们打辅助**：

- **栈（Stack）**：后进先出，像一摞盘子——只能从顶上放/取。适合「撤销」「嵌套匹配」「回溯」。
- **队列（Queue）**：先进先出，像排队。适合「按层遍历」（BFS）、「任务调度」。
- **哈希表（Hash Map）**：键值映射，O(1) 查找。适合「计数」「去重」「快速定位」。

> 栈管「最近」，队列管「顺序」，哈希管「直查」。把它们当工具箱，遇到新题先想「这题能用哪个？」。

## 它解决什么问题

1. **括号/嵌套匹配**：栈天然记录「待闭合的最近开口」；
2. **下一个更大元素**：单调栈；
3. **层序遍历/最短路径**：队列 BFS；
4. **两数之和/频率统计**：哈希表。

## 核心概念

### 1. 栈：括号匹配

```python
def is_valid(s):
    st = []
    pair = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            st.append(ch)
        elif not st or st.pop() != pair[ch]:   # 栈空或顶不匹配
            return False
    return not st                               # 最后必须空
```

> 核心：**遇到左括号压栈，遇到右括号看栈顶是否配对**。结束时栈必须空（无遗留左括号）。

### 2. 单调栈：下一个更大元素

维护一个**栈底到栈顶递减**的栈，遍历时遇到更大的就「结算」栈里比它小的：

```python
def next_greater(nums):
    st, ans = [], ans := [-1] * len(nums)
    for i, x in enumerate(nums):
        while st and nums[st[-1]] < x:      # 当前 x 是栈顶的「下一个更大」
            ans[st.pop()] = x
        st.append(i)
    return ans
# 每个元素进出栈一次 → O(n)
```

> 单调栈模板：遍历元素，while 栈不空且「破坏单调性」就弹栈结算，再把当前入栈。求「左侧/右侧第一个更大/更小」都套这个。

### 3. 队列：BFS 层序遍历

```python
from collections import deque

def bfs(start, neighbors):
    q = deque([start])
    seen = {start}
    while q:
        u = q.popleft()              # 队首出
        for v in neighbors(u):
            if v not in seen:
                seen.add(v)
                q.append(v)          # 邻居入队
```

> BFS 用 `deque`（双端队列），`popleft` O(1)。List 当队列 `pop(0)` 是 O(n)，别用。

### 4. 哈希表：O(1) 查找/计数

```python
# 两数之和：边走边记「目标差在哪」
def two_sum(nums, target):
    pos = {}
    for i, x in enumerate(nums):
        if target - x in pos:        # O(1) 查补数
            return [pos[target - x], i]
        pos[x] = i
    return []

# 频率统计
from collections import Counter
freq = Counter("abracadabra")        # {'a':5, 'b':2, 'r':2, 'c':1, 'd':1}
top = freq.most_common(2)            # [('a',5), ('b',2)]
```

> 哈希表把「找某个值在哪」从 O(n) 降到 O(1)，是优化双重循环的利器。

## 常见坑

1. **用 list 当队列**：`pop(0)` O(n) 会超时，用 `collections.deque`。
2. **栈空时 pop**：先 `if st:` 再弹，否则 IndexError（Python）/ 未定义（C++）。
3. **哈希表边遍历边删**：`for k in d: del d[k]` 会报错/漏项；用 `d.pop(k)` 单删或建新表。
4. **单调栈方向搞反**：求「更大」用递减栈，「更小」用递增栈，写反就全错。
5. **BFS 忘标记 visited**：会重复入队死循环，入队同时标记（或在出队时标，但入队标更稳）。

## 小结

- 栈 LIFO：括号匹配、回溯、单调栈（下一个更大/更小元素）；
- 队列 FIFO：BFS 层序/最短路径，用 `deque` 别用 list；
- 哈希表 O(1)：两数之和、计数、去重、快速定位；
- 三者常作辅助：配合数组/树/图使用；
