## 先建立直觉

**排序**是把一堆数按升/降序排好；**二分查找**是在「已排好序」的序列里用「每次砍一半」极快地定位。

> 二分查找是「最值性价比」的算法：O(log n) 在百万数据中只查约 20 次。但它**前提是有序**——所以排序常常是二分的铺垫。两者经常捆绑出现：「先排序，再二分」。

## 它解决什么问题

1. **有序才能高效查找**：二分把 O(n) 查找降到 O(log n)；
2. **分治排序**：快排/归并把 O(n²) 暴力排序降到 O(n log n)；
3. **边界类问题**：「第一个 ≥ x 的位置」「最后一个 ≤ x」用二分模板。

## 核心概念

### 1. 快速排序（分治 + 基准）

选一个基准（pivot），把小的放左、大的放右，再递归排两边：

```python
def quicksort(a, lo, hi):
    if lo >= hi: return
    pivot = a[hi]
    i = lo
    for j in range(lo, hi):
        if a[j] < pivot:
            a[i], a[j] = a[j], a[i]; i += 1
    a[i], a[hi] = a[hi], a[i]          # pivot 归位
    quicksort(a, lo, i - 1)
    quicksort(a, i + 1, hi)
```

> 平均 O(n log n)，最坏（已有序且取末位为 pivot）O(n²)。工程实现随机选 pivot 或三数取中来规避。

### 2. 归并排序（稳定，分治合并）

先分到底，再「合并两个有序段」：

```python
def mergesort(a):
    if len(a) <= 1: return a
    mid = len(a) // 2
    L, R = mergesort(a[:mid]), mergesort(a[mid:])
    res, i, j = [], 0, 0
    while i < len(L) and j < len(R):
        if L[i] <= R[j]: res.append(L[i]); i += 1
        else: res.append(R[j]); j += 1
    return res + L[i:] + R[j:]
```

> 归并**稳定**（相等不交换），且最坏也是 O(n log n)，代价是需要 O(n) 额外空间。求「逆序对」也用它。

### 3. 排序对比

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 特点 |
|------|------|------|------|------|------|
| 快排 | O(n log n) | O(n²) | O(log n) | 否 | 快、原地 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 | 稳定、耗空间 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 | 原地但不稳定 |
| 计数/桶 | O(n+k) | O(n+k) | O(k) | 是 | 整数/范围小专用 |

### 4. 二分查找模板（找等于）

```python
def binary_search(a, x):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == x: return mid
        elif a[mid] < x: lo = mid + 1
        else: hi = mid - 1
    return -1
```

### 5. 二分找边界（左闭右开模板更稳）

**第一个 ≥ x 的位置**：

```python
def lower_bound(a, x):
    lo, hi = 0, len(a)                  # [lo, hi) 左闭右开
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x: lo = mid + 1
        else: hi = mid
    return lo                            # 返回插入位置
```

> 左闭右开 `[lo, hi)` 模板避免 `mid±1` 的边界纠结：小了就 `lo=mid+1`，否则 `hi=mid`。`lower_bound` 既是「第一个≥x」，也是「x 的插入点」。

## 常见坑

1. **二分 mid 写 `(lo+hi)//2` 大数溢出**：Python 无此问题；C++ 用 `lo + (hi-lo)/2`。
2. **循环条件 `lo<=hi` vs `lo<hi` 混用**：找「等于」用 `<=`（闭区间），找「边界」用 `<`（左闭右开），别乱套。
3. **快排 pivot 取末位且数组已序**：退化 O(n²)，工程要随机化。
4. **忘了排序就二分**：二分前提是单调有序，乱序数组二分结果无意义。
5. **lower_bound 返回 len(a)**：说明所有元素都 < x，调用方要判越界。

## 小结

- 排序：快排（快/原地/不稳）、归并（稳/耗空间/最坏仍 nlogn）；
- 二分前提是有序；找等于用闭区间 `<=`，找边界用左闭右开 `<`；
- `lower_bound` 给「第一个≥x」即插入点；
