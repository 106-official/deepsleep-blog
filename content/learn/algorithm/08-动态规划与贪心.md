## 先建立直觉

**动态规划（DP）** 和 **贪心（Greedy）** 都是解决「在一系列选择里找最优解」的算法。区别在于：

- **贪心**：每一步都选「当前看起来最好」的，指望局部最优累成全局最优。简单但**只对特定问题成立**；
- **DP**：把问题拆成「重叠子问题」，把每个子问题的最优解**记下来（查表）**，避免重复算。通用但要想清楚状态。

> 类比爬楼梯：贪心是「每步都跨最大能跨的」；DP 是「先算到第 1 级、第 2 级……每一级的最优步数都存好，第 n 级 = min(从第 n-1 级来, 从第 n-2 级来) + 1」。

## 它解决什么问题

1. **最优化**：最大和、最长、最少步数、可行性；
2. **有重叠子问题**：直接递归会指数爆炸，DP 用记忆化降到多项式；
3. **贪心可证最优的场景**：区间调度、最小生成树、哈夫曼编码。

## 核心概念

### 1. DP 三要素

写 DP 先想清三件事：
1. **状态（dp 数组代表什么）**：`dp[i]` 通常表「前 i 个 / 到第 i 个时的最优值」；
2. **转移方程（怎么从子问题来）**：`dp[i] = f(dp[i-1], dp[i-2], ...)`；
3. **基线（最小子问题的值）**：`dp[0] = ?`。

### 2. 经典：爬楼梯 / 打家劫舍

**爬楼梯**：一次 1 或 2 阶，到第 n 阶几种走法。

```python
def climb(n):
    if n <= 2: return n
    a, b = 1, 2
    for _ in range(3, n + 1):
        a, b = b, a + b      # dp[i] = dp[i-1] + dp[i-2]
    return b
```

**打家劫舍**（不能偷相邻）：`dp[i] = max(偷i: dp[i-2]+nums[i], 不偷i: dp[i-1])`

```python
def rob(nums):
    prev, cur = 0, 0
    for x in nums:
        prev, cur = cur, max(cur, prev + x)
    return cur
```

### 3. 经典：0/1 背包

n 件物品，每件重量 w、价值 v，背包容量 W，求最大价值（每件最多取一次）。

```python
def knapsack(W, weights, values):
    dp = [0] * (W + 1)
    for w, v in zip(weights, values):
        for cap in range(W, w - 1, -1):   # 倒序！避免同件重复取
            dp[cap] = max(dp[cap], dp[cap - w] + v)
    return dp[W]
# 时间 O(n·W)，空间 O(W)
```

> **倒序遍历容量**是关键：保证更新 `dp[cap]` 时用的 `dp[cap-w]` 还是「上一轮（没放当前物品）」的值，即每件只放一次。正序会变成完全背包（可重复取）。

### 4. 经典：最长递增子序列 LIS

```python
def lis(nums):
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
# O(n²)；O(n log n) 版用二分维护尾元素
```

### 5. 贪心：区间调度

「最多不重叠区间数」——每次选**结束最早**的区间：

```python
def max_intervals(intervals):
    intervals.sort(key=lambda x: x[1])   # 按结束时间排序
    cnt, end = 0, float('-inf')
    for s, e in intervals:
        if s >= end:                     # 不重叠就选
            cnt += 1; end = e
    return cnt
```

> 贪心得先「证明」：选结束最早的，留给后面最多空位，必是最优。不能证明就别用贪心，改用 DP。

## 常见坑

1. **DP 容量遍历方向错**：0/1 背包必须**倒序**，完全背包才正序，写反语义全变。
2. **状态定义模糊**：`dp[i]` 到底含不含第 i 个？定义不清导致转移错。先写清「dp[i] = 前 i 个的最优」。
3. **忘了基线**：`dp[0]` 该是 0 还是 1？基线错整个表错。
4. **贪心没证明就上**：很多题局部最优 ≠ 全局最优（如部分背包能贪心、0/1 背包不能），错用贪心得错误解。
5. **空间可压缩却开了二维**：很多 DP 只用上一行，可压成一维/两个变量，省内存且更快。

## 小结

- DP 三要素：状态定义、转移方程、基线；用记忆化/打表避免重复算；
- 背包倒序容量（每件一次），完全背包正序（可重复）；
- LIS、区间调度等是高频模型；
- 贪心只对「能证明局部最优→全局最优」的问题成立，否则用 DP；
