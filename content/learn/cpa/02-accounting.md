## 📍 本章定位

**会计**是 CPA 专业阶段六科中**内容最多、难度最大、联系最广**的科目，是审计、税法、财管的基础。被普遍认为是 CPA 备考的"第一关"。

| 项目 | 信息 |
|------|------|
| **难度** | ⭐⭐⭐⭐⭐ |
| **建议备考时长** | 350-450 小时 |
| **通过率** | 约 15-20% |
| **核心模块** | 会计准则、长期股权投资、合并报表、收入、金融工具、所得税 |

## 📝 内容大纲（待补充）

- [ ] 会计基本准则与假设
- [ ] 资产类科目（存货、固定资产、无形资产、投资性房地产）
- [ ] 负债与所有者权益
- [ ] 收入、费用与利润
- [ ] 长期股权投资与企业合并
- [ ] 合并财务报表
- [ ] 金融工具
- [ ] 所得税会计
- [ ] 租赁、债务重组、非货币性资产交换
