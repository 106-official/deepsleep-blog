## 📝 考情分析

本章是审计学科的入门章节，阐述审计的基本概念、要素、目标、要求、风险和过程，为后续章节奠定理论基础。分值稳定在 2-3 分，多以选择题形式命题。**认定类别和审计风险模型是高频考点**。

**命题规律：**

1. **审计概念与保证程度**：常考合理保证与有限保证的区别（保证水平、证据数量、检查风险、结论表达方式），注意审计只能提供合理保证，不能提供绝对保证。
2. **审计要素**：三方关系人（注册会计师、管理层、预期使用者）的识别是常考点，注意管理层可能是预期使用者之一，但不是唯一预期使用者。
3. **认定类别**：高频考点，区分各类交易和事项的认定（发生、完整性、准确性、截止、分类、列报）与期末账户余额的认定（存在、权利和义务、完整性、准确性计价和分摊、分类、列报）。
4. **审计风险模型**：审计风险=重大错报风险×检查风险，重大错报风险=固有风险×控制风险，检查风险与重大错报风险呈反向关系。
5. **审计基本要求**：职业怀疑的四方面理解、职业判断的五步骤。
6. **审计过程**：五个阶段（接受业务委托、计划审计工作、识别和评估重大错报风险、应对重大错报风险、编制审计报告）。

**备考策略：** 重点掌握认定的分类（交易类 vs 账户余额类）及其与具体审计目标的对应关系、审计风险模型的计算与反向关系、合理保证与有限保证的对比。本章概念较多，建议通过表格对比和口诀记忆。

## 📖 核心精讲

### 一、审计的概念与保证程度

#### （一）审计的产生和发展

注册会计师制度源于企业**所有权和经营权的分离**。所有者不再直接参与企业日常经营管理，产生了经营者定期通过财务报表向所有者报告财务状况和经营成果的需要。由于财务报表由管理层编制，其自身利益通常与企业的财务状况和经营成果挂钩，需要由独立的第三方——注册会计师对财务报表进行审计。

#### （二）财务报表审计的概念

财务报表审计是指注册会计师对财务报表是否不存在重大错报提供**合理保证**，以**积极方式**提出意见，增强除管理层之外的预期使用者对财务报表信赖的程度。

从以下五个方面理解：

| 要点 | 内容 |
|------|------|
| **审计的用户** | 财务报表的预期使用者 |
| **审计的目的** | 改善财务报表质量，增强除管理层之外的预期使用者对财务报表的信赖程度（不涉及为如何利用信息提供建议） |
| **保证程度** | 合理保证（高水平保证），由于审计存在固有限制，不能提供绝对保证 |
| **审计的基础** | 注册会计师的独立性和专业性 |
| **审计的最终产品** | 审计报告 |

#### （三）保证程度

注册会计师执行的业务分为**鉴证业务**和**相关服务**两类。鉴证业务包括审计、审阅和其他鉴证业务；相关服务包括代编财务信息、对财务信息实施商定程序、税务咨询和管理咨询等。

| 对比项 | 合理保证（审计） | 有限保证（审阅） |
|--------|------------------|------------------|
| **目标** | 在可接受的低审计风险下，以积极方式对财务报表整体发表审计意见，提供高水平保证 | 在可接受的审阅风险下，以消极方式对财务报表整体发表审阅意见，提供低于高水平的保证 |
| **证据收集程序** | 系统化执业过程，证据收集程序包括检查记录或文件、检查有形资产、观察、询问、函证、重新计算、重新执行、分析程序等 | 系统化执业过程，证据收集程序受到有意地限制，主要采用询问和分析程序获取证据 |
| **所需证据数量** | 较多 | 较少 |
| **检查风险** | 较低 | 较高 |
| **财务报表的可信性** | 较高 | 较低 |
| **提出结论的方式** | 积极方式（"我们认为，财务报表在所有重大方面按照企业会计准则的规定编制，公允反映了……"） | 消极方式（"根据我们的审阅，我们没有注意到任何事项使我们相信，财务报表没有按照企业会计准则的规定编制……"） |

#### （四）注册会计师审计、政府审计和内部审计

**1. 注册会计师审计与政府审计的区别**

| 区别项 | 注册会计师审计 | 政府审计 |
|--------|----------------|----------|
| **审计目的和对象** | 对财务报表或内部控制发表审计意见 | 监督财政收支或财务收支的真实、合法、效益 |
| **审计依据** | 《注册会计师法》和注册会计师审计准则 | 《审计法》和国家审计准则 |
| **经费或收入来源** | 市场行为，有偿服务，费用由双方协商确定 | 行政行为，经费列入同级财政预算 |
| **取证权限** | 依赖企业及相关单位配合，没有行政强制力 | 具有更大的强制力，有关单位和个人应当支持、协助 |
| **对发现问题的处理方式** | 出具非无保留意见的审计报告、必要时解除业务约定或向监管机构报告 | 可在职权范围内作出审计决定或向有关主管机关提出处理、处罚意见 |

**2. 注册会计师审计与内部审计的区别**

| 区别项 | 注册会计师审计 | 内部审计 |
|--------|----------------|----------|
| **审计独立性** | 独立于被审计单位的第三方，较强独立性 | 受所在单位直接领导，独立性受限 |
| **审计方式** | 接受委托进行 | 单位根据自身经营管理需要安排 |
| **审计程序** | 严格按照执业准则的规定程序进行 | 根据业务目的和需要选择并实施必要的程序 |
| **审计职责** | 对被审计单位负责，且对社会负责 | 只对本单位负责 |
| **审计作用** | 起鉴证作用，阅读对象不限于被审计单位 | 仅作本单位改善工作的参考，对外不起鉴证作用 |

### 二、审计要素

审计业务要素包括审计业务的三方关系人、财务报表、财务报告编制基础、审计证据和审计报告。

#### （一）审计业务的三方关系人

三方关系人分别是**注册会计师**、**被审计单位管理层（责任方）**和**财务报表预期使用者**。

> **重点**：是否存在三方关系是判断某项业务是否属于审计业务的重要标准之一。管理层可能成为预期使用者之一，但不是唯一的预期使用者。

**1. 注册会计师**：取得注册会计师证书并在会计师事务所执业的人员。对财务报表发表审计意见是注册会计师的责任，通过签署审计报告确认其责任。

**2. 被审计单位管理层**：对被审计单位经营活动的执行负有经营管理责任的人员，对财务报表编制负责。

**执行审计工作的前提**：管理层和治理层（如适用）认可并理解其应当承担下列责任：
- 按照适用的财务报告编制基础编制财务报表，并使其实现公允反映（如适用）；
- 设计、执行和维护必要的内部控制，以使财务报表不存在舞弊或错误导致的重大错报；
- 向注册会计师提供必要的工作条件。

> **重点**：财务报表审计并不能减轻管理层或治理层的责任。如果财务报表存在重大错报，而注册会计师通过审计没有能够发现，也不能因为财务报表已经被注册会计师审计这一事实而减轻管理层和治理层对财务报表的责任。

**3. 预期使用者**：预期使用审计报告和财务报表的组织或人员。一般情况下，注册会计师可能无法识别预期使用审计报告的所有组织和人员，此时预期使用者主要是指那些与财务报表有重要和共同利益的主要利益相关者（如上市公司财务报表审计中的股东）。

#### （二）财务报表

财务报表是指依据某一财务报告编制基础对被审计单位历史财务信息作出的结构性表述。整套财务报表通常包括资产负债表、利润表、现金流量表、所有者权益（或股东权益）变动表和相关附注。

#### （三）财务报告编制基础

分为**通用目的编制基础**（如企业会计准则）和**特殊目的编制基础**（如计税核算基础、监管机构的报告要求和合同的约定等）。

#### （四）审计证据

审计证据的充分性和适当性相互关联：

- **充分性**：对审计证据数量的衡量。评估的重大错报风险越高，需要的审计证据可能越多；审计证据质量越高，需要的审计证据可能越少。
- **适当性**：对审计证据质量的衡量，包括**相关性**和**可靠性**。

> **重点**：注册会计师仅靠获取更多的审计证据可能无法弥补其质量上的缺陷。不应仅以获取证据的困难和成本为由减少不可替代的程序。

#### （五）审计报告

如果对财务报表发表无保留意见，除非法律法规另有规定，注册会计师应当在审计意见中使用"财务报表在所有重大方面按照[适用的财务报告编制基础]编制，公允反映了……"的措辞。

### 三、审计目标

#### （一）审计总体目标

执行财务报表审计工作时，注册会计师的总体目标是：
1. 对财务报表整体是否不存在舞弊或错误导致的重大错报获取合理保证，使得注册会计师能够对财务报表是否在所有重大方面按照适用的财务报告编制基础编制发表审计意见；
2. 按照审计准则的规定，根据审计结果对财务报表出具审计报告，并与管理层和治理层沟通。

> **重点**：如果不能获取合理保证，并且在审计报告中发表保留意见也不足以实现向预期使用者报告的目的，注册会计师应当按照审计准则的规定出具无法表示意见的审计报告，或者在法律法规允许的情况下终止审计业务或解除业务约定。

#### （二）认定

认定是指管理层针对财务报表要素的确认、计量和列报（包括披露）作出一系列明确或暗含的意思表达。

**1. 关于所审计期间各类交易、事项及相关披露的认定**

| 认定 | 含义 |
|------|------|
| **发生** | 记录或披露的交易和事项已发生，且与被审计单位有关 |
| **完整性** | 所有应当记录的交易和事项均已记录，相关披露均已包括 |
| **准确性** | 金额及其他数据已恰当记录，相关披露已得到恰当计量和描述 |
| **截止** | 交易和事项已记录于正确的会计期间 |
| **分类** | 交易和事项已记录于恰当的账户 |
| **列报** | 已被恰当地汇总或分解且表述清楚，相关披露是相关的、可理解的 |

**2. 关于期末账户余额及相关披露的认定**

| 认定 | 含义 |
|------|------|
| **存在** | 记录的资产、负债和所有者权益是存在的 |
| **权利和义务** | 记录的资产由被审计单位拥有或控制，记录的负债是被审计单位应当履行的偿还义务 |
| **完整性** | 所有应当记录的资产、负债和所有者权益均已记录，相关披露均已包括 |
| **准确性、计价和分摊** | 以恰当的金额包括在财务报表中，与之相关的计价或分摊调整已恰当记录 |
| **分类** | 已记录于恰当的账户 |
| **列报** | 已被恰当地汇总或分解且表述清楚，相关披露是相关的、可理解的 |

> **重点区分**：交易类认定用"发生"（已发生），账户余额类认定用"存在"（确实存在）；交易类用"准确性"，账户余额类用"准确性、计价和分摊"。

#### （三）具体审计目标

注册会计师了解认定后，相对应地确定每个项目的具体审计目标。例如：

| 认定 | 审计目标 | 审计程序举例 |
|------|----------|--------------|
| 存在 | 资产负债表列示的存货存在 | 实施存货监盘程序 |
| 完整性 | 销售收入包括了所有已发货的交易 | 检查发货单和销售发票的编号以及销售明细账 |
| 准确性 | 销售业务基于正确的价格和数量，计算准确 | 比较价格清单与发票上的价格，重新计算发票上的金额 |
| 截止 | 销售业务记录在恰当的期间 | 比较上一年度最后几天和下一年度最初几天的发货单日期与记账日期 |
| 权利和义务 | 资产负债表中的固定资产确实为公司所有 | 查阅所有权证书、购货合同、结算单和保险单 |
| 准确性、计价和分摊 | 以净值记录应收款项 | 检查应收账款账龄分析表，评估计提的坏账准备是否充足 |

### 四、审计基本要求

#### （一）维护公共利益

维护公共利益是注册会计师行业的**天职和初心使命**。注册会计师是资本市场的"看门人"，投资者是注册会计师的真正委托人。

#### （二）遵守审计准则

审计准则是衡量注册会计师执行财务报表审计业务的权威性标准，涵盖从接受业务委托到出具审计报告的整个过程。

#### （三）遵守职业道德守则

注册会计师应当遵循的基本原则包括：
1. 诚信；
2. 独立性；
3. 客观公正；
4. 专业胜任能力和勤勉尽责；
5. 保密；
6. 良好职业行为。

**独立性**包括实质上的独立性和形式上的独立性。

#### （四）保持职业怀疑

职业怀疑是指注册会计师执行审计业务的一种态度，包括采取质疑的思维方式，对可能表明舞弊或错误导致错报的情况保持警觉，以及对审计证据进行审慎评价。

从下列四方面理解：

1. **本质上要求秉持质疑的理念**：摒弃"存在即合理"的逻辑思维，寻求事物的真实情况。
2. **对引起疑虑的情形保持警觉**：包括相互矛盾的审计证据、引起对文件记录可靠性产生怀疑的信息、表明可能存在舞弊的情况等。
3. **审慎评价审计证据**：质疑相互矛盾的审计证据的可靠性。
4. **客观评价管理层和治理层**：不应依赖以往对管理层和治理层诚信形成的判断。

> **重点**：审计中的困难、时间或成本等事项本身，不能作为省略不可替代的审计程序或满足于说服力不足的审计证据的理由。

#### （五）运用职业判断

职业判断贯穿于注册会计师执业的始终。职业判断的决策过程通常可划分为五个步骤：
1. 确定职业判断的问题和目标；
2. 收集和评价相关信息；
3. 识别可能采取的解决方案；
4. 评价可供选择的方案；
5. 得出职业判断结论并作出书面记录。

**衡量职业判断质量的三个方面**：
1. 准确性或意见一致性；
2. 决策一贯性和稳定性；
3. 可辩护性。

### 五、审计风险

审计风险是指当财务报表存在重大错报时，注册会计师发表不恰当审计意见的可能性。审计风险取决于重大错报风险和检查风险。

#### （一）重大错报风险

重大错报风险是指财务报表在审计前存在重大错报的可能性，**独立于财务报表审计而存在**。

**1. 两个层次的重大错报风险**

| 层次 | 特点 |
|------|------|
| **财务报表层次重大错报风险** | 与财务报表整体存在广泛联系，可能影响多项认定，通常与控制环境有关，与舞弊引起的风险尤其相关 |
| **认定层次重大错报风险** | 直接有助于确定认定层次上实施的进一步审计程序的性质、时间安排和范围 |

**2. 固有风险和控制风险**

认定层次的重大错报风险可进一步细分为：

- **固有风险**：在不考虑控制的情况下，某类交易、账户余额或披露的某一认定易于发生错报的可能性。固有风险因素包括事项或情况的复杂性、主观性、变化、不确定性，以及管理层偏向和其他舞弊风险因素。
- **控制风险**：某类交易、账户余额或披露的某一认定发生错报，但没有被内部控制及时防止或发现并纠正的可能性。由于控制的固有局限性，某种程度的控制风险始终存在。

> **重点**：审计准则规定，对于识别出的认定层次重大错报风险，注册会计师应当**分别评估**固有风险和控制风险。

#### （二）检查风险

检查风险是指如果存在某一错报，注册会计师为将审计风险降至可接受的低水平而实施程序后没有发现这种错报的风险。检查风险取决于审计程序设计的合理性和实施的有效性。由于注册会计师通常并不对所有的交易、账户余额和披露进行检查，检查风险不可能降低为零。

#### （三）审计风险模型

$$
\text{审计风险} = \text{重大错报风险} \times \text{检查风险}
$$

$$
\text{重大错报风险} = \text{固有风险} \times \text{控制风险}
$$

> **重点**：在既定的审计风险水平下，可接受检查风险水平与重大错报风险的评估结果呈**反向关系**。评估的重大错报风险越高，可接受的检查风险越低；评估的重大错报风险越低，可接受的检查风险就越高。

**示例**：假设针对某一认定，注册会计师将可接受的审计风险水平设定为 5%，实施风险评估程序后将重大错报风险评估为 25%，则根据审计风险模型，可接受的检查风险为 20%。

#### （四）审计的固有限制

注册会计师不可能将审计风险降至零，因此不能对财务报表是否不存在重大错报获取绝对保证。审计的固有限制源于：

1. **财务报告的性质**：管理层编制财务报表需要运用判断，许多财务报表项目涉及主观决策、评估或一定程度的不确定性。
2. **审计程序的性质**：管理层或其他人员可能不提供全部信息；舞弊可能涉及精心策划和蓄意实施以进行隐瞒；注册会计师没有被授予特定的法律权力（如搜查权）。
3. **在合理的时间内以合理的成本完成审计的需要**：需要在信息的可靠性和成本之间进行权衡。

### 六、审计过程

审计过程大致可分为以下五个阶段：

| 阶段 | 主要工作 |
|------|----------|
| **1. 接受业务委托** | 实施客户接受与保持的程序，考虑客户诚信、自身能力、遵守职业道德要求；就审计约定条款达成一致意见 |
| **2. 计划审计工作** | 开展初步业务活动；制定总体审计策略；制定具体审计计划（贯穿审计全过程） |
| **3. 识别和评估重大错报风险** | 实施风险评估程序，了解被审计单位及其环境、适用的财务报告编制基础和内部控制体系各要素；识别和评估财务报表层次和认定层次重大错报风险 |
| **4. 应对重大错报风险** | 针对财务报表层次重大错报风险确定总体应对措施；针对认定层次重大错报风险设计和实施进一步审计程序（控制测试和实质性程序） |
| **5. 编制审计报告** | 完成审计工作，根据所获取的审计证据形成适当的审计意见，编制审计报告 |

### 七、注册会计师审计的执业责任

#### （一）执业责任

| 责任类型 | 主要内容 |
|----------|----------|
| **行政责任** | 财政部门行政处罚（警告、没收违法所得、暂停业务、吊销证书）；证券法规定未勤勉尽责的，没收业务收入并处业务收入 1-10 倍罚款 |
| **民事责任** | 会计师事务所违反规定给委托人、其他利害关系人造成损失的，依法承担赔偿责任；证券服务机构和委托人承担连带赔偿责任 |
| **刑事责任** | 提供虚假证明文件情节严重的，处 5 年以下有期徒刑或拘役；情节特别严重的，处 5-10 年有期徒刑 |

判断勤勉尽责的核心标准是会计师事务所和注册会计师是否遵守了法律法规和职业准则。

#### （二）期望差距

社会公众与注册会计师职业界在对职业责任的认识上存在的差距。社会公众期望注册会计师通过审计，能发现并报告被审计单位的重大故意和非故意的错报；而过去注册会计师职业界曾认为他们的责任是发现重大非故意错报。

#### （三）审计报告和信息差距

财务报表使用者作出理智投资决策需要的信息，与从审计报告和已审计财务报表中得到的信息之间存在差距。2016 年我国借鉴国际审计报告改革成果，增加关键审计事项部分，缩小了"信息差距"。

## 💡 典型例题

**【例题1·单选题】** 关于财务报表审计，下列说法中错误的是（　）。

A. 审计的用户是财务报表的预期使用者
B. 审计的目的是改善财务报表质量，增强除管理层之外的预期使用者对财务报表的信赖程度
C. 审计能够提供绝对保证
D. 审计的基础是注册会计师的独立性和专业性

> **答案：C**
> **解析**：由于审计存在固有限制，注册会计师得出审计结论和形成审计意见依据的大多数审计证据是说服性而非结论性的，因此审计只能提供合理保证，而不能提供绝对保证，C 错误。

**【例题2·单选题】** 下列关于合理保证和有限保证的说法中，正确的是（　）。

A. 审计属于有限保证的鉴证业务
B. 审阅属于合理保证的鉴证业务
C. 审计所需证据数量较少，审阅所需证据数量较多
D. 审计以积极方式提出结论，审阅以消极方式提出结论

> **答案：D**
> **解析**：审计属于合理保证（高水平保证）的鉴证业务，审阅属于有限保证（低于审计业务的保证水平）的鉴证业务，A、B 错误；审计所需证据数量较多，审阅所需证据数量较少，C 错误；审计以积极方式提出结论，审阅以消极方式提出结论，D 正确。

**【例题3·单选题】** 注册会计师在对 A 公司的存货进行审计时，通过实施存货监盘程序，确认资产负债表列示的存货存在。该审计目标对应的认定是（　）。

A. 完整性
B. 存在
C. 权利和义务
D. 准确性、计价和分摊

> **答案：B**
> **解析**："存在"认定是指记录的资产、负债和所有者权益是存在的。由"存在"认定推导的审计目标是确认记录的金额确实存在。通过存货监盘程序确认资产负债表列示的存货存在，对应的是"存在"认定，B 正确。

**【例题4·多选题】** 下列各项中，属于关于所审计期间各类交易、事项及相关披露的认定的有（　）。

A. 发生
B. 存在
C. 截止
D. 准确性

> **答案：ACD**
> **解析**：关于所审计期间各类交易、事项及相关披露的认定包括：发生、完整性、准确性、截止、分类、列报。"存在"属于期末账户余额及相关披露的认定，B 错误。

**【例题5·单选题】** 在既定的审计风险水平下，注册会计师针对某一认定确定的可接受检查风险水平与评估的重大错报风险之间的关系是（　）。

A. 正向关系
B. 反向关系
C. 没有关系
D. 等比例关系

> **答案：B**
> **解析**：在既定的审计风险水平下，可接受检查风险水平与重大错报风险的评估结果呈反向关系。即评估的重大错报风险越高，可接受的检查风险越低；评估的重大错报风险越低，可接受的检查风险就越高。

**【例题6·多选题】** 下列各项中，属于审计的固有限制来源的有（　）。

A. 财务报告的性质
B. 审计程序的性质
C. 在合理的时间内以合理的成本完成审计的需要
D. 注册会计师缺乏独立性

> **答案：ABC**
> **解析**：审计的固有限制源于：①财务报告的性质；②审计程序的性质；③在合理的时间内以合理的成本完成审计的需要。注册会计师缺乏独立性不属于审计的固有限制，而是违反职业道德要求的情况，D 错误。

## 🎯 记忆口诀

**财务报表审计五要素**：用户、目的、保证、基础、产品——"用目保基产"。

**合理保证 vs 有限保证**：合理高水平积极多证据，有限低水平消极少证据——"合高积多，有低消少"。

**三方关系人**：注册会计师、管理层、预期使用者——"注管用"。

**管理层执行审计工作前提三责任**：编制财务报表、设计内部控制、提供工作条件——"编内提"。

**审计要素五项**：三方关系人、财务报表、财务报告编制基础、审计证据、审计报告——"三人表基证报"。

**交易类认定六项**：发生、完整性、准确性、截止、分类、列报——"发完准截分列"。

**账户余额类认定六项**：存在、权利和义务、完整性、准确性计价和分摊、分类、列报——"存权完准分列"。

**交易类与余额类认定区分**：交易用"发生"，余额用"存在"；交易用"准确性"，余额用"准确性计价和分摊"——"发对交，存对余"。

**职业道德六项基本原则**：诚信、独立性、客观公正、专业胜任能力和勤勉尽责、保密、良好职业行为——"诚独客专保良"。

**职业怀疑四方面**：质疑理念、保持警觉、审慎评价、客观评价管理层——"疑警惕评管"。

**职业判断五步骤**：确定问题和目标、收集评价信息、识别解决方案、评价方案、得出结论并记录——"定收识评得"。

**职业判断质量三方面**：准确性或意见一致性、决策一贯性和稳定性、可辩护性——"准一辩"。

**审计风险模型**：审计风险=重大错报风险×检查风险，重大错报风险=固有风险×控制风险——"审大检，大固控"。

**检查风险与重大错报风险反向关系**：评估风险越高，可接受检查风险越低——"高反低"。

**审计固有限制三来源**：财务报告性质、审计程序性质、时间成本权衡——"报序时"。

**审计过程五阶段**：接受业务委托、计划审计工作、识别评估重大错报风险、应对重大错报风险、编制审计报告——"接计识应编"。

**执业责任三类**：行政责任、民事责任、刑事责任——"行民刑"。
