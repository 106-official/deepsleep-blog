## 📝 考情分析

本章阐述信息技术对审计的影响，包括信息技术一般控制、信息处理控制、计算机辅助审计技术、数据分析等内容，分值稳定在 2-3 分。**信息技术一般控制和信息处理控制的概念及关系是高频考点**。

**命题规律：**

1. **信息技术对企业内部控制的影响**：常考自动化控制的好处（处理大量交易、不容易被绕过、有效职责分离等）和运用信息技术导致的风险（错误处理数据、非授权访问、数据丢失、人工干预绕过自动化控制）。
2. **三类信息技术控制**：高频考点，区分信息技术一般控制（程序开发、程序变更、程序和数据访问、计算机运行四个领域）、信息处理控制（完整性、准确性、授权和访问限制）和公司层面信息技术控制，以及三者的关系。
3. **信息技术对审计过程的影响**：对审计线索、审计技术手段、内部控制、审计内容、注册会计师的影响。
4. **计算机辅助审计技术**：面向系统（平行模拟法、测试数据法、嵌入审计模块法等）和面向数据（数据查询、账表分析等）两类。
5. **数据分析**：基本步骤（计划、获取整理数据、评价相关性和可靠性、执行数据分析、评价和应对结果）。
6. **不同信息技术环境**：网络环境、数据库管理系统、电子商务系统、外包安排的内部控制考虑。

**备考策略：** 重点掌握三类信息技术控制的概念、内容及其相互关系（公司层面控制决定风险基调，一般控制是基础影响信息处理控制的有效性），以及计算机辅助审计技术的分类。本章以概念理解为主，难度不大。

## 📖 核心精讲

### 一、信息技术对企业财务报告和内部控制的影响

#### （一）信息技术对企业财务报告的影响

企业可以运用信息系统来创建、记录、处理和报告各项交易。信息系统的使用带来的变化包括：计算机输入和输出代替人工记录；计算机显示屏和电子影像代替纸质凭证；计算机文档代替纸质日记账和分类账；网络通信和电子邮件代替公司间的邮寄；管理系统需求固化到应用程序中；灵活多样的报告代替固定格式的报告；数据更加充分，信息更易共享；系统性问题比偶然性误差更为普遍。

> **重点**：如果注册会计师拟依赖相关信息系统生成的信息和报告作为审计工作的依据，则必须考虑相关信息和报告的质量，需要在整个过程中考虑信息的**准确性、完整性、授权和访问限制**四个方面。

#### （二）信息技术对企业内部控制的影响

在信息技术环境下，传统的人工控制越来越多地被自动化控制所替代，但人工控制并不会被完全取代。

**自动化控制的好处**：

| 好处 | 说明 |
|------|------|
| 有效处理大量交易 | 自动化信息系统可以提供与业务规则一致的系统处理方法 |
| 不容易被绕过 | 相比人工控制，自动化控制更难被绕过 |
| 有效职责分离 | 信息系统、数据库及操作系统的安全控制可以实现有效的职责分离 |
| 提高信息及时性、准确性 | 使信息变得更易获取 |
| 提高监督水平 | 提高管理层对企业业务活动及相关政策的监督水平 |

#### （三）运用信息技术导致的风险

信息技术在改进内部控制的同时，也产生了特定的风险：

1. 信息系统或相关程序可能会对数据进行错误处理，也可能会去处理那些本身就错误的数据；
2. 自动化信息系统、数据库及操作系统的相关安全控制如果无效，会增加对数据非授权访问的风险；
3. 数据丢失风险或数据无法访问风险，如系统瘫痪等；
4. 不适当的人工干预，或人为绕过自动化控制。

#### （四）注册会计师在信息化环境下面临的挑战

主要包括八个方面：①对业务流程开展和内部控制运作的理解；②对信息系统相关审计风险的认识；③审计范围的确定；④审计内容的变化；⑤审计线索的隐性化；⑥改进审计技术的必要性；⑦知识结构有待优化；⑧与专业团队的充分协作。

### 二、信息技术一般控制、信息处理控制和公司层面信息技术控制

#### （一）信息技术一般控制

信息技术一般控制是指为了保证信息系统的安全，对整个信息系统以及外部各种环境要素实施的、对所有的应用或控制模块具有普遍影响的控制措施。通常会对实现部分或全部财务报表认定作出**间接贡献**。

与财务报告相关的信息技术一般控制通常涉及**四个领域**：

| 领域 | 目标 |
|------|------|
| **程序开发** | 确保系统的开发、配置和实施能够实现管理层的信息处理控制目标 |
| **程序变更** | 确保对程序和相关基础组件的变更是经过请求、授权、执行、测试和实施的 |
| **程序和数据访问** | 确保分配的访问程序和数据的权限是经过用户身份认证并经过授权的 |
| **计算机运行** | 确保业务系统根据管理层的控制目标完整准确地运行，确保运行问题被完整准确地识别并解决 |

> **重点**：如果注册会计师计划依赖自动化信息处理控制或依赖使用信息系统生成信息的控制，就需要对相关的信息技术一般控制进行测试。

#### （二）信息处理控制

信息处理控制是指与被审计单位信息系统中下列两方面相关的控制：①信息技术应用程序进行的信息处理；②人工进行的信息处理。信息处理控制一般要经过输入、处理及输出等环节。

**系统自动化控制关注的要素**：

| 要素 | 含义 | 示例 |
|------|------|------|
| **完整性** | 系统处理数据的完整性 | 各系统之间数据传输的完整性、销售订单自动记录的完整性 |
| **准确性** | 系统运算逻辑的准确性 | 利息计提逻辑的准确性、物料成本运算逻辑的准确性、应收账款账龄的准确性 |
| **授权和访问限制** | 信息系统相关的逻辑校验控制 | 限制检查、合理性检查、存在检查和格式检查；业务操作的授权管理 |

**常见的系统自动化控制**：系统自动生成报告、系统配置和科目映射、接口控制、访问和权限。

#### （三）公司层面信息技术控制

常见的公司层面信息技术控制包括：信息技术规划的制定、信息技术年度计划的制定、信息技术内部审计机制的建立、信息技术外包管理、信息技术预算管理、信息安全和风险管理、信息技术应急预案的制定、信息系统架构建设和信息技术复杂性的考虑。

#### （四）三者之间的关系

> **重点**：这是本章的核心考点。

| 控制类型 | 作用 | 关系 |
|----------|------|------|
| **公司层面信息技术控制** | 代表公司信息技术控制的整体环境 | 决定信息技术一般控制和信息处理控制的风险基调 |
| **信息技术一般控制** | 保证信息系统安全的普遍性控制 | 是基础，其有效与否直接影响信息处理控制的有效性是否能够信任 |
| **信息处理控制** | 设计在应用系统中达到信息处理目标的控制 | 依赖于一般控制的有效性 |

**举例**：如果在带有关键的编辑检查功能的应用系统所依赖的计算机环境中发现了信息技术一般控制的缺陷，注册会计师可能就不能信赖上述编辑检查功能按设计发挥作用。例如，程序变更控制缺陷可能导致未授权人员对检查录入数据字段格式的编程逻辑进行修改，以至于系统接受不准确的数据录入。

### 三、信息技术对审计过程的影响

信息技术在企业中的应用**并不改变**注册会计师制定审计目标、实施风险评估和了解内部控制的原则性要求，但对其产生以下影响：

| 影响方面 | 内容 |
|----------|------|
| **对审计线索的影响** | 数据保存在存储介质上，影响数据存储介质、存取方式以及处理程序等，审计线索隐性化 |
| **对审计技术手段的影响** | 需要掌握相关信息技术，把信息技术当作审计工具 |
| **对内部控制的影响** | 影响信息的处理、存储和沟通方式，影响内部控制的设计和执行方式 |
| **对审计内容的影响** | 审计内容可能包括对信息系统中相关自动化控制的测试 |
| **对注册会计师的影响** | 要求注册会计师具备相关信息技术方面的知识，成为复合型人才 |

#### 信息技术审计范围的确定

注册会计师在确定审计策略时，需要结合以下三个方面对信息技术审计范围进行考虑：

1. **业务流程复杂程度**（销售流程、薪酬流程、采购流程等）；
2. **信息系统复杂程度**（系统生成的交易数量、业务对系统的依赖程度、信息和复杂计算的数量）；
3. **信息技术环境规模和复杂程度**（产生财务数据的信息系统数量、接口及数据传输方式、信息部门结构与规模、网络规模、用户数量、外包及访问方式）。

> **重点**：信息技术审计的范围与被审计单位在业务流程及信息系统相关方面的复杂程度呈**正相关关系**。

#### 信息技术一般控制对控制风险的影响

- 无效的一般控制增加了信息处理控制不能防止或发现并纠正认定层次重大错报的可能性；
- 如果一般控制有效，注册会计师可以更多地信赖信息处理控制，测试这些控制的运行有效性，并将控制风险评估为低于"最高"水平；
- 注册会计师通常**优先评估**公司层面信息技术控制和信息技术一般控制的有效性。

#### 不同复杂程度环境下的审计

| 环境复杂程度 | 审计方式 |
|--------------|----------|
| **不太复杂** | "绕过计算机进行审计"——仍需了解信息技术一般控制和信息处理控制，但不需要测试其运行有效性 |
| **较为复杂** | "穿过计算机进行审计"——需要运用各项审计技术和审计工具开展工作 |

### 四、计算机辅助审计技术和电子表格的运用

#### （一）计算机辅助审计技术（CAATs）

计算机辅助审计技术是指利用计算机和相关软件，使审计测试工作实现自动化的技术。分为两类：

| 类型 | 方法 |
|------|------|
| **面向系统的 CAATs** | 平行模拟法、测试数据法、嵌入审计模块法、程序编码审查、程序代码比较和跟踪、快照等 |
| **面向数据的 CAATs** | 数据查询、账表分析、审计抽样、统计分析、数值分析等 |

**CAATs 的应用领域**：
- **实质性程序**（特别是实质性分析程序）：最广泛的应用领域，可以替代人工测试大量交易；
- **控制测试**：可以测试控制运行的有效性，对每一笔交易进行测试；
- **舞弊检查**：有助于详细审计海量数据，如审计非正常的日记账。

**计算机辅助审计工具**：
- 通用类：Excel、Access 等；
- 数据库类：SQL Server、Oracle 等；
- 专业工具类：ACL、DEA 等。

#### （二）电子表格

电子表格的特性（开放的访问、人工输入数据和容易出错）以及使用环境特性（用户开发不正式、开发文档不完整），增加了数据存在错误的风险。

**电子表格面临的重大风险**：
1. 输入错误；
2. 逻辑错误（创建错误的公式）；
3. 接口错误（与其他系统传输数据时）；
4. 未经授权访问风险；
5. 其他错误（单元格范围定义不当、单元格参考错误、电子表格链接不当）。

### 五、数据分析

#### （一）数据分析的概念

数据分析是注册会计师获取审计证据的一种手段，是指注册会计师在计划和执行审计工作时，通过对内部或外部数据进行分析、建模或可视化处理，以发现其中隐含的模式、偏差或不一致，从而揭示出对审计有用的信息的方法。

#### （二）数据分析的基本步骤

| 步骤 | 内容 |
|------|------|
| **1. 计划数据分析** | 确定数据分析所针对的财务报表账户、披露和相关认定，数据分析的总体目标和具体目标，选择数据、程序及具体步骤 |
| **2. 获取和整理数据** | 从不同信息系统或外部获取数据，识别数据中的错误，校验数据的准确性和完整性（数据一致性校验、处理无效值和缺失值等） |
| **3. 评价所用数据的相关性和可靠性** | 相关性：与审计程序目的和所考虑的相关认定之间的逻辑关系；可靠性：考虑数据的准确性和完整性、来源和性质、获取数据的环境、与数据生成和维护相关的控制 |
| **4. 具体执行数据分析** | 识别异常项目，必要时重新定义数据特征进行分析或将异常项目分为若干子集设计针对性审计程序 |
| **5. 评价和应对数据分析结果** | 得出执行数据分析的目的是否已实现的结论 |

#### （三）数据分析面临的主要挑战

1. 审计对象信息或审计证据的数字化程度（大量纸质形式存在）；
2. 电子数据的可获得性（财务数据接口不一致，信息"孤岛化"）；
3. 数据标准的统一（不同企业数据在单位、编码、格式等方面存在差异）；
4. 被审计单位的信息技术一般控制和信息处理控制存在缺陷（提取的数据可能不准确、不完整）。

### 六、不同信息技术环境下的信息管理

| 环境 | 内部控制相关问题 |
|------|------------------|
| **网络环境** | 分布于不同位置的服务器的安全、数据和信息的分布及同步、管理监督以及兼容性问题 |
| **数据库管理系统（DBMS）** | 多重使用者能够访问和修改共享数据的风险，需要实施严格的数据库管理和接触控制，以及数据安全备份制度 |
| **电子商务系统** | 交易信息在网上传输容易被拦截、篡改或不当获取；与交易对方系统相连接产生互相依赖的风险 |
| **外包安排** | 参照《中国注册会计师审计准则第1241号》办理，需了解服务机构控制并获取控制运行有效性证据 |

**外包安排下注册会计师获取证据的程序**：
1. 了解服务机构注册会计师对服务机构内部控制有效性出具的报告或与控制测试相关的商定程序报告；
2. 测试被审计单位对服务机构活动的控制；
3. 对服务机构实施控制测试。

### 七、运用信息技术识别与应对舞弊风险

#### （一）可用于识别与应对舞弊风险的信息技术

| 技术 | 说明 |
|------|------|
| **机器人流程自动化（RPA）** | 使用软件机器人模拟人工在数字系统中交互以执行任务，减少人为错误 |
| **可视化分析工具和技术** | 将大量复杂数据转化为易于理解的视觉格式，常用工具有 Power BI、Tableau、帆软等 |
| **光学字符识别技术（OCR）** | 将不同形式文档中的印刷或手写文本转换为机器可编辑的文本格式 |
| **大数据分析技术** | 从大规模数据集提取有价值信息，如业财核对、时间序列分析、相关性分析、异常分布等 |
| **人工智能模型和算法** | 通过回归算法、聚类算法、敏感性分析等提取和学习舞弊数据模式，进行特征识别 |
| **智能实体机器人应用技术** | 如无人机盘点，协助快速且精确的库存盘点 |

#### （二）运用信息技术前的准备工作

**会计师事务所的准备工作**：
1. **信息技术内部认证**：确保拟运用的信息技术经过充分的测试和认证（可靠性、安全性、有效性、数据保密性）；
2. **培养运用信息技术的胜任能力**：必要时利用相关领域专家的工作；
3. **避免自动化零错误的认知偏差**：倾向于相信信息系统自动生成的结果，即使该结果有悖于常识推理；
4. **建立相关的基础设施并投入充足的资源**：存储和算力资源、数据传输安全保障体系等。

> **重点**：**自动化零错误**是指倾向于相信信息系统自动生成的结果，即使该结果有悖于人的常识推理或与其他方面的信息存在冲突。这种认知偏差可能影响注册会计师保持职业怀疑。

#### （三）不同阶段运用信息技术识别与应对舞弊风险

| 阶段 | 应用 |
|------|------|
| **承接审计业务前** | 收集多维度财务与非财务数据，建立层级式指标体系，识别疑似高风险、高舞弊行为特征点 |
| **审计计划和风险评估阶段** | 运用总账分析器等工具进行风险识别与评估，如简要财务报表分析、特定科目的锚定分析 |
| **进一步审计程序中** | 收入分析（大数据分析识别异常客户和供应商、机器学习核查用户行为真实性）、资金分析（OCR清洗银行流水、对手方分析）、关联方分析（机器学习识别隐性关联关系） |

## 💡 典型例题

**【例题1·单选题】** 下列各项中，不属于信息技术一般控制领域的是（　）。

A. 程序开发
B. 程序变更
C. 系统自动生成报告
D. 计算机运行

> **答案：C**
> **解析**：与财务报告相关的信息技术一般控制通常涉及程序开发管理、程序变更管理、程序和数据访问管理以及计算机运行管理四个领域。"系统自动生成报告"属于信息处理控制，而非信息技术一般控制，C 错误。

**【例题2·单选题】** 关于公司层面信息技术控制、信息技术一般控制和信息处理控制之间的关系，下列说法中正确的是（　）。

A. 信息处理控制是基础，影响信息技术一般控制的有效性
B. 信息技术一般控制决定公司层面信息技术控制的风险基调
C. 公司层面信息技术控制代表整体控制环境，决定风险基调
D. 信息技术一般控制对财务报表认定只产生直接贡献

> **答案：C**
> **解析**：公司层面信息技术控制是公司信息技术整体控制环境，决定了信息技术一般控制和信息处理控制的风险基调，C 正确；信息技术一般控制是基础，其有效与否直接影响信息处理控制的有效性，A、B 错误；信息技术一般控制通常会对实现部分或全部财务报表认定作出间接贡献（在某些情况下也可能作出直接贡献），D 错误。

**【例题3·多选题】** 下列各项中，属于运用信息技术导致的风险的有（　）。

A. 信息系统对数据进行错误处理
B. 增加对数据非授权访问的风险
C. 数据丢失风险或数据无法访问风险
D. 不适当的人工干预或人为绕过自动化控制

> **答案：ABCD**
> **解析**：信息技术在改进内部控制的同时，产生了特定的风险：①信息系统或相关程序可能会对数据进行错误处理；②自动化信息系统、数据库及操作系统的相关安全控制如果无效，会增加对数据非授权访问的风险；③数据丢失风险或数据无法访问风险；④不适当的人工干预，或人为绕过自动化控制。四个选项均属于运用信息技术导致的风险。

**【例题4·单选题】** 注册会计师使用自身的应用软件，运用与被审计单位同样的数据文件，执行被审计单位应用软件同样的操作，以确定被审计单位自动化控制的有效性。这种计算机辅助审计技术是（　）。

A. 测试数据法
B. 平行模拟法
C. 嵌入审计模块法
D. 程序编码审查

> **答案：B**
> **解析**：平行模拟法是指注册会计师使用自身的应用软件，并且运用与被审计单位同样的数据文件，执行被审计单位应用软件同样的操作，以确定被审计单位自动化控制的有效性或账户余额的准确性，B 正确。

**【例题5·多选题】** 下列各项中，属于数据分析基本步骤的有（　）。

A. 计划数据分析
B. 获取和整理数据
C. 评价所用数据的相关性和可靠性
D. 具体执行数据分析

> **答案：ABCD**
> **解析**：数据分析的基本步骤包括：①计划数据分析；②获取和整理数据；③评价所用数据的相关性和可靠性；④具体执行数据分析；⑤评价和应对数据分析结果。四个选项均属于数据分析的基本步骤。

**【例题6·单选题】** 当面临不太复杂的信息技术环境时，注册会计师通常采取的审计方式是（　）。

A. 穿过计算机进行审计
B. 绕过计算机进行审计
C. 不需要了解信息技术一般控制
D. 不需要了解信息处理控制

> **答案：B**
> **解析**：当面临不太复杂的信息技术环境时，注册会计师可采取传统方式进行审计，即"绕过计算机进行审计"。在此情形下，注册会计师虽然仍需了解信息技术一般控制和信息处理控制，但不需要测试其运行有效性，B 正确。

## 🎯 记忆口诀

**信息系统信息质量四方面**：准确性、完整性、授权、访问限制——"准完授访"。

**自动化控制五好处**：处理大量交易、不容易被绕过、有效职责分离、提高信息及时性准确性、提高监督水平——"量绕职及监"。

**运用信息技术四风险**：错误处理数据、非授权访问、数据丢失、绕过自动化控制——"错访丢绕"。

**信息技术一般控制四领域**：程序开发、程序变更、程序和数据访问、计算机运行——"开更访运"。

**信息处理控制三要素**：完整性、准确性、授权和访问限制——"完准授"。

**三者关系**：公司层面控制决定风险基调，一般控制是基础影响信息处理控制有效性——"公基处"。

**信息技术对审计五影响**：审计线索、技术手段、内部控制、审计内容、注册会计师——"线手内容人"。

**信息技术审计范围三考虑**：业务流程复杂程度、信息系统复杂程度、环境规模复杂程度——"业系环"。

**一般控制对控制风险影响**：一般控制有效→可信赖信息处理控制→控制风险评估低于最高——"有效可信赖"。

**两类 CAATs**：面向系统（平行模拟、测试数据、嵌入审计模块）、面向数据（查询、分析、抽样）——"系模测嵌，数查分抽"。

**CAATs 三应用领域**：实质性程序、控制测试、舞弊检查——"实控舞"。

**电子表格五风险**：输入错误、逻辑错误、接口错误、未经授权访问、其他错误——"辑接未其"。

**数据分析五步骤**：计划、获取整理、评价相关性可靠性、执行、评价应对——"计获评执评"。

**数据分析四挑战**：数字化程度、数据可获得性、数据标准统一、内控缺陷——"数可标缺"。

**四类信息技术环境**：网络环境、数据库管理系统、电子商务系统、外包安排——"网数电外"。

**运用信息技术前事务所四准备**：内部认证、培养胜任能力、避免自动化零错误偏差、建立基础设施——"认培避建"。

**六类舞弊识别技术**：RPA、可视化分析、OCR、大数据分析、人工智能、智能实体机器人——"机视光大智实"。
