## 2. 考情分析

房产税法是 CPA 税法考试次重点章节，分值约 1-2 分。考查形式以客观题为主，主观题偶有与城镇土地使用税结合考查。考查重点集中于：房产税纳税人（产权所有人、承典人、代管人/使用人、无租使用代缴人）、征税范围（城市、县城、建制镇、工矿区，不含农村）、两种计征方式（从价计征 1.2%、从租计征 12%/4%）、计税依据（房产原值减除 10%-30% 后的余值、租金收入）、房产原值的确定（含地价、附属设备、地下建筑折算）、应纳税额计算、税收优惠（法定免征 21 项）、纳税义务发生时间（8 种情形）。复习时需重点掌握"从价计征"和"从租计征"两种计算方法及其适用情形，以及地下建筑应税原值的折算比例。

## 4. 核心精讲

### 一、纳税人与征税范围

#### （一）纳税人

房产税是以房产为征税对象，按照房产的计税余值或出租房产取得的租金收入，向产权所有人征收的一种财产税。房产税由产权所有人缴纳。

| 情形 | 纳税人 |
|------|--------|
| 产权属于全民所有 | 经营管理单位 |
| 产权出典 | 承典人 |
| 产权所有人、承典人不在房产所在地，或产权未确定及租典纠纷未解决 | 房产代管人或者使用人 |
| 无租使用其他单位房产的应税单位和个人 | 依照房产余值代缴纳 |

> 产权出典是指产权所有人将房屋产权在一定期限内典当给他人使用而取得资金的融资业务。出典期间产权所有人无权支配房屋，故由承典人纳税。

#### （二）征税范围

房产税以房产为征税对象。所谓房产，是指有屋面和围护结构（有墙或两边有柱），能够遮风避雨，可供人们在其中生产、学习、工作、娱乐、居住或储藏物资的场所。

| 区域 | 确认标准 |
|------|----------|
| 城市 | 国务院批准设立的市 |
| 县城 | 未设立建制镇的县人民政府所在地 |
| 建制镇 | 省、自治区、直辖市人民政府批准设立的建制镇 |
| 工矿区 | 工商业发达、人口集中、符合建制镇标准但尚未设镇的大中型工矿企业所在地（须经省级政府批准） |

**特别规定**：
- 房地产开发企业建造的商品房，在出售前不征收房产税；
- 但出售前已使用或出租、出借的商品房，应按规定征收房产税。

### 二、税率、计税依据和应纳税额

#### （一）税率

房产税采用**比例税率**，依计税依据不同分为两种：

| 计征方式 | 税率 |
|----------|------|
| 从价计征（按房产余值） | 1.2% |
| 从租计征（按租金收入） | 12% |
| 个人出租住房（不区分用途） | 4%（自 2008.3.1 起） |
| 企事业单位、社会团体等向个人、专业化规模化住房租赁企业出租住房 | 4%（自 2021.10.1 起） |

#### （二）计税依据

**1. 从价计征——房产余值**

从价计征的计税余值 = 房产原值一次减除 **10%~30%** 后的余值（具体减除幅度由省级政府规定）。

**房产原值的确定**：

| 事项 | 规定 |
|------|------|
| 会计账簿"固定资产"科目记载的房屋原价 | 以房屋原价按规定减除比例后计征 |
| 未记载房屋原价 | 参照同类房屋确定 |
| 地价（自 2010.12.21 起） | 无论会计如何核算，房产原值均应包含地价（含土地使用权价款、开发土地成本费用） |
| 宗地容积率低于 0.5 | 按房产建筑面积的 2 倍计算土地面积并据此确定计入房产原值的地价 |
| 附属设备 | 暖气、卫生、通风、照明、煤气、电梯、升降机、过道、晒台等，及给排水、采暖、消防、中央空调等不可随意移动的附属设备，均应计入房产原值 |
| 改建扩建 | 相应增加房屋原值 |
| 更换附属设备 | 可扣减原来相应设备价值；易损零配件更新后不再计入 |

**地下建筑的应税房产原值折算**：

| 地下建筑类型 | 应税房产原值折算比例 |
|--------------|---------------------|
| 工业用途房产 | 房屋原价的 50%~60% |
| 商业和其他用途房产 | 房屋原价的 70%~80% |
| 与地上房屋相连的地下建筑（地下室、地下停车场、商场地下部分等） | 与地上房屋视为一个整体，按地上房屋规定计征 |

> 房屋原价折算为应税房产原值的具体比例，由各省、自治区、直辖市和计划单列市财政和地方税务部门在上述幅度内自行确定。

**2. 从租计征——租金收入**

房产出租的，以房产租金收入为计税依据。租金收入包括货币收入和实物收入。

| 情形 | 计税依据 |
|------|----------|
| 以劳务或其他形式为报酬抵付房租 | 按当地同类房产租金水平确定标准租金额 |
| 租赁合同约定免收租金期限 | 免租期间由产权所有人按照房产原值缴纳房产税 |
| 出租地下建筑 | 按出租地上房屋建筑规定计征 |

**3. 特殊情形的计税依据**

| 情形 | 计税依据 |
|------|----------|
| 投资联营，共担风险 | 按房产余值 |
| 投资联营，收取固定收入、不承担风险 | 按租金收入 |
| 融资租赁房产 | 由承租人依照房产余值缴纳（合同约定开始日次月起；未约定的为合同签订次月起） |
| 居民住宅区内业主共有的经营性房产（自营） | 依照房产原值减除 10%~30% 余值计征 |
| 居民住宅区内业主共有的经营性房产（出租） | 依照租金收入计征 |

#### （三）应纳税额计算

**1. 从价计征**：

$$\text{应纳税额}=\text{应税房产原值}\times(1-\text{原值减除比例})\times 1.2\%$$

**2. 从租计征**：

$$\text{应纳税额}=\text{租金收入}\times 12\%\text{（或 }4\%\text{）}$$

### 三、税收优惠

| 序号 | 免征项目 | 说明 |
|------|----------|------|
| 1 | 国家机关、人民团体、军队自用的房产 | 办公用房和公务用房；出租房产及非自身业务使用的生产营业用房不免税 |
| 2 | 国家财政部门拨付事业经费的单位自用的房产 | 经费来源实行自收自支后应征收 |
| 3 | 宗教寺庙、公园、名胜古迹自用的房产 | 仪式用房/公共参观用房；附设营业单位及出租房产照章纳税 |
| 4 | 个人所有非营业用的房产 | 居民住房不分面积一律免征；营业用房或出租房产照章纳税 |
| 5 | 非营利性医疗机构、疾病控制机构、妇幼保健机构自用房产 | — |
| 6 | 按政府规定价格出租的公有住房和廉租住房 | 暂免征收 |
| 7 | 公租房 | 免征（须单独核算租金收入） |
| 8 | 企业办的各类学校、医院、托儿所、幼儿园自用房产 | — |
| 9 | 毁损不堪居住的房屋和危险房屋 | 停止使用后可免征 |
| 10 | 房屋大修导致连续停用半年以上 | 大修期间免征 |
| 11 | 基建工地临时性房屋 | 施工期间免征；工程结束后交基建单位的从接收次月起征税 |
| 12 | 纳税单位与免税单位共同使用的房屋 | 按各自使用部分分别征免 |
| 13 | 财政拨付事业经费的文化单位转制为企业 | 自转制注册之日起至 2027.12.31 自用房产免征 |
| 14 | 房地产开发企业建造的商品房出售前 | 不征收；已使用/出租/出借的除外 |
| 15 | 大型民用客机研制项目自用科研生产办公房产 | 至 2027.12.31 |
| 16 | 高校学生公寓 | 至 2027.12.31 |
| 17 | 农产品批发市场、农贸市场专门用于经营农产品的房产 | 至 2027.12.31 |
| 18 | 商品储备管理公司及其直属库自用承担商品储备业务的房产 | 至 2027.12.31 |
| 19 | 农村饮水安全工程运营管理单位自用生产办公用房产 | 至 2027.12.31（按向农村居民供水量比例免征） |
| 20 | 国家级、省级科技企业孵化器、大学科技园、众创空间自用及提供给在孵对象使用的房产 | 至 2027.12.31 |
| 21 | 增值税小规模纳税人、小型微利企业和个体工商户 | 减半征收，至 2027.12.31（可叠加享受其他优惠） |

### 四、征收管理

#### （一）纳税义务发生时间

| 情形 | 纳税义务发生时间 |
|------|------------------|
| 原有房产用于生产经营 | 从生产经营之月起 |
| 自行新建房屋用于生产经营 | 从建成之次月起 |
| 委托施工企业建设的房屋 | 从办理验收手续之次月起 |
| 购置新建商品房 | 自房屋交付使用之次月起 |
| 购置存量房 | 自房屋权属证书签发之次月起 |
| 出租、出借房产 | 自交付出租、出借房产之次月起 |
| 房地产开发企业自用、出租、出借本企业建造的商品房 | 自房屋使用或交付之次月起 |
| 因房产实物或权利状态变化终止纳税义务 | 应纳税款计算截止到房产实物或权利状态发生变化的当月末 |

> 注意：仅"原有房产用于生产经营"为"之月起"，其余均为"次月起"。

#### （二）纳税期限

房产税实行**按年征收、分期缴纳**，具体纳税期限由省、自治区、直辖市人民政府规定。

#### （三）纳税地点

房产税在**房产所在地**缴纳。房产不在同一地方的纳税人，应按房产的坐落地点分别向房产所在地的税务机关申报纳税。

## 5. 典型例题

### 例题 1：从价计征基本计算

某企业的经营用房原值为 5,000 万元，按照当地规定允许减除 30% 按余值计税，适用税率为 1.2%。计算其应缴纳的房产税。

**解答**：

$$\text{应纳税额}=5{,}000\times(1-30\%)\times 1.2\%=5{,}000\times 70\%\times 1.2\%=42\text{（万元）}$$

### 例题 2：从租计征基本计算

某公司出租房屋 10 间，年租金收入为 30 万元，适用税率为 12%。计算其应缴纳的房产税。

**解答**：

$$\text{应纳税额}=30\times 12\%=3.6\text{（万元）}$$

### 例题 3：个人出租住房

某个人 2026 年出租住房，年租金收入为 60,000 元。计算其应缴纳的房产税。

**解答**：

个人出租住房按 4% 税率征收房产税：

$$\text{应纳税额}=60{,}000\times 4\%=2{,}400\text{（元）}$$

### 例题 4：地下建筑从价计征

某企业拥有工业用途地下建筑，房屋原价 2,000 万元，当地规定应税房产原值折算比例为 50%，房产原值减除比例为 30%。计算该地下建筑全年应纳房产税。

**解答**：

应税房产原值 = 2,000 × 50% = 1,000（万元）

$$\text{应纳税额}=1{,}000\times(1-30\%)\times 1.2\%=1{,}000\times 70\%\times 1.2\%=8.4\text{（万元）}$$

### 例题 5：投资联营房产计税

某企业以房产投资联营，参与投资利润分红、共担风险，房产原值 8,000 万元，当地减除比例 25%。该企业同时另有一处房产收取固定收入 100 万元/年不承担风险。计算该企业全年应纳房产税。

**解答**：

1. 投资联营共担风险：按房产余值计征

$$\text{应纳税额}=8{,}000\times(1-25\%)\times 1.2\%=8{,}000\times 75\%\times 1.2\%=72\text{（万元）}$$

2. 收取固定收入不承担风险：按租金收入计征

$$\text{应纳税额}=100\times 12\%=12\text{（万元）}$$

合计应纳房产税 = 72 + 12 = **84（万元）**

### 例题 6：免租期房产计税

某企业出租房产，年租金 120 万元，租赁合同约定免收租金 3 个月。房产原值 1,000 万元，当地减除比例 30%。计算该企业全年应纳房产税。

**解答**：

1. 免租期间（3 个月）由产权所有人按房产原值缴纳：

$$\text{免租期应纳税额}=1{,}000\times(1-30\%)\times 1.2\%\times\frac{3}{12}=1{,}000\times 70\%\times 1.2\%\times\frac{1}{4}=2.1\text{（万元）}$$

2. 有租金期间（9 个月）按租金收入计征：

$$\text{有租金期应纳税额}=120\times 12\%=14.4\text{（万元）}$$

合计应纳房产税 = 2.1 + 14.4 = **16.5（万元）**

## 6. 记忆口诀

### 口诀 1：房产税征税范围
> 城市县城建制镇，工矿区也要征收；农村房产不征税，四区以外不征收。

### 口诀 2：房产税税率
> 从价一点二，从租百分之十二；个人出租按四征，企事业单位出租住房四。

### 口诀 3：房产税计税依据
> 从价按余值，原值减除十至三；从租按租金，货币实物都算上。

### 口诀 4：房产原值含地价
> 一零年十二月二十一，房产原值含地价；容积率低零点五，建筑面积翻倍算。

### 口诀 5：地下建筑折算
> 工业用途五到六，商业其他七到八；地上地下相连者，视为整体来征收。

### 口诀 6：投资联营计税
> 共担风险按余值，固定收入按租金；融资租赁承租人，依照余值来缴纳。

### 口诀 7：纳税义务发生时间
> 原有经营之月起，其余都是次月缴；终止义务当月末，截止计算要记牢。

### 口诀 8：税收优惠
> 机关团体军队自用，财政拨款事业自用；寺庙公园古迹自用，个人非营业用房；医疗机构公租房，学校医院托幼校。

### 口诀 9：房产税纳税人判定
> 产权所有人纳税为原则，全民所有经营管理单位；产权出典由承典人缴纳，不在当地代管人使用人。

### 口诀 10：免租期间计税
> 免租期间产权人缴，按房产原值计征；出租期间按租金，从租计征十二个百分比。

### 口诀 11：房产原值构成
> 房屋原价为基础，地价附属要计入；中央空调电梯设备，不可随意移动附属。

### 口诀 12：房产税征收管理
> 按年征收分期缴纳，房产所在地纳税；不在同一地方分别缴，按房产坐落分别申报。
