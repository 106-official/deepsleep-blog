# 2020年真题

> CPA 2020年专业阶段考试真题汇编，按科目整理，题目与参考答案同页呈现。

## 科目试卷

- [会计](accounting/) — CPA 六科之基，难度最大、内容最多
- [审计](audit/) — 理论性强，需建立审计思维
- [财务成本管理](fm/) — 计算量大，公式密集
- [公司战略与风险管理](strategy/) — 相对简单，记忆为主
- [经济法](economic-law/) — 法条记忆 + 案例分析
- [税法](tax-law/) — 政策变动频繁，需关注新规

## 使用说明

- 每科独立成页，题型结构与真实试卷一致（单选、多选、简答/计算、综合）。
- 部分年份题目与答案分文件存储，已按题目/答案区整合到对应小节。
