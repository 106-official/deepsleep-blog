## 先建立直觉

「数据决定上限，模型只是拟合数据」。同一套架构，喂垃圾语料出垃圾模型，喂高质量语料出好模型。**预训练阶段，数据工程往往比模型结构更影响最终效果**。

可以把数据准备想成「做饭」：
- **采集** = 买菜（越多越杂越好）；
- **清洗** = 摘菜洗菜（去掉烂叶、泥沙）；
- **去重** = 别把同一棵菜炒三遍（否则模型会对它过拟合、记癖好）；
- **组织** = 切配装盘（变成模型能吃的样本格式）。

## 它解决什么问题

原始语料（网页、书籍、代码）充满噪声：HTML 标签、重复灌水、色情暴力、低质机器翻译、个人信息。直接训练会：
- 学坏（有害内容、隐私泄露）；
- 学偏（被重复文本带偏分布）；
- 学废（低质文本拉低困惑度）。

所以需要一套**可复现的清洗 + 去重流水线**。

## 核心概念

### 1. 常见语料来源

| 来源 | 特点 | 注意 |
|------|------|------|
| Common Crawl / CCNet | 海量网页，免费 | 噪声极大，需重洗 |
| Wikipedia / 百科 | 质量高、结构化 | 量小，适合提质 |
| 书籍 / 开源书库 | 长文本、连贯 | 版权风险 |
| GitHub / 代码 | 提升代码能力 | 许可证过滤 |
| 论坛 / 问答（StackExchange 等） | 高质量对话 | 去广告 |
| 自建业务语料 | 领域专精 | 脱敏！ |

### 2. 质量过滤（启发式规则）

```python
import re

def is_quality_text(text: str) -> bool:
    if not text or len(text) < 50:            # 太短丢弃
        return False
    if len(text) > 100_000:                   # 异常长（可能是拼接）截断或丢
        return False
    # 字母/符号比例：正常文本应有合理字母占比
    alpha_ratio = len(re.findall(r"[a-zA-Z一-鿿]", text)) / max(len(text), 1)
    if alpha_ratio < 0.5:                      # 像乱码/纯符号
        return False
    # 重复行比例过高（灌水）
    lines = [l for l in text.splitlines() if l.strip()]
    if lines and len(set(lines)) / len(lines) < 0.5:
        return False
    # 语言识别（用 fasttext / langdetect 过滤非目标语言）
    return True
```

### 3. 近似去重：MinHash + LSH

精确去重（哈希整篇）抓不到「改了几个字的副本」。**MinHash** 把文档压缩成「指纹集」，相似文档指纹高度重合；**LSH（局部敏感哈希）** 把这些指纹分桶，只在同桶内比对，大幅降复杂度。

```python
from datasketch import MinHash, MinHashLSH

def make_minhash(text: str, n=128):
    m = MinHash(num_perm=n)
    # 用 3-gram 作为特征（可按词或字切）
    for shingle in {text[i:i+3] for i in range(len(text)-2)}:
        m.update(shingle.encode("utf8"))
    return m

# 建索引
lsh = MinHashLSH(threshold=0.8, num_perm=128)
for doc_id, text in corpus.items():
    lsh.insert(doc_id, make_minhash(text))

# 查询重复：插入前先查，命中则判为重复
dup_ids = set()
for doc_id, text in corpus.items():
    if lsh.query(make_minhash(text)):
        dup_ids.add(doc_id)
```

> 工业级常用 **CCNet / dolma / RedPajama 的去重流水线**，原理都是「MinHash 分桶 + 相似度阈值」。本教程小规模用 `datasketch` 即可。

### 4. 用 datasets 流式清洗

```python
from datasets import load_dataset

ds = load_dataset("text", data_files="raw/*.txt", streaming=True)

def clean(example):
    t = example["text"]
    return {"text": t.strip()} if is_quality_text(t) else {"text": None}

cleaned = ds.map(clean).filter(lambda x: x["text"] is not None)
cleaned = cleaned.shuffle(seed=42, buffer_size=10_000)
cleaned.to_json("clean/corpus.jsonl", force_ascii=False)
```

### 5. 组织成预训练样本

预训练目标就是「预测下一个 token」，所以样本本质是一段**长文本**。把若干文档拼接到固定长度（如 2048），中间用特殊分隔符断开：

```python
SEQ_LEN = 2048
BOS, EOS, SEP = "<bos>", "<eos>", "\n\n"

def pack_documents(docs, seq_len=SEQ_LEN):
    """把多篇文档拼接成定长样本，文档间用 SEP 隔开。"""
    buf, out = [], []
    for d in docs:
        piece = (BOS + d + EOS + SEP)
        if len(buf) + len(piece) > seq_len:
            out.append("".join(buf)[:seq_len])
            buf = [piece]
        else:
            buf.append(piece)
    if buf:
        out.append("".join(buf)[:seq_len])
    return out
```

## 常见坑

1. **只去重整篇、不去近似重复**：同一篇文章被不同站点转载几十次，模型会反复学它、形成偏见。务必做 MinHash 近似去重。
2. **过滤太狠丢光数据**：规则阈值要「先在样本上人工看效果」再全量跑，别一上来就 `alpha_ratio < 0.8` 把中文全删了（中文 alpha 比例天然低！）。
3. **忘了脱敏**：业务/用户数据直接进训练集会泄露隐私。上线前做 PII 检测与掩码。
4. **样本不固定长度导致 padding 浪费**：预训练尽量「拼接定长」，减少无效 token。

## 小结

- 数据质量 >> 数据数量；清洗 + 去重是预训练的隐形主战场；
- 启发式过滤（长度/语言/重复行）+ MinHash/LSH 近似去重是标准组合；
- 用 `datasets` 流式处理海量语料，把文档拼成定长训练样本；
