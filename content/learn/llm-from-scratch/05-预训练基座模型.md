## 先建立直觉

预训练就是把第 4 章的「随机权重模型」，丢进第 2 章的「海量文本」里，反复做一件事：

> 给它前半句，让它猜下一个词；猜错了就反向传播改参数。

猜得越准，模型内部就越「理解」语言与世界的统计规律。这一步不需要任何标注，只要**足够多、足够干净的文本**。

## 它解决什么问题

- 把「通用知识与语言能力」压缩进参数 —— 这是后面 SFT / 对齐的地基；
- 选定训练目标 = 下一 token 预测（CLM，Causal Language Modeling），它和生成方式一致，简单且 scalable；
- 工程上要解决：显存不够（混合精度 + 分布式）、训练不稳（lr 调度 + 初始化）、太慢（数据流水线优化）。

## 核心概念

### 1. 训练目标：因果语言建模（CLM）

对长度为 T 的序列 `x`，损失是「每个位置预测下一个 token」的交叉熵均值：

```math
L = - 1/T · Σ_t log P(x_t | x_{<t}; θ)
```

PyTorch 里就是 `CrossEntropyLoss`（logits 对下一个 token 的 id）：

```python
import torch.nn as nn
loss_fn = nn.CrossEntropyLoss()

def train_step(model, idx, targets):
    logits = model(idx)                 # [B, T, vocab]
    loss = loss_fn(logits.view(-1, logits.size(-1)), targets.view(-1))
    return loss
# targets[i] = idx[i] 右移一位（即 idx 的下一个 token）
```

### 2. 最小可跑训练循环（单卡）

```python
import torch
from torch.optim import AdamW

model = MiniGPT(vocab=32000).cuda()
opt = AdamW(model.parameters(), lr=3e-4, weight_decay=0.1)
opt.zero_grad()

for step, batch in enumerate(loader):           # batch: {input_ids, labels}
    idx, targets = batch["input_ids"].cuda(), batch["labels"].cuda()
    logits = model(idx)
    loss = nn.functional.cross_entropy(logits.view(-1, logits.size(-1)), targets.view(-1))

    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 防梯度爆炸
    opt.step(); opt.zero_grad()

    if step % 50 == 0:
        print(f"step {step} loss {loss.item():.4f}")
```

### 3. 混合精度 bf16（省显存、提速、不易溢出）

```python
from torch.amp import autocast, GradScaler
# bf16 不需要 GradScaler（指数范围大，不会下溢），用 autocast 即可
with torch.autocast(device_type="cuda", dtype=torch.bfloat16):
    logits = model(idx)
    loss = nn.functional.cross_entropy(...)
loss.backward(); opt.step(); opt.zero_grad()
```

> bf16 动态范围大，**训 LLM 首选 bf16**（A100/H100/4090 都支持）。fp16 易溢出，需配合 GradScaler 且更娇气。

### 4. 学习率调度：Warmup + Cosine

```python
from torch.optim.lr_scheduler import CosineAnnealingLR
from transformers import get_cosine_schedule_with_warmup

total_steps = 100_000
sched = get_cosine_schedule_with_warmup(opt, num_warmup_steps=2000, num_training_steps=total_steps)
# 每个 step：sched.step()
```

- **Warmup**：前 2k 步 lr 线性升，避免初期大 lr 把随机权重冲坏；
- **Cosine 衰减**：后期 lr 缓慢降到接近 0，收敛更稳。

### 5. 分布式：DDP → FSDP → DeepSpeed ZeRO

| 方案 | 显存优化点 | 适用 |
|------|-----------|------|
| **DDP** | 数据并行，每卡存完整模型副本 | 单模型能放下时最快 |
| **FSDP**（PyTorch 原生） | 参数/梯度/优化器分片到各卡 | 单卡放不下 |
| **DeepSpeed ZeRO-2/3** | ZeRO-2 分片梯度+优化器；ZeRO-3 连参数也分片 | 大模型工业级 |

用 `accelerate` 一行不改代码即可切换后端：

```bash
accelerate config        # 交互式选择多卡 / FSDP / DeepSpeed
accelerate launch train.py
```

DeepSpeed 配置（`ds_zero3.json`）核心：

```json
{
  "bf16": { "enabled": "auto" },
  "zero_optimization": {
    "stage": 3,
    "offload_optimizer": { "device": "none" },
    "overlap_comm": true
  },
  "gradient_accumulation_steps": "auto",
  "train_micro_batch_size_per_gpu": "auto"
}
```

> 显存不够就用 **梯度累积**：`micro_batch=4, accum=8` 等效 `batch=32`，不增加单卡峰值显存。

### 6. 训练监控

```python
import wandb
wandb.init(project="llm-from-scratch")
# 每个 step 记录
wandb.log({"loss": loss.item(), "lr": sched.get_last_lr()[0]})
```

关注：loss 是否稳定下降、是否有尖刺（数据异常/学习率突跳）、**perplexity = exp(loss)** 是否随规模下降。

## 常见坑

1. **没做梯度裁剪**：初期 loss 尖刺会梯度爆炸，整个训练崩掉。`clip_grad_norm_=1.0` 是标配。
2. **fp16 溢出**：换 bf16，或老卡不支持 bf16 时谨慎用 fp16 + GradScaler。
3. **数据没 shuffle / 有重复 epoch**：模型记住顺序过拟合。流式数据要 `shuffle(buffer)`。
4. **ZeRO-3 下误用 `model.parameters()` 做某些操作**：分片参数在未聚合时 shape 不对，应用 `deepspeed.zero.GatheredParameters`。
5. **学习率设错数量级**：大模型 lr 常是 `1e-4 ~ 3e-4`，太大发散、太小不动。

## 小结

- 预训练目标 = 下一 token 预测（CLM），无需标注；
- 训练循环 = 前向→CE loss→反向→clip→step，配 warmup+cosine；
- 显存不够：bf16 + 梯度累积 + FSDP/DeepSpeed ZeRO；
- 用 wandb 盯 loss 与 lr；训出的就是「基座模型（Base）」；
- 下一章：用 SFT 把基座变成会按指令回答的助手。
