## 先建立直觉

应用层漏洞被突破后，攻击者往往进入的是**内网**。这一章讲"网络本身的边界与内部"：外网怎么被扫描发现、防火墙挡什么、VPN 解决什么，以及一旦进了内网，攻击者通常怎么"横向移动"。

> 重点仍是**防御视角**：理解攻击手法，是为了知道该在哪个环节布防、留什么检测日志。

## 核心概念

### 1. 端口扫描：攻击者先"摸地图"

```bash
# 仅用于你 own 的授权目标
nmap -sV -O 192.168.1.0/24     # 探活 + 服务版本 + 系统指纹
nmap -p 1-65535 target         # 全端口
```

| 端口 | 服务 | 常见风险 |
|------|------|----------|
| 22 | SSH | 弱密码/密钥泄露 |
| 3389 | RDP | 暴力破解、蓝屏漏洞 |
| 445 | SMB | 永恒之蓝类漏洞、共享泄露 |
| 6379 | Redis | 未授权访问（无密码） |

**防御**：关闭不必要的端口与服务、改默认端口只是"遮眼"、核心是**强认证 + 补丁 + 网络隔离**。

### 2. 防火墙 / ACL：边界的"门禁"

- **防火墙**：按规则放行/拒绝流量（五元组：源/目的 IP、端口、协议）；
- **ACL（访问控制列表）**：路由器/交换机上的细粒度规则；
- 关键不是"全拒"，而是**默认拒绝 + 显式最小放行**（白名单）。

### 3. VPN：把"公网"变成"内网延伸"

VPN 在公网上建加密隧道，让远程设备像连在内部一样。注意：
- VPN 不是"安全终点"——连进来后仍要**零信任**（不自动信任内网一切）；
- VPN 网关本身是高价值目标，需强认证 + 补丁。

### 4. 内网横向移动（理解为了布防）

```mermaid
flowchart LR
    A[入口机失陷] --> B[内网嗅探/扫描]
    B --> C[凭据窃取: 明文/哈希/票据]
    C --> D[利用 SMB/WinRM 横向]
    D --> E[域控拿下 → 全域失陷]
```

- **凭据窃取**：内存里的明文密码、NTLM 哈希、Kerberos 票据（黄金/白银票据）；
- **传递哈希/票据**：不解密也能借合法凭据移动；
- **域安全（AD）**：域控是内网"王座"，拿下即控全域。

**对应加固**：
- **网络分段**：把数据库、域控、办公网隔开，限制横向；
- **最小权限 + 特权账号隔离**：日常用普通账号，管理员账号单独、受控；
- **EDR + 日志集中（SIEM）**：横向移动会留痕（异常登录、陌生进程）；
- **补丁 + 关闭 SMBv1** 等老旧协议。

## 动手：在隔离实验网观察

用两台虚拟机（攻击机 Kali + 靶机 Win/Linux），在**仅主机（Host-only）网络**里：
1. `nmap` 扫靶机开放端口；
2. 看靶机防火墙默认拒绝未开端口；
3. 观察 `wireshark` 抓到的握手包——理解"为什么暴露在公网的 RDP 会被秒扫"。

> 严禁对不属于自己的网络做上述操作（见第 1 章法律红线）。

## 常见坑

1. **"内网=可信"**：零信任相反——进内网也要逐跳鉴权，否则一个点破全网破。
2. **只开防火墙不关服务**：端口没开但服务弱密码，被其他方式绕过照样失陷。
3. **域控和普通机同网段无隔离**：横向移动零成本。
4. **日志不收集**：攻击发生了也查不到"谁、何时、动了什么"。
5. **VPN 账号共享**：一个泄露，全员暴露，且无个人可追溯。

## 小结

- 网络安全是**分层边界**：扫描探活 → 防火墙/ACL 挡 → VPN 加密延伸 → 内网分段限制横向；
- 理解横向移动（凭据窃取 → SMB/WinRM → 域控）是为了在每一跳留检测与隔离；
- 核心原则：**默认拒绝、网络分段、最小权限、日志可追溯**；
