## 先建立直觉

把 Three.js 想成一个 **摄影棚**：

- **场景（Scene）** 是摄影棚本身——里面摆的所有东西（模型、灯光）都属于它；
- **相机（Camera）** 是那台摄像机——它站在某个位置、朝某个方向"看"，决定观众最终看到什么；
- **渲染器（Renderer）** 是冲印师——它每"咔嚓"一下，就把相机看到的画面算成一帧像素，画到 `<canvas>` 上。

三者缺一不可：**有场景没相机 = 没人拍；有相机没渲染器 = 拍了不洗；有渲染器没场景 = 洗一张白纸。**

## 它解决什么问题

原生 WebGL 画一个三角形，要写几百行：编译着色器、绑定缓冲、设置矩阵、处理上下文……Three.js 把这些封装成一二十行：

```js
import * as THREE from 'three';

const scene = new THREE.Scene();          // 摄影棚
const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 1000);
camera.position.z = 5;                     // 相机退后 5 个单位

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement); // 把画布挂到页面
```

> 记住：`WebGLRenderer` 默认帮你创建一块 `<canvas>`（`renderer.domElement`），你要把它挂到 DOM 上才看得到。

## 核心概念

### 1. 三件套的职责边界

| 对象 | 你通常改什么 | 你通常不改什么 |
|------|--------------|----------------|
| `Scene` | `add()` / `remove()` 物体与灯光 | 自身几乎不动 |
| `Camera` | `position`、`lookAt`、FOV | 投影矩阵内部由 Three.js 算 |
| `Renderer` | `setSize`、`setPixelRatio`、`render(scene, camera)` | 每帧只负责"洗一帧" |

### 2. 第一个完整示例（会转的立方体）

```html
<script type="module">
  import * as THREE from 'three';

  const scene = new THREE.Scene();
  scene.background = new THREE.Color(0x1a1a2e); // 深蓝背景

  // 相机：FOV 75, 宽高比, 近裁剪面 0.1, 远裁剪面 1000
  const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 1000);
  camera.position.set(0, 0, 5);

  const renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setSize(innerWidth, innerHeight);
  renderer.setPixelRatio(Math.min(devicePixelRatio, 2)); // 高清屏别超 2 倍
  document.body.appendChild(renderer.domElement);

  // 几何体 + 材质 = 网格
  const geometry = new THREE.BoxGeometry(1, 1, 1);
  const material = new THREE.MeshBasicMaterial({ color: 0xD4AF37 });
  const cube = new THREE.Mesh(geometry, material);
  scene.add(cube);

  // 坐标轴辅助：红=X 绿=Y 蓝=Z
  scene.add(new THREE.AxesHelper(3));

  // 渲染循环
  function animate() {
    requestAnimationFrame(animate);
    cube.rotation.x += 0.01;
    cube.rotation.y += 0.013;
    renderer.render(scene, camera);
  }
  animate();
</script>
```

> 注意上面用的是 `MeshBasicMaterial`——它**不受光照影响**，所以即使没打灯也能看到颜色。第 3、4 章换成 PBR 材质后，没光就黑了，到时候别慌。

### 3. 自适应窗口（几乎必写）

不处理 resize，拉伸窗口时画面会被拉伸变形：

```js
addEventListener('resize', () => {
  camera.aspect = innerWidth / innerHeight; // 改宽高比
  camera.updateProjectionMatrix();           // 必须调用，矩阵才刷新
  renderer.setSize(innerWidth, innerHeight); // 改画布尺寸
});
```

### 4. 调试三件套（开发期救命）

```js
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

scene.add(new THREE.AxesHelper(3));          // 看坐标朝向
scene.add(new THREE.GridHelper(10, 10));      // 看地面网格与比例
const controls = new OrbitControls(camera, renderer.domElement); // 鼠标拖动看物体
controls.enableDamping = true;                // 惯性，需在循环里 controls.update()
```

## 常见坑

1. **画面全黑**：八成是相机和物体在同一个点（相机没退后），或用了 PBR 材质却没打灯。先 `camera.position.z = 5` 并加 `AxesHelper`。
2. **只看到一条线 / 一个点**：物体在相机正前方太近，或 `near` 设太大把物体裁掉了。检查 `position.z` 和 `near`/`far`。
3. **物体不动**：忘记在循环里调用 `requestAnimationFrame`，或根本没调 `animate()`。
4. **拉伸变形**：没在 `resize` 里 `updateProjectionMatrix()`。
5. **`THREE is not defined`**：新版用 ES Module，`THREE` 不是全局变量，必须 `import * as THREE from 'three'`（见第 0 章环境准备）。

## 小结

- 三件套：**Scene（放东西）+ Camera（决定看哪）+ Renderer（洗成像素）**；
- 画面靠 `requestAnimationFrame` 驱动的**渲染循环**不断 `renderer.render(scene, camera)`；
- 开发期务必加 `AxesHelper` / `GridHelper` / `OrbitControls` 三大辅助；
- 下一章搞懂：`BoxGeometry` 这种几何体到底是怎么"长"出来的，以及 `Mesh = 几何体 + 材质` 这个恒等式。
