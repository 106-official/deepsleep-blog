## 先建立直觉

屏幕上的任何 3D 物体，剥到最后都是 **一堆三角形**。一个立方体有 6 个面、12 个三角形；一个球体是"足够多边"的近似。Three.js 里：

- **几何体（Geometry）** 只负责"形状"——它的顶点在哪里、怎么连成三角形；
- **材质（Material）** 只负责"表面"——这些三角形看起来是什么颜色、质感；
- 二者合在一起叫 **网格（Mesh）**，才是能塞进场景、被相机拍到的实体。

> 一句话恒等式：**`Mesh = 几何体(形状) + 材质(外表)`**。同一个几何体可以配不同材质；同一份材质也能贴不同几何体。

## 它解决什么问题

如果只能用手写顶点，建个球体要算几百个点。Three.js 提供了一大批**内置几何体**，开箱即用；同时把"顶点数据"统一成 `BufferGeometry` 这种标准结构，让你既能用现成的，也能自己捏形状。

## 核心概念

### 1. 内置几何体速查

| 几何体 | 用途 | 关键参数 |
|--------|------|----------|
| `BoxGeometry(w, h, d)` | 方块 | 长宽高、各方向分段 |
| `SphereGeometry(r, ws, hs)` | 球 | 半径、横向/纵向分段（越大越圆） |
| `PlaneGeometry(w, h)` | 平面/地面 | 宽高、分段 |
| `CylinderGeometry(rt, rb, h)` | 圆柱/圆锥 | 上/下半径、高 |
| `TorusGeometry(r, t)` | 甜甜圈 | 主半径、管半径 |
| `CapsuleGeometry(r, len)` | 胶囊 | 半径、柱段长 |
| `RingGeometry`, `TorusKnotGeometry`, `IcosahedronGeometry` | 装饰/抽象 | — |

```js
const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(1, 32, 32),   // 分段 32 → 够圆
  new THREE.MeshStandardMaterial({ color: 0x4f9 }),
);
scene.add(sphere);
```

> **分段数（segments）** 越大越平滑，但顶点越多越费性能。球用 32×32 通常够；地面平面的分段用于"顶点位移"做地形时才需要。

### 2. BufferGeometry 到底是什么

所有几何体底层都是 `BufferGeometry`——一堆**类型化数组**：

```js
const g = new THREE.BufferGeometry();
const vertices = new Float32Array([
  -1, 0, 0,   // 顶点 0 (x,y,z)
   1, 0, 0,   // 顶点 1
   0, 1, 0,   // 顶点 2
]);
g.setAttribute('position', new THREE.BufferAttribute(vertices, 3)); // 每项 3 个数
g.computeVertexNormals(); // 法线影响光照，必须算
```

| 属性 | 含义 | 每项分量 |
|------|------|----------|
| `position` | 顶点坐标 | 3（x,y,z） |
| `normal` | 法线（朝向，决定受光） | 3 |
| `uv` | 纹理坐标（0~1，贴图用） | 2 |
| `index` | 顶点索引（哪些点组成三角形） | 1（整数） |

### 3. 用索引减少顶点（省内存）

不索引时，每个三角形要 3 个独立顶点；用 `index` 可让相邻三角形**共享顶点**：

```js
const g = new THREE.BufferGeometry();
g.setAttribute('position', new THREE.BufferAttribute(new Float32Array([
  -1, -1, 0,   1, -1, 0,   -1, 1, 0,   1, 1, 0, // 4 个顶点
]), 3));
g.setIndex([0, 1, 2,  2, 1, 3]); // 两个三角形共享顶点
g.computeVertexNormals();
```

### 4. 线框与调试

```js
const mat = new THREE.MeshStandardMaterial({ color: 0x4f9, wireframe: true });
// 或单独加线框辅助
scene.add(new THREE.Mesh(geometry, new THREE.MeshBasicMaterial({ wireframe: true })));
```

> 看不清结构时，`wireframe: true` 一目了然：能直接看到分段数和三角面是怎么分布的。

## 动手写：自定义一个三角形

```js
const geo = new THREE.BufferGeometry();
geo.setAttribute('position', new THREE.BufferAttribute(new Float32Array([
  0, 1, 0,  -1, -1, 0,  1, -1, 0,
]), 3));
geo.setIndex([0, 1, 2]);
geo.computeVertexNormals();

const tri = new THREE.Mesh(
  geo,
  new THREE.MeshStandardMaterial({ color: 0xff6b6b, side: THREE.DoubleSide }),
);
scene.add(tri);
```

> `side: THREE.DoubleSide` 让单面也能从背面看到，调试时常用。`computeVertexNormals()` 不能省，否则 PBR 材质会是黑的。

## 常见坑

1. **用了 PBR 材质却黑**：忘了 `computeVertexNormals()`，或没打光（见第 4 章）。
2. **只看到背面/透明**：默认材质只渲染正面，自定义几何体顶点顺序导致法线朝内；加 `side: THREE.DoubleSide` 应急，正确做法是保证顶点**逆时针**绕序。
3. **球看起来有棱角**：分段数太低。
4. **更新顶点后画面没变**：改了 `position.array` 要设 `geometry.attributes.position.needsUpdate = true`。
5. **内存泄漏**：频繁 `new Geometry` 要记得 `geometry.dispose()`（见第 8 章）。

## 小结

- 几何体=形状，材质=外表，`Mesh` 是二者组合；
- 一切几何体底层都是 `BufferGeometry`（`position/normal/uv/index`）；
- 相邻三角形用 `index` 共享顶点省内存；
- 改顶点数据后记得 `needsUpdate = true`，自定义形状记得 `computeVertexNormals()`；
