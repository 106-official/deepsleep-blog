## 先建立直觉

材质就是给三角形"刷漆 + 抛光 + 贴膜"的那一层。它回答一个问题：**当一束光照到这个表面，观众眼睛该接收到什么颜色？**

Three.js 的材质分两大阵营：

- **基础/非物理材质**（`MeshBasicMaterial`、`MeshNormalMaterial`）：不管光照，简单直接，常用于调试或 2D 风格；
- **PBR 物理材质**（`MeshStandardMaterial`、`MeshPhysicalMaterial`）：按真实物理规律算光，受光照影响，**效果最真实**，是正式项目首选。

> 经验法则：**正式画面用 `MeshStandardMaterial`；调试、指示线、纯色 UI 用 `MeshBasicMaterial`。**

## 它解决什么问题

没有材质，几何体只是一堆"知道在哪但不知道啥样"的顶点。材质把"颜色、反光、透明、贴图"这些视觉属性集中管理，并且和光照系统对接，让同一份几何体在不同光线下呈现不同质感。

## 核心概念

### 1. MeshStandardMaterial 四件套

```js
const mat = new THREE.MeshStandardMaterial({
  color: 0xD4AF37,        // 基础反照色（被光照射后显现的颜色）
  metalness: 0.9,         // 金属度 0=绝缘体(塑料) 1=金属
  roughness: 0.3,         // 粗糙度 0=镜面 1=磨砂
  emissive: 0x000000,     // 自发光颜色（不受光照，自己亮）
});
```

| 属性 | 取值 | 视觉含义 |
|------|------|----------|
| `color` | 十六进制色 | 物体"本来的颜色"，需有光才显现 |
| `metalness` | 0~1 | 越高越像金属（高光集中、反照低） |
| `roughness` | 0~1 | 越低越亮泽如镜，越高越哑光 |
| `emissive` | 颜色 | 自身发光，常用于灯、屏幕、霓虹 |
| `emissiveIntensity` | 数值 | 自发光强度倍率 |
| `map` | 纹理 | 用贴图替换纯色（见第 7 章） |

> **金属度的反直觉点**：金属（`metalness=1`）几乎不显示 `color` 作为漫反射，它的颜色主要来自**环境反射**。所以纯金属球在一个空场景里会显得很暗——给个环境贴图（第 7 章 `RGBELoader`）就立刻"亮"了。

### 2. 透明与混合

```js
const glass = new THREE.MeshStandardMaterial({
  color: 0x88ccff,
  transparent: true,   // 必须开
  opacity: 0.4,
  roughness: 0.05,
  metalness: 0.0,
  side: THREE.DoubleSide,
});
```

> `transparent: true` 是开关；只设 `opacity` 不生效。透明物体有**渲染排序**问题（见常见坑）。

### 3. 材质分类对照

| 材质 | 受光？ | 典型用途 |
|------|--------|----------|
| `MeshBasicMaterial` | 否 | 调试色块、HUD、纯色背景 |
| `MeshNormalMaterial` | 否 | 看法线朝向（彩虹色） |
| `MeshStandardMaterial` | 是（PBR） | **正式项目默认** |
| `MeshPhysicalMaterial` | 是（PBR） | 玻璃/车漆等高级质感（继承自 Standard） |
| `MeshLambertMaterial` | 是（非 PBR） | 低成本、无高光，老式 |
| `MeshPhongMaterial` | 是（非 PBR） | 有高光，老式 |

### 4. 调试材质

```js
const debug = new THREE.MeshNormalMaterial(); // 整个物体按法线染成彩虹，看结构神器
scene.add(new THREE.Mesh(geometry, debug));
```

## 动手写：会发光的金属球 + 玻璃罩

```js
const metal = new THREE.Mesh(
  new THREE.SphereGeometry(1, 32, 32),
  new THREE.MeshStandardMaterial({
    color: 0xffd700, metalness: 1.0, roughness: 0.2, emissive: 0x332200, emissiveIntensity: 0.5,
  }),
);
scene.add(metal);

const glass = new THREE.Mesh(
  new THREE.SphereGeometry(1.4, 32, 32),
  new THREE.MeshStandardMaterial({
    color: 0xffffff, metalness: 0, roughness: 0.05,
    transparent: true, opacity: 0.25, side: THREE.DoubleSide,
  }),
);
scene.add(glass);
```

> 这段代码在**没有环境贴图**时会偏暗，属正常。第 7 章加载 HDR 环境后会立刻变得通透高级。

## 常见坑

1. **PBR 物体全黑**：第一反因永远是"没打光"或"没环境贴图"，不是材质写错。
2. **透明物体互相穿帮**：透明按距离排序，重叠时可能后画的盖前画的；可设 `depthWrite = false` 缓解，或用 `MeshPhysicalMaterial` 的透射 `transmission`（更真）。
3. **金属球一片死黑**：缺环境反射，加 `scene.environment`（第 7 章）即可。
4. **颜色偏暗/偏灰**：检查 `renderer.toneMapping` 与 `outputColorSpace`（第 4 章），旧教程的 `outputEncoding` 在新版已改名。
5. **改了材质属性不刷新**：多数属性即时生效；但换 `map` 等贴图后要 `material.needsUpdate = true`。

## 小结

- 材质决定"表面视觉"，PBR 的 `MeshStandardMaterial` 是正式首选；
- 四件套：`color / metalness / roughness / emissive`；
- 透明要 `transparent: true`；金属要环境贴图才显好；
- 调试用 `MeshNormalMaterial`（看结构）、`MeshBasicMaterial`（纯色）；
- 下一章：光照与阴影——把 PBR 材质真正"点亮"。
