## 先建立直觉

第 3 章的 PBR 材质是"油漆"，但**没光就看不见油漆**——这正是很多新手"材质写对了却全黑"的根因。

把光想成几种现实灯具：

- **环境光（AmbientLight）**：把整个房间均匀照亮，没有方向、不产生阴影。相当于"开了天花板上的散光"，只为兜底不让暗部死黑。
- **方向光（DirectionalLight）**：像太阳，光线平行、有方向，能投影。最常用。
- **点光（PointLight）**：像灯泡，从一点向四周发散，有衰减。
- **聚光（SpotLight）**：像舞台射灯，锥形光束。
- **半球光（HemisphereLight）**：天空色 + 地面色各照一半，做室外自然补光极好。

> 黄金组合：**1 盏方向光（主光+投影）+ 1 盏环境光/半球光（补光兜底）**，90% 场景够用。

## 它解决什么问题

没有光照系统，3D 场景就是"黑乎乎一团"。光照让 PBR 材质按物理规律显色、产生明暗体积感，并支持**阴影**——而阴影是"物体真的立在地上"的关键视觉证据。

## 核心概念

### 1. 常见光源对照

| 光源 | 有方向 | 投影 | 衰减 | 典型参数 |
|------|--------|------|------|----------|
| `AmbientLight` | 否 | 否 | — | `color, intensity` |
| `HemisphereLight` | 否（上下各一色） | 否 | — | `skyColor, groundColor, intensity` |
| `DirectionalLight` | 是（平行） | 是 | 否 | `position, intensity, target` |
| `PointLight` | 是（放射） | 是 | 是 | `position, intensity, distance, decay` |
| `SpotLight` | 是（锥形） | 是 | 是 | `angle, penumbra, decay` |

```js
const ambient = new THREE.AmbientLight(0xffffff, 0.4);
scene.add(ambient);

const sun = new THREE.DirectionalLight(0xffffff, 2.0);
sun.position.set(5, 10, 7);
scene.add(sun);
```

> 新版（r155+）灯光强度改用**物理单位**，`intensity` 数值比老教程大很多（方向光常用 1~3，点光可能要到几百）。老教程写 `intensity: 1` 在新版偏暗属正常。

### 2. 阴影三件套（缺一不可）

```js
// ① 渲染器开阴影
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // 软阴影

// ② 光源开投影，并配置阴影相机范围
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);  // 阴影贴图分辨率，越大越清晰越费
sun.shadow.camera.near = 1;
sun.shadow.camera.far = 50;
sun.shadow.camera.left = -15;        // 方向光的阴影是个"正交相机框"
sun.shadow.camera.right = 15;
sun.shadow.camera.top = 15;
sun.shadow.camera.bottom = -15;

// ③ 物体：谁投、谁接
cube.castShadow = true;     // 立方体投阴影
ground.receiveShadow = true; // 地面接收阴影
```

> 关键认知：**阴影是光源算出来的**。所以 `castShadow` 开在光源上，物体只是声明"我参与投影/接收"。地面必须 `receiveShadow = true` 才会显示影子。

### 3. 阴影质量调优

| 问题 | 调法 |
|------|------|
| 阴影边缘锯齿硬 | `renderer.shadowMap.type = THREE.PCFSoftShadowMap` + 提高 `mapSize` |
| 阴影有摩尔纹/条纹 | 调大 `mapSize`，或移动 `shadow.bias = -0.0005` 消除"阴影痤疮" |
| 影子被裁掉一块 | 扩大 `shadow.camera` 的 left/right/top/bottom/near/far |
| 物体浮空/黏地 | 检查物体与地面的 `y` 是否贴合；`bias` 正负试一下 |

## 动手写：带软阴影的落地场景

```js
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const sun = new THREE.DirectionalLight(0xffffff, 2.5);
sun.position.set(6, 12, 8);
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);
Object.assign(sun.shadow.camera, { near: 1, far: 60, left: -20, right: 20, top: 20, bottom: -20 });
scene.add(sun);

const ball = new THREE.Mesh(
  new THREE.SphereGeometry(1, 32, 32),
  new THREE.MeshStandardMaterial({ color: 0xff6b6b, roughness: 0.5 }),
);
ball.position.y = 1;
ball.castShadow = true;
scene.add(ball);

const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(40, 40),
  new THREE.MeshStandardMaterial({ color: 0x444444, roughness: 1 }),
);
ground.rotation.x = -Math.PI / 2; // 平面默认竖着，转 90° 当地面
ground.receiveShadow = true;
scene.add(ground);
```

## 常见坑

1. **开了 `shadowMap.enabled` 还是没影**：光源没 `castShadow`，或地面没 `receiveShadow`，或物体没 `castShadow`——三处都要查。
2. **全黑但代码没报错**：先加 `AmbientLight` 兜底；仍黑就是材质/环境贴图问题（第 3、7 章）。
3. **阴影痤疮（物体表面出现条纹状自阴影）**：`sun.shadow.bias = -0.0001 ~ -0.001`。
4. **点光/聚光没衰减**：设了 `decay`（物理衰减，新版默认 2）但 `distance=0` 表示无限远；想有范围就给 `distance`。
5. **阴影性能爆掉**：`mapSize` 别无脑 4096；多光源投影很贵，通常只让主方向光投影。

## 小结

- 灯光三件套组合：**方向光(主+影) + 环境光/半球光(补)**；
- 阴影三件套：**renderer 开 + 光源 castShadow + 物体 cast/receiveShadow**；
- 方向光阴影本质是个"正交相机框"，要调 near/far/左右上下范围；
- 锯齿用 `PCFSoftShadowMap`+ 大 `mapSize`，条纹用 `shadow.bias`；
