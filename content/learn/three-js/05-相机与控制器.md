## 先建立直觉

相机就是观众的眼睛。但 3D 里的"眼睛"比现实多两个开关：

- **视野（FOV）**：眼睛睁多大。睁太大（广角）边缘会拉伸变形，睁太小像望远镜。
- **裁剪面（near / far）**：只拍"最近到最远"之间的东西，太近或太远的一律无视。这就是第 1 章"只看到一条线/一个点"的元凶之一。

控制器（Controls）则是"观众能不能自己转头看"——`OrbitControls` 让你用鼠标拖动旋转、滚轮缩放、右键平移。

## 它解决什么问题

没有相机参数概念，你永远调不对"物体怎么这么小/这么扁/边缘变形"。`OrbitControls` 则把"让用户交互式观察 3D"这件原本要写几十行鼠标事件的事，变成了几行配置。

## 核心概念

### 1. PerspectiveCamera 四个参数

```js
const camera = new THREE.PerspectiveCamera(
  fov,                              // 视野角度(度)，常用 50~75
  aspect,                           // 宽高比 = 宽/高，必须和画布一致
  near,                             // 近裁剪面，>0，常用 0.1
  far,                              // 远裁剪面，常用 1000+
);
camera.position.set(0, 2, 6);      // 相机站在 (0,2,6)
camera.lookAt(0, 0, 0);            // 看向原点
```

| 参数 | 太小 | 太大 |
|------|------|------|
| `fov` | 像长焦，物体"凑近放大" | 广角，边缘畸变（透视夸张） |
| `near` | 容易把近处物体裁掉 | 深度精度变差（z-fighting 闪烁） |
| `far` | 远处物体消失 | 深度精度变差 |
| `aspect` | 画面被横向拉伸 | 画面被纵向压缩 |

> **z-fighting（面闪烁）**：`near` 和 `far` 差距过大时，GPU 深度缓冲精度不够，两个靠近的面会打架闪烁。经验：`near` 别小于 0.1，`far` 别设成 100000 这种离谱值。

### 2. 正交相机 OrthographicCamera

```js
const aspect = innerWidth / innerHeight;
const cam = new THREE.OrthographicCamera(-5*aspect, 5*aspect, 5, -5, 0.1, 100);
```

| 相机 | 透视 | 用途 |
|------|------|------|
| `PerspectiveCamera` | 有近大远小 | 绝大多数 3D 场景、游戏、产品展示 |
| `OrthographicCamera` | 无透视、等距 | 2.5D 游戏、工程制图、UI/小地图 |

> 正交相机没有"近大远小"，所以远处和近处一样大——做 2.5D 像素风或需要精确比例的界面时更可控。

### 3. OrbitControls 实战

```js
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;     // 惯性滑动，必开
controls.dampingFactor = 0.05;
controls.target.set(0, 0.5, 0);    // 围绕这个点旋转（默认原点）
controls.minDistance = 3;          // 最近能拉到多近
controls.maxDistance = 20;         // 最远能拉到多远
controls.maxPolarAngle = Math.PI / 2.05; // 不让相机钻到地面以下
controls.update();                 // 改 target/参数后调用一次

// 渲染循环里也要 update（开了 damping 才生效）
function animate() {
  requestAnimationFrame(animate);
  controls.update();
  renderer.render(scene, camera);
}
```

| 配置 | 作用 |
|------|------|
| `enableDamping` | 拖动有惯性，体验顺滑（需在循环 `update`） |
| `autoRotate` / `autoRotateSpeed` | 自动旋转展示 |
| `enablePan` | 是否允许右键平移 |
| `minDistance` / `maxDistance` | 限制缩放范围 |
| `maxPolarAngle` | 限制俯仰（防穿地） |

## 动手写：产品展示式相机

```js
const camera = new THREE.PerspectiveCamera(50, innerWidth / innerHeight, 0.1, 100);
camera.position.set(4, 3, 6);

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.target.set(0, 1, 0);     // 看向物体中心高度
controls.minDistance = 3;
controls.maxDistance = 15;
controls.maxPolarAngle = Math.PI / 2; // 不穿地
```

## 常见坑

1. **画面拉伸变形**：`aspect` 用了固定值或没在 `resize` 里更新（第 1 章）。
2. **物体忽大忽小漂**：`near` 设得过小（如 0.001）导致深度精度崩溃，调到 0.1 起。
3. **OrbitControls 拖不动**：忘了在循环里 `controls.update()`（开了 damping 必需），或传错 DOM 元素。
4. **相机转着转着穿模**：用 `maxPolarAngle` / `minDistance` / `maxDistance` 限制。
5. **`lookAt` 不生效**：`OrbitControls` 会每帧用 `target` 覆盖朝向；想固定朝向就别用控制器，或改 `controls.target`。

## 小结

- 透视相机四参数：`fov / aspect / near / far`；`near~far` 差距别太大防 z-fighting；
- 等距/无透视用 `OrthographicCamera`（2.5D、制图）；
- `OrbitControls` + `enableDamping` + 循环里 `update()` 是交互标配；
- 用 `minDistance/maxDistance/maxPolarAngle` 约束观察范围；
