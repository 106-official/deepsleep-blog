## 先建立直觉

真实项目里，角色、家具、建筑几乎不会用代码一个个三角形去拼——那是美术在 Blender / Maya 里做好的。Three.js 负责"把做好的模型文件读进来、摆到场景里"。

- **模型文件（glTF / GLB）**：几何体 + 材质 + 贴图 + 动画打包成一坨；
- **纹理（Texture）**：单独一张图，贴到材质上（木纹、砖墙、皮肤）；
- **环境（HDR）**：一张全景光照图，让金属/玻璃有东西可反射。

> 行业事实：**glTF 是"3D 界的 JPEG"**，是 Web 3D 的事实标准格式，优先用它（`.glb` 是二进制单文件版，体积更小、加载更快）。

## 它解决什么问题

手写几何体只能做基础形状。要真实感，就必须加载外部资产；而加载涉及异步、进度、错误处理、压缩解码、路径管理——`Loader` 系列把这些封装好，你只需关心"加载完怎么用"。

## 核心概念

### 1. 加载一个 GLB 模型

```js
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load(
  '/models/duck.glb',                 // URL
  (gltf) => {                          // 成功回调
    const model = gltf.scene;
    model.scale.set(1, 1, 1);
    scene.add(model);

    // 播放内置动画
    if (gltf.animations.length) {
      mixer = new THREE.AnimationMixer(model);
      mixer.clipAction(gltf.animations[0]).play();
    }
  },
  (xhr) => {                           // 进度回调
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  (err) => {                           // 错误回调
    console.error('模型加载失败', err);
  },
);
```

> 回调三件套：**成功 / 进度 / 失败**。生产环境务必处理失败（路径错、CORS、文件损坏都会在这里炸）。

### 2. 贴图：给材质换"皮肤"

```js
import { TextureLoader } from 'three';

const texLoader = new TextureLoader();
const woodTex = texLoader.load('/textures/wood.jpg');

const floor = new THREE.Mesh(
  new THREE.PlaneGeometry(10, 10),
  new THREE.MeshStandardMaterial({ map: woodTex, roughness: 0.8 }),
);
```

| 贴图通道 | 材质属性 | 作用 |
|----------|----------|------|
| `map` | 反照色贴图 | 基础颜色 |
| `normalMap` | 法线贴图 | 伪造凹凸细节（不增顶点） |
| `roughnessMap` | 粗糙度贴图 | 局部粗糙/光滑 |
| `metalnessMap` | 金属度贴图 | 局部金属/非金属 |
| `aoMap` | 环境光遮蔽 | 缝隙更暗，更立体 |

### 3. LoadingManager：统一管理所有加载

```js
const manager = new THREE.LoadingManager();
manager.onProgress = (url, loaded, total) => console.log(`进度 ${loaded}/${total}`);
manager.onLoad = () => console.log('全部加载完成，可以开场了');
manager.onError = (url) => console.error('失败:', url);

const loader = new GLTFLoader(manager);   // 把 manager 传进去
const texLoader = new TextureLoader(manager);
```

> 用 `LoadingManager` 你只需在一个地方写"加载中…"和"加载完成"的逻辑，而不是每个 loader 各写一遍。

### 4. DRACO 压缩 & HDR 环境

```js
// ① 模型用了 DRACO 压缩 → 必须挂解码器
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';
const draco = new DRACOLoader();
draco.setDecoderPath('https://www.gstatic.com/draco/v1/decoders/');
const loader = new GLTFLoader();
loader.setDRACOLoader(draco);

// ② HDR 环境：让金属/玻璃有反射，画面瞬间高级
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';
new RGBELoader().load('/env/studio.hdr', (hdr) => {
  hdr.mapping = THREE.EquirectangularReflectionMapping;
  scene.environment = hdr;   // 所有 PBR 材质共享这层反射
});
```

## 动手写：加载角色 + 播动画 + 加环境

```js
const manager = new THREE.LoadingManager();
manager.onLoad = () => console.log('资源就绪');

const gltfLoader = new GLTFLoader(manager);
gltfLoader.load('/models/robot.glb', (gltf) => {
  const model = gltf.scene;
  model.traverse((o) => { if (o.isMesh) { o.castShadow = true; o.receiveShadow = true; } });
  scene.add(model);
  if (gltf.animations.length) {
    mixer = new THREE.AnimationMixer(model);
    mixer.clipAction(gltf.animations[0]).play();
  }
});

new RGBELoader(manager).load('/env/studio.hdr', (hdr) => {
  hdr.mapping = THREE.EquirectangularReflectionMapping;
  scene.environment = hdr;
});

// 循环里：if (mixer) mixer.update(dt);
```

## 常见坑

1. **模型不显示 / 报错 404**：路径相对的是网页根；用 Vite 把资产放 `public/`，或确认服务器能访问该 URL。
2. **跨域（CORS）报错**：贴图/模型托管在别的域名必须带 CORS 头；本地用本地服务器（`npx serve`）而非 `file://` 打开。
3. **模型是黑的**：缺 `scene.environment` 或没打光（第 3、4 章）。金属尤其依赖环境贴图。
4. **DRACO 模型加载卡住**：忘了 `setDRACOLoader` + `setDecoderPath`。
5. **动画不动**：`mixer.update(dt)` 要在循环里调用，且 `action.play()`。
6. **`file://` 直接打开页面**：浏览器禁止本地 fetch，必须用本地服务器（`python -m http.server` 或 Vite）。

## 小结

- 优先用 **glTF / GLB**（3D 界的 JPEG）；Loader 回调 = 成功/进度/失败；
- 贴图用 `TextureLoader`，通道有 `map/normalMap/roughnessMap` 等；
- 多资产用 `LoadingManager` 统一管进度；
- 压缩模型挂 `DRACOLoader`，高级反射用 `RGBELoader` 做 `scene.environment`；
