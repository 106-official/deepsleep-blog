## 先建立直觉

"点一下这个方块让它发光"——屏幕是 2D 的，方块在 3D 里，中间差一层坐标转换。Three.js 用 **Raycaster（射线）** 解决这个问题：从相机出发，沿你点击的屏幕方向射出一条无限长的"激光"，看它先撞到哪个物体。

至于性能：3D 场景最贵的不是"算"，而是"提交"——每提交一次绘制叫一个 **Draw Call**。一千个独立方块 = 一千次提交；合并成一个 `InstancedMesh` = 一次提交。

## 它解决什么问题

- **交互**：把"用户点了屏幕哪个像素"翻译成"3D 里选中的是哪个物体"；
- **观感**：用后期处理（辉光/景深）提升质感；
- **性能**：当物体变多、帧率下跌时，用实例化、合批、资源释放等手段把帧率救回来。

## 核心概念

### 1. Raycaster 鼠标拾取

```js
import * as THREE from 'three';

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

renderer.domElement.addEventListener('pointerdown', (e) => {
  // 屏幕坐标 → 归一化设备坐标(-1~1)
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;

  raycaster.setFromCamera(pointer, camera);          // 从相机射出
  const hits = raycaster.intersectObjects(scene.children, true); // 递归检测
  if (hits.length) {
    const obj = hits[0].object;                       // 最近被击中的物体
    obj.material.emissive.set(0xffaa00);              // 高亮
    console.log('点中了', obj.name);
  }
});
```

| 步骤 | 代码 | 说明 |
|------|------|------|
| 算 NDC 坐标 | `pointer.x/y` | 把像素映射到 -1~1 |
| 设射线 | `setFromCamera(pointer, camera)` | 从相机经该点射出 |
| 求交点 | `intersectObjects(list, true)` | 返回按距离排序的命中数组 |

> `intersectObjects` 第二个参数 `true` = 递归检测子物体（组里的 mesh）。只检测某一层就传具体数组，性能更好。

### 2. 悬停高亮 + 拖拽（要点）

```js
let hovered = null;
renderer.domElement.addEventListener('pointermove', (e) => {
  pointer.x = (e.clientX / innerWidth) * 2 - 1;
  pointer.y = -(e.clientY / innerHeight) * 2 + 1;
  raycaster.setFromCamera(pointer, camera);
  const hit = raycaster.intersectObjects(pickables, false)[0];
  if (hit?.object !== hovered) {
    if (hovered) hovered.material.emissive.set(0x000000); // 取消旧高亮
    hovered = hit?.object || null;
    if (hovered) hovered.material.emissive.set(0x335577); // 新高亮
  }
});
```

> 拖拽一般用 `DragControls`（addons 自带），或自己结合射线 + 平面投影实现；简单拾取用上面这套足矣。

### 3. 后期处理：辉光（Bloom）

```js
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));
const bloom = new UnrealBloomPass(
  new THREE.Vector2(innerWidth, innerHeight), 0.6, 0.4, 0.85, // strength, radius, threshold
);
composer.addPass(bloom);

// 循环里用 composer.render() 代替 renderer.render()
// resize 时：composer.setSize(innerWidth, innerHeight)
```

> 注意：开了 `EffectComposer` 后，渲染要调 `composer.render()` 而非 `renderer.render()`，否则后期不生效。

### 4. 性能优化清单

| 手段 | 何时用 | 做法 |
|------|--------|------|
| `InstancedMesh` | 大量相同几何体（树/星/子弹） | 一次提交渲染 N 个实例 |
| 合批 `BufferGeometryUtils.mergeGeometries` | 多静态物体拼一起 | 减少 Draw Call |
| 降 `pixelRatio` | 高分屏掉帧 | `setPixelRatio(min(dpr, 2))` |
| `frustumCulled` | 默认开即可 | 视锥外不渲染 |
| 纹理压缩 / 降尺寸 | 贴图过大 | 用 KTX2 / 合理分辨率 |
| `geometry.dispose()` + `material.dispose()` | 切换/删除物体 | 释放 GPU 内存，防泄漏 |
| 限光源投影数 | 多阴影光源 | 通常只主光投影 |

```js
// InstancedMesh：1000 个方块一次提交
const geo = new THREE.BoxGeometry(0.2, 0.2, 0.2);
const mat = new THREE.MeshStandardMaterial({ color: 0x4f9 });
const mesh = new THREE.InstancedMesh(geo, mat, 1000);
const dummy = new THREE.Object3D();
for (let i = 0; i < 1000; i++) {
  dummy.position.set((Math.random()-0.5)*10, (Math.random()-0.5)*10, (Math.random()-0.5)*10);
  dummy.updateMatrix();
  mesh.setMatrixAt(i, dummy.matrix);
}
scene.add(mesh);
```

```js
// 释放资源，避免 GPU 内存泄漏
function removeMesh(m) {
  scene.remove(m);
  m.geometry.dispose();
  m.material.dispose();   // 若 material.map 存在也要 .dispose()
}
```

## 常见坑

1. **点不中物体**：NDC 坐标算错（常见漏了 `*-1` 或用了 `offsetX` 没算 canvas 偏移）；确认 `setFromCamera` 用的是当前相机。
2. **后期处理黑屏/不生效**：循环里还在调 `renderer.render()`，应改 `composer.render()`；并确认 `composer.setSize` 已设置。
3. **帧率越来越低（内存泄漏）**：动态删除物体没 `dispose()` 几何体/材质。
4. **InstancedMesh 不显示**：忘了 `setMatrixAt` 后设 `instanceMatrix.needsUpdate = true`（首次也要）。
5. **拖拽受 OrbitControls 干扰**：拖拽时临时 `controls.enabled = false`，结束再开。

## 小结

- 鼠标拾取 = 算 NDC 坐标 → `Raycaster.setFromCamera` → `intersectObjects`；
- 辉光等后期用 `EffectComposer` + `RenderPass` + `UnrealBloomPass`，渲染改 `composer.render()`；
- 性能第一招是减 **Draw Call**：`InstancedMesh` / 合批；
- 动态移除物体务必 `dispose()` 几何与材质，防 GPU 泄漏；
- 至此，你已具备"搭场景 → 打光 → 动画 → 加载资产 → 交互 → 优化"的完整闭环。去读官方 [examples](https://threejs.org/examples/) 抄活学活用吧。
