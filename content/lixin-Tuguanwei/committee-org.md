## 组织架构

图管委设主任【1】名、副主任【2】名，下设若干职能部门，分工协作：

| 部门 | 职责 |
| --- | --- |
| 秘书处 | 会议记录、文书与排班协调 |
| 读者服务部 | 值班、咨询引导、意见收集 |
| 宣传推广部 | 活动策划、新媒体运营 |
| 馆藏协管部 | 上架协助、破损巡查、秩序维护 |
| 【可增部门】 | 【职责说明】 |

### 换届与招募

- 每年【月份】进行换届选举，面向全校招募新成员
- 招新对象：【年级 / 专业要求】
- 报名方式：见「联系我们」或在馆内扫码

> 部门设置可根据实际需要调整，欢迎在问答中提出你的建议。
