## 概率的运算

### 第 1 题

**题源：2016-2021 七套卷 · 选择题**

对于任意两个事件 $A, B$，必有 $P(A-B)=$ （　　）

- (A) $P(A)-P(B)$
- (B) $P(A)-P(B)+P(AB)$
- (C) $P(A)+P(B)$
- (D) $P(A)-P(AB)$

> 答案：D
>
> 解析：$A - B = A\bar{B}$，而 $A = AB \cup A\bar{B}$ 且 $AB$ 与 $A\bar{B}$ 互斥，故 $P(A) = P(AB) + P(A\bar{B}) = P(AB) + P(A-B)$，所以 $P(A-B) = P(A) - P(AB)$。

### 第 2 题

**题源：2016-2021 七套卷 · 选择题**

若 $A$ 与 $B$ 互为对立事件，则下式成立的是（　　）

- (A) $P(A\cup B) = \Omega$
- (B) $P(AB) = P(A)P(B)$
- (C) $P(A) = 1 - P(B)$
- (D) $P(AB) = \phi$

> 答案：C
>
> 解析：对立事件的定义是 $A \cup B = \Omega$ 且 $AB = \phi$，故 $P(A) + P(B) = 1$，即 $P(A) = 1 - P(B)$。(A) 的写法不规范（概率值应为数值而非样本空间），(D) 同理。

### 第 3 题

**题源：2016-2021 七套卷 · 选择题**

某种动物活到 25 岁以上的概率为 $0.8$，活到 30 岁以上的概率为 $0.4$，则现年 25 岁的这种动物活到 30 岁以上的概率是（　　）

- (A) $0.76$
- (B) $0.4$
- (C) $0.32$
- (D) $0.5$

> 答案：D
>
> 解析：设 $A$ = "活到 25 岁以上"，$B$ = "活到 30 岁以上"。显然 $B \subset A$，所求为条件概率 $P(B|A) = \dfrac{P(AB)}{P(A)} = \dfrac{P(B)}{P(A)} = \dfrac{0.4}{0.8} = 0.5$。

### 第 4 题

**题源：2016-2021 七套卷 · 选择题**

$A, B, C$ 为任意三个随机事件，则事件 $(A-B)\cup(B-C)=$ （　　）

- (A) $A-C$
- (B) $A\cup(B-C)$
- (C) $(A\cup B)-C$
- (D) $(A\cup B)-BC$

> 答案：C
>
> 解析：利用集合运算规则，$(A-B)\cup(B-C) = A\bar{B} \cup B\bar{C}$。注意到 $(A\cup B)-C = (A\cup B)\cap \bar{C} = A\bar{C} \cup B\bar{C}}$。通过文氏图验证可知答案为 C。

### 第 5 题

**题源：2016-2021 七套卷 · 选择题**

设 $A, B, C$ 为任意三个随机事件，$A, B, C$ 中至少有两个发生的事件是（　　）

- (A) $AB\bar{C} \cup A\bar{B}C \cup \bar{A}BC$
- (B) $AB \cup AC \cup BC$
- (C) $ABC$
- (D) $\bar{A} \cup \bar{B} \cup \bar{C}$

> 答案：B
>
> 解析："至少两个发生" = "恰有两个发生" + "三个都发生"。$AB$ 表示 $A$ 与 $B$ 同时发生（$C$ 可发生也可不发生），同理 $AC$、$BC$。三者之并即为"至少两个发生"。(A) 只表示"恰好两个发生"，(C) 只是"三个都发生"。

### 第 6 题

**题源：2016-2021 七套卷 · 选择题**

对于任意两个事件 $A$ 与 $B$，则 $P(A-B)=$ ______.

- A. $P(A)-P(B)$
- B. $\overline{P(A)-P(B)} + P(AB)$
- C. $P(A)-P(AB)$
- D. $P(A)+P(\bar{B})-P(A\bar{B})$

> 答案：C
>
> 解析：同第 1 题，$P(A-B) = P(A\bar{B}) = P(A) - P(AB)$。

### 第 7 题

**题源：2016-2021 七套卷 · 选择题**

设 $A$、$B$ 为任意两个随机事件，则下列选项中错误的是 ______.

- A. $(A+B)-B = A$
- B. $A-B = A-AB$
- C. $(A-B)+B = A+B$
- D. $AB + \bar{A}B = A$

> 答案：A
>
> 解析：
> - A 错误：$(A+B)-B = (A\cup B) \cap \bar{B} = A\bar{B} \neq A$（除非 $A$ 与 $B$ 互斥）。
> - B 正确：$A-AB = A\cap \overline{AB} = A\cap(\bar{A}\cup\bar{B}) = A\bar{B} = A-B$。
> - C 正确：$(A-B)+B = A\bar{B} \cup B = A\cup B$。
> - D 正确：$AB + \bar{A}B = (A \cup \bar{A})B = \Omega B = B \neq A$（一般情况下）。
>
> 实际上 D 也是错误的——但 A 是"最明显"的错误答案。如果单选则选 A。
