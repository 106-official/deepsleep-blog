## 已知概率密度求概率

### 第 1 题

**题源：2016-2021 七套卷 · 选择题**

设随机变量 $X, Y$ 相互独立，且 $X \sim N(2,1)$，$Y \sim N(1,1)$，则（　　）

- (A) $P\{X-Y \le 1\} = \dfrac{1}{2}$
- (B) $P\{X-Y \le 0\} = \dfrac{1}{2}$
- (C) $P\{X+Y \le 1\} = \dfrac{1}{2}$
- (D) $P\{X+Y \le 0\} = \dfrac{1}{2}$

> 答案：A
>
> 解析：由 $X \sim N(2,1)$，$Y \sim N(1,1)$ 且独立，得 $X - Y \sim N(2-1, 1+1) = N(1, 2)$。
>
> $P\{X-Y \le 1\} = P\left\{\dfrac{(X-Y)-1}{\sqrt{2}} \le 0\right\} = \Phi(0) = \dfrac{1}{2}$。

### 第 2 题

**题源：2016-2021 七套卷 · 选择题**

设二维随机变量 $(X,Y)$ 的概率密度为

$$f(x,y) = \begin{cases} \dfrac{1}{4}, & 0 < x < 2,\, 0 < y < 2 \\ 0, & \text{其他} \end{cases}$$

则 $P\{0 < X < 1,\, 0 < Y < 1\} =$ （　　）

- (A) $\dfrac{1}{4}$
- (B) $\dfrac{1}{2}$
- (C) $\dfrac{3}{4}$
- (D) $1$

> 答案：A
>
> 解析：$(X,Y)$ 服从区域 $[0,2]\times[0,2]$ 上的均匀分布。
>
> $P\{0<X<1,\, 0<Y<1\} = \displaystyle\int_0^1\int_0^1 \frac{1}{4}\,dy\,dx = \frac{1}{4} \times 1 \times 1 = \frac{1}{4}$。
