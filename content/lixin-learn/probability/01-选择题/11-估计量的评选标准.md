## 估计量的评选标准

### 第 1 题

**题源：2016-2021 七套卷 · 选择题**

设总体 $X$ 的分布中含有未知参数 $\theta$，$X_1, X_2, \cdots, X_n$ 为其简单随机样本，$\hat{\theta}_1 = \hat{\theta}_1(X_1, X_2, \cdots, X_n)$ 和 $\hat{\theta}_2 = \hat{\theta}_2(X_1, X_2, \cdots, X_n)$ 是参数 $\theta$ 的两个无偏估计，若对任意的样本容量 $n$，若 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ 有效的估计量，则必有（　　）

- (A) $E(\hat{\theta}_1) > E(\hat{\theta}_2)$
- (B) $E(\hat{\theta}_1) < E(\hat{\theta}_2)$
- (C) $D(\hat{\theta}_1) > D(\hat{\theta}_2)$
- (D) $D(\hat{\theta}_1) < D(\hat{\theta}_2)$

> 答案：D
>
> 解析：**有效性**比较的是无偏估计的方差。$\hat{\theta}_1$ 比 $\hat{\theta}_2$ 有效 $\Leftrightarrow D(\hat{\theta}_1) < D(\hat{\theta}_2)$（方差越小越有效）。两者同为无偏估计时 $E(\hat{\theta}_1) = E(\hat{\theta}_2) = \theta$。

### 第 2 题

**题源：2016-2021 七套卷 · 选择题**

设总体未知参数 $\theta$ 的估计量 $\hat{\theta}$ 满足 $E(\hat{\theta}) \neq \theta$，则 $\hat{\theta}$ 一定是 $\theta$ 的（　　）

- (A) 极大似然估计
- (B) 矩估计
- (C) 有偏估计
- (D) 有效估计

> 答案：C
>
> 解析：**无偏性**定义：$E(\hat{\theta}) = \theta$。若 $E(\hat{\theta}) \neq \theta$，则 $\hat{\theta}$ 是**有偏估计**（biased estimator）。

### 第 3 题

**题源：2016-2021 七套卷 · 选择题**

设 $\hat{\theta}_1, \hat{\theta}_2$ 是参数 $\theta$ 的两个相互独立的无偏估计量，且 $D(\hat{\theta}_1) = 2D(\hat{\theta}_2) > 0$，若 $\hat{\theta} = k_1\hat{\theta}_1 + k_2\hat{\theta}_2$ 也是 $\theta$ 的无偏估计量，则下列四个估计量中方差最小的是（　　）

- (A) $\dfrac{1}{2}\hat{\theta}_1 + \dfrac{1}{2}\hat{\theta}_2$
- (B) $\dfrac{2}{3}\hat{\theta}_1 + \dfrac{1}{3}\hat{\theta}_2$
- (C) $\dfrac{1}{3}\hat{\theta}_1 + \dfrac{2}{3}\hat{\theta}_2$
- (D) $\dfrac{1}{4}\hat{\theta}_1 + \dfrac{3}{4}\hat{\theta}_2$

> 答案：C
>
> 解析：无偏条件：$E(\hat{\theta}) = k_1\theta + k_2\theta = (k_1+k_2)\theta = \theta$，故 $k_1 + k_2 = 1$。
>
> 方差：$D(\hat{\theta}) = k_1^2 D(\hat{\theta}_1) + k_2^2 D(\hat{\theta}_2) = k_1^2 \cdot 2\sigma^2 + k_2^2 \cdot \sigma^2 = \sigma^2(2k_1^2 + k_2^2)$。
>
> 令 $k_2 = 1 - k_1$，则 $f(k_1) = 2k_1^2 + (1-k_1)^2 = 3k_1^2 - 2k_1 + 1$。
>
> 求导：$f' = 6k_1 - 2 = 0 \Rightarrow k_1 = \dfrac{1}{3}$，此时 $k_2 = \dfrac{2}{3}$，即选项 C。
