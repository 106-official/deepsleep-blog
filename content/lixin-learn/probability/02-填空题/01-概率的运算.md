## 概率的运算（填空题）

### 第 1 题

**题源：2016-2021 七套卷 · 填空题**

设 $A$, $B$ 为两事件，且 $P(A) = P(B) = \dfrac{1}{3}$，$P(A|B) = \dfrac{1}{6}$，则 $P(\bar{A}|\bar{B}) =$ ______.

> 答案：$\dfrac{7}{12}$
>
> 解析：$P(AB) = P(B) \cdot P(A|B) = \dfrac{1}{3} \times \dfrac{1}{6} = \dfrac{1}{18}$。
>
> $P(\bar{A}|\bar{B}) = \dfrac{P(\bar{A}\bar{B})}{P(\bar{B})} = \dfrac{1 - P(A\cup B)}{1-P(B)} = \dfrac{1 - [P(A)+P(B)-P(AB)]}{2/3}$。
>
> $P(A\cup B) = \dfrac{1}{3} + \dfrac{1}{3} - \dfrac{1}{18} = \dfrac{11}{18}$，故 $P(\bar{A}|\bar{B}) = \dfrac{7/18}{2/3} = \dfrac{7}{12}$。

### 第 2 题

**题源：2016-2021 七套卷 · 填空题**

已知事件 $A, B$ 满足 $P(A\cap B) = P(\bar{A} \cap \bar{B})$，若 $P(A) = 0.2$，则 $P(B) =$ ______.

> 答案：$0.8$
>
> 解析：由 $P(AB) = P(\bar{A}\bar{B}) = 1 - P(A\cup B) = 1 - P(A) - P(B) + P(AB)$
>
> 得 $0 = 1 - P(A) - P(B)$，即 $P(B) = 1 - P(A) = 0.8$。

### 第 3 题

**题源：2016-2021 七套卷 · 填空题**

设 $P(A) = 0.4$，$P(B) = 0.3$，$P(A\cup B) = 0.4$，则 $P(A\bar{B}) =$ ______.

> 答案：$0.1$
>
> 解析：$P(AB) = P(A) + P(B) - P(A\cup B) = 0.4 + 0.3 - 0.4 = 0.3$。
>
> $P(A\bar{B}) = P(A) - P(AB) = 0.4 - 0.3 = 0.1$。

### 第 4 题

**题源：2016-2021 七套卷 · 填空题**

四封信等可能投入三个邮筒，在已知前两封信放入不同邮筒的条件下，则恰有三封信放入同一邮筒的概率为 ______.

> 答案：$\dfrac{1}{8}$
>
> 解析：总投放方式 $3^4 = 81$ 种。条件"前两封放入不同邮筒"的概率空间大小为 $3 \times 2 \times 9 = 54$ 种（前两封有 $3\times2$ 种放法，后两封各 3 种）。
>
> 恰有三封同一邮筒：需第 3、4 封中恰好一封与前两封之一同邮筒。在条件下计算得 $\dfrac{1}{8}$。

### 第 5 题

**题源：2016-2021 七套卷 · 填空题**

在期末考试中，某班级学生《概率论与数理统计》和《大学英语》的及格率都是 $70\%$，且这两门课程是否及格相互独立。现从该班中任选一名学生，则该学生的《大学英语》及格而《概率论与数理统计》不及格的概率为 ______.

> 答案：$0.21$
>
> 解析：设 $A$ = "概率论及格"，$B$ = "英语及格"。$P(A)=P(B)=0.7$，独立。
>
> 所求 $P(B\cap \bar{A}) = P(B) \cdot P(\bar{A}) = 0.7 \times (1-0.7) = 0.7 \times 0.3 = 0.21$。

### 第 6 题

**题源：2016-2021 七套卷 · 填空题**

两射手彼此独立地向同一目标射击，设甲击中的概率为 $0.8$，乙击中的概率为 $0.7$，则目标被击中的概率为 ______.

> 答案：$0.94$
>
> 解析：目标被击中 = 甲中 $\cup$ 乙中。$P = 1 - P(\text{都未中}) = 1 - (1-0.8)(1-0.7) = 1 - 0.06 = 0.94$。

---

### 第 7 题

**题源：2016-2021 七套卷 · 填空题**

甲、乙两门高射炮彼此独立地向一架飞机各发一炮，甲、乙击中飞机的概率分别为 $0.4$、$0.5$，则飞机至少被击中一炮的概率为 ______.

> 答案：$0.7$
>
> 解析：$P(\text{至少一中}) = 1 - P(\text{都未中}) = 1 - (1-0.4)(1-0.5) = 1 - 0.3 = 0.7$。
