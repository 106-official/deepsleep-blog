## 已知概率密度求参数（填空题）

### 第 1 题

**题源：2016-2021 七套卷 · 填空题**

设随机变量 $X$ 的概率密度为

$$f(x) = \begin{cases} x+c, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$$

则常数 $c =$ ______.

> 答案：$\dfrac{1}{2}$
>
> 解析：归一化条件 $\displaystyle\int_{-\infty}^{+\infty} f(x)\,dx = \int_0^1 (x+c)\,dx = \left[\dfrac{x^2}{2} + cx\right]_0^1 = \dfrac{1}{2} + c = 1$，故 $c = \dfrac{1}{2}$。

### 第 2 题

**题源：2016-2021 七套卷 · 填空题**

设随机变量 $X$ 服从区间 $[2, \theta]$ 上的均匀分布，且概率密度

$$f(x) = \begin{cases} \dfrac{1}{4}, & 2 \le x \le \theta \\ 0, & \text{其他} \end{cases}$$

则 $\theta =$ ______.

> 答案：$6$
>
> 解析：均匀分布 $U[a,b]$ 的密度为 $\dfrac{1}{b-a}$。此处 $\dfrac{1}{\theta - 2} = \dfrac{1}{4}$，故 $\theta - 2 = 4$，得 $\theta = 6$。

### 第 3 题

**题源：2016-2021 七套卷 · 填空题**

设连续型随机变量 $X$ 的密度函数为

$$f(x) = \begin{cases} kx+1, & 0 < x < 2 \\ 0, & \text{其它} \end{cases}$$

则 $k =$ ______.

> 答案：$-\dfrac{1}{2}$
>
> 解析：$\displaystyle\int_0^2 (kx+1)\,dx = \left[\dfrac{kx^2}{2} + x\right]_0^2 = 2k + 2 = 1$，故 $k = -\dfrac{1}{2}$。

---

### 第 4 题

**题源：2016-2021 七套卷 · 填空题**

设连续型随机变量 $X$ 的密度函数为

$$f(x) = \begin{cases} \dfrac{A}{\sqrt{1-x^2}}, & -1 < x < 1 \\ 0, & \text{其他} \end{cases}$$

则 $A =$ ______.

> 答案：$\dfrac{1}{\pi}$
>
> 解析：$\displaystyle\int_{-1}^{1} \frac{A}{\sqrt{1-x^2}}\,dx = A \cdot [\arcsin x]_{-1}^{1} = A \cdot \left(\dfrac{\pi}{2} - (-\dfrac{\pi}{2})\right) = A\pi = 1$，故 $A = \dfrac{1}{\pi}$。
>
> （此分布为**反正弦分布（Arcsine Distribution）**）

### 第 5 题

**题源：2016-2021 七套卷 · 填空题**

设随机变量 $X$ 的概率分布为 $P\{X=k\} = \theta(1-\theta)^{k-1}$ ($k=1,2,\cdots$)，其中 $0 < \theta < 1$。若 $P\{X \le 2\} = \dfrac{5}{9}$，则 $P\{X=3\} =$ ______.

> 答案：$\dfrac{4}{27}$
>
> 解析：这是**几何分布** $Geometric(\theta)$。
>
> $P(X \le 2) = P(X=1) + P(X=2) = \theta + \theta(1-\theta) = \theta(2-\theta) = \dfrac{5}{9}$。
>
> 解方程：$9\theta(2-\theta) = 5 \Rightarrow 18\theta - 9\theta^2 = 5 \Rightarrow 9\theta^2 - 18\theta + 5 = 0$。
>
> $(3\theta-1)(3\theta-5)=0$，因 $\theta<1$ 故 $\theta=\dfrac{1}{3}$。
>
> $P(X=3) = \dfrac{1}{3}\left(\dfrac{2}{3}\right)^2 = \dfrac{4}{27}$。
