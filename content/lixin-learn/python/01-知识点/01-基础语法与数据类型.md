## 基础语法与数据类型

本页整理 Python 基础语法、变量与标识符、字符串、运算符、常用内置函数与输入输出，对应教材第 1–3 章。

### 一、Python 语言特点与历史

- 1989 年，荷兰人吉多·范罗苏姆（Guido van Rossum）创立 Python。
- 特点：简单、易学、免费、开源；**解释型语言**；可移植；代码规范；面向对象；胶水语言；丰富的库；动态类型。
- 常见辨析：
  - Python 是解释性语言。（✓）
  - "变量必须先声明后使用"是 Python 的特点。（✗ —— Python 变量无需声明，动态类型；但这不是它的"特点"表述，且动态类型才是特性）
  - Python 依赖平台。（✗ —— 跨平台）
  - Python 语法简洁、类库丰富、支持中文。（✓）

### 二、变量命名规则（保留字）

标识符（变量名）命名规则：

1. 由 **字母、数字、下划线 `_`** 组成；
2. **不能以数字开头**；
3. **不能是 Python 保留字**；
4. **严格区分大小写**。

Python 保留字（关键字）：

```
False None True and as assert async await break class continue
def del elif else except finally for from global if import in is
lambda nonlocal not or pass raise return try while with yield
```

示例辨析：

- `a-name` 不符合命名规则（含 `-`）。（✓）
- `2_abc` 不符合命名规则（以数字开头）。（✓）
- `_abc` 符合命名规则。（✓）
- `True` 不能作为变量名（是保留字）；但 `true` 可以（不建议）。（✓ 对 True 而言）
- `'ID'`（带引号）不是合法变量名。（✓）

### 三、书写格式

- Python **不允许在一行写两条语句**（书 P14 允许用分号分隔，但不建议）：`a=5;b="python"` 不推荐。
- Python 用严格的**缩进**表示程序框架，而非 `{}`。
- 注释以 `#` 开头，不会被解释器执行（"注释语句不会被解释器过滤掉"为 ✗，注释本就被忽略）。
- 快捷键：新建 `Ctrl+N`；缩进 `Ctrl+]`；取消缩进 `Ctrl+[`；注释 `Alt+3`；取消注释 `Alt+4`。

### 四、数据类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| `int` | 整数（可无限大） | `520` |
| `float` | 浮点数（含小数） | `3.14` |
| `bool` | 布尔 `True` / `False` | `True` |
| `str` | 字符串（字符序列） | `'abc'` |

- 整数没有长度限制，可计算几百位大整数。（✓）
- 布尔值：`False`、数值 `0`、`None`、空字符串、空列表/元组/字典/集合的布尔值为 `False`；其余（如 `16`、`'a'`）为 `True`。
- 关系运算符优先级 **高于** 逻辑运算符。（✓）

### 五、字符串

- 界定：单引号 `'`、双引号 `"`、三引号 `''' '''` / `""" """`（三引号可跨多行）。
- 单双引号界定的字符串必须在一行。
- 转义字符：反斜杠 `\` + 功能首字母，如 `\n` 换行、`\r` 回车、`\t` 制表。
  - 辨析：`\r` 表示**回车符**（非退格符）。（✓）
  - 输出含单/双引号的字符串，除转义外，也可用外层另一种引号包裹：`print("'老骥伏枥'")`。
- 原始字符串：前缀 `r` / `R`，如 `r'C:\temp'`，不转义。
- 基本操作：

```python
s = "abcdefghijklmn"
print(s[3:13:2])   # dfhjl  （从 d 起到索引13止，步长2，左闭右开）
print(s[3::2])      # dfhjln （省略 end，含到末尾）
print(s[3])         # d
print(len(s))       # 14
```

- 索引：正向 `0 ~ n-1`，负向 `-1 ~ -n`。
- 切片 `<string>[start:end:step]`：**左闭右开**；`step` 为负时从后往前。
- 拼接 `+`、复制 `*`、大小写 `s.lower()` / `s.upper()`、长度 `len(s)`。

### 六、常用运算符与优先级

算术、赋值（`=`）、关系、逻辑运算符优先级（由低到高）：

```
or  <  and  <  not  <  关系运算符(==, <, ...)  <  算术(+ - * / // %)  <  幂(**)
```

- `i += 1` 等价于 `i = i + 1`。（✓）
- 条件表达式 `a == b and b == c` 等价于 `a == b == c`。（✓）
- `-1 <= x <= 1` 在 Python 中合法（链式比较）。（✓）
- `'a' > 'A'` 为 `True`（按 ASCII：小写 97–122 > 大写 65–90）。（✓）

### 七、输入输出与常用内置函数

```python
x = input("提示")        # 输入，类型恒为 str
print(value, sep=' ', end='\n')   # sep 间隔，end 结尾
int(x)  float(x)  str(x)           # 类型转换
eval("3.14+10")          # 求字符串表达式的值 -> 13.14
ord('a')  chr(97)        # 字符 <-> ASCII
bool(x)                   # 求布尔值
pow(2, 5)                 # 乘方 = 32
divmod(a, b)              # 返回 (商, 余数)
round(2.5)                # 圆整（四舍六入五留双）
```

`math` 模块：

```python
import math
print(math.pi * math.sqrt(25))     # 用 math. 前缀
# 或： from math import *
```

### 八、对象布尔值小结

```python
if 2:
    print(True)     # 输出 True（条件表达式 2 为真）
else:
    print(False)
```

> 任何对象的布尔值可用 `bool()` 求得；`0`、空容器、`None`、`False` 为假，其余为真。
