## 流程控制

本页整理分支结构（`if` / `if-else` / `if-elif-else`）、循环结构（`while` / `for-in`）、`break` / `continue`、以及异常处理 `try-except-finally`。

### 一、三种基本结构

任何算法都可由 **顺序、选择（分支）、循环** 三种基本结构组合而成。（✓）

### 二、分支结构

- 单分支：`if 条件: 条件执行体`
- 双分支：`if 条件: ... else: ...`
- 多分支：`if ... elif ... elif ... else: ...`
- 嵌套 `if` 与 `if-elif-else` 均可实现多重选择。
  - 辨析："多分支决策**必须**采用嵌套的 if-else 语句"。（✗ —— if-elif-else 即可）
- `try` / `in` 等保留字**不用于**分支结构。（✓）

```python
x = int(input())
if -10 <= x < 0:
    y = 2*x**3 + 4*x**2 + 3
    print(y)
elif 0 <= x < 6:
    y = x + 14
    print(y)
elif 6 <= x <= 10:
    y = 6*x
    print(y)
else:
    print('ERROR')
```

> 关系运算符优先级高于逻辑运算符；链式比较 `a <= x < b` 等价于 `a <= x and x < b`。

### 三、循环结构

**while 循环**（条件循环）：

```python
while 条件表达式:
    循环体
```

**for-in 循环**（遍历循环）：

```python
for 变量 in 可迭代对象:
    循环体
```

- 遍历结构可以是字符串、`range()`、列表、元组、字典、集合、文件等。（✓）
- `while True`（死循环）中通过 `break` 终止，称为**半路循环**。"Python 不允许使用 while True"为 ✗。
- `while` / `for` 均可搭配 `else`：循环**正常结束**（非 `break` 跳出）后执行 `else` 块。（✓）

**break 与 continue**：

- `break`：跳出**当前层** `for` / `while` 循环，之后从循环后继续执行。（✓）
- `continue`：结束**本次**循环，进入下一轮条件判断。（✓）
- "每个 continue 只能跳出当前层次的循环"。（✓）；"continue 结束整个循环过程"为 ✗。

```python
for a in b:
    if 条件:
        break          # 跳出 for 循环
```

- 循环内可嵌套分支，分支内也可嵌套循环。（✓）
- `for i in len(range(1,3)):` 语法错误（`len()` 返回整数，不能用 `in` 遍历整数）。（✗）

### 四、异常处理

```python
try:
    可能出错的语句
except 异常类型:
    处理语句
else:
    无异常时执行
finally:
    始终执行
```

- `finally` 中的代码段**始终**被执行。（✓）
- 一个 `try` 后接**一个或多个** `except` 块，或 `finally` 块；`try` 必须与 `except` 或 `finally` 一起使用。（✓ —— 不能单独 `try`）
- 一个 `try` 后接**一个或多个** `finally` 块为 ✗（只能一个 `finally`）。
- `except` 对应语句块在 **try 中出现异常时**执行。（✓）
- 合理用法：在输入判断及关键代码中使用，但**不滥用**。（✓）

```python
score = input()
if score.isalpha():
    print("invalid literal for int() with base 10: '%s'" % score)
else:
    score = int(score)
    if 0 <= score <= 100:
        print("分数为：%d" % score)
    else:
        print("分数不正确！")
```

### 五、pass 语句

`pass` 用在语法上需要语句但暂时不想写逻辑的地方，仅占位、什么都不做。（✓）
