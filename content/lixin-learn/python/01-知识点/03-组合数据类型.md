## 组合数据类型：列表 / 字典 / 元组 / 集合

本页整理四种组合数据类型的异同、创建方式、常用操作与生成式，对应教材第 4 章（列表、字典、元组、集合）。

### 零、总体理解

| 类型 | 符号 | 能否重复 | 是否有序 | 是否可变 | 生成式 |
| --- | --- | --- | --- | --- | --- |
| 列表 `list` | `[]` | 能 | 有序 | 可变 | 有 |
| 元组 `tuple` | `()` | 能 | 有序 | **不可变** | 无 |
| 集合 `set` | `{}` | 不能 | **无序** | 可变 | 有 |
| 字典 `dict` | `{}` | 键不能重复 | 无序 | 可变 | 有 |

- 序列（有顺序的排列）：**字符串、列表、元组**。
- 元组 = 不可修改的列表；集合 = 没有键的字典。
- 所有不可变对象：字符串、数值、元组。
- 字典的键必须是不可变对象（字符串、数值、元组）；值可任意类型。

### 一、列表 list

特点：① 有序 ② 可重复 ③ 容纳不同类型数据。

```python
# 生成自然数列表
n = int(input())
lst = list(range(1, n+1))     # 直接生成
print(lst)

lst = []
for i in range(1, n+1):        # 迭代生成
    lst.append(i)
print(lst)
```

**查**：`list.index(x)` 返回索引；`lst[i]` 返回内容。

**切片**（与字符串、`range()` 类似）：`lst[start:end:step]`

- 左闭右开；正向从 `0`、负向从 `-1`；
- 默认值：不写头=从头，不写尾=到尾，步长默认 `1`；`step` 为负时从后往前。

**增 / 删 / 改 / 排 / 拼**：

```python
lst.append(x)        # 末尾加一个
lst.extend([x, y])   # 末尾加一堆（逐个加入）
lst.insert(a, b)     # 在索引 a 前插入 b
lst.remove(x)        # 删内容（首个匹配）
lst.pop(i)           # 删索引 i 处元素
lst[i] = '新值'      # 索引改
lst[x:] = [...]      # 切片改
lst.sort()           # 正排
lst.sort(reverse=True)  # 降排
[1,2] + [3,4]        # 拼接 -> [1,2,3,4]
```

> `append()` 与 `extend()` 区别：`append([1,2])` 把整个列表作为**一个元素**加入（形成嵌套）；`extend([1,2])` 把其中**每个元素**分别加入。

### 二、字典 dict

- 定义：花括号 `{}`，以**键值对** `key: value` 存储；`dict()` 亦可创建。
- 特点：键不可重复、元素无序、键必须不可变、动态伸缩、以空间换时间。

```python
d = {'A': 10, 'B': 20}
print(d['A'])            # 10，按键取值
print(d.get('A', 0))     # 取键 A 的值，不存在返回默认 0
d['C'] = 30              # 增 / 改
del d['A']               # 删键
d.clear()                # 清空字典，保留变量
```

- `x in d` 判断 `x` 是否是字典的**键**（✓）；`d.get(x, y)` 返回键 `x` 的值，不存在则返回 `y`。

### 三、元组 tuple

- 不可变序列；创建：`(1,2)` 或 `tuple()`。
- **只含一个元素的元组必须带逗号**：`(20,)` 是元组，`('runoob')` 是字符串。
- 没有 `append()` / `extend()` / `sort()`；元素不能增删改。

```python
print(type((20,)))        # <class 'tuple'>
print(type(('runoob')))   # <class 'str'>
t = ("cat", "dog", "tiger", "human")
print(t[::-1])            # ('human', 'tiger', 'dog', 'cat')
```

### 四、集合 set

- 可变序列，"没有键的字典"；元素不重复、无序。
- 创建：`{1,2,3}` 或 `set()`（**空集合必须用 `set()`，`{}` 是空字典**）。

```python
s = set([1, 2, 2, 3, 3, 3, 4])
print(len(s))             # 4（自动去重）
s.add(x)                  # 增一个
s.update([x, y])          # 增多个
s.remove(x)               # 删指定元素，不存在抛 KeyError
s.discard(x)              # 删指定元素，不存在不抛异常
s.pop()                   # 删任意一个
s.clear()                 # 清空
```

**集合运算**：交集 `&`、并集 `|`、差集 `-`、对称差 `^`。

```python
S = {1, 2, 3}; T = {2, 3, 4}
print(S | T)   # {1, 2, 3, 4}  并集
print(S & T)   # {2, 3}         交集
print(S - T)   # {1}            差集
```

### 五、生成式

- 列表生成式：`[表达式 for 变量 in 可迭代对象 if 条件]`
- 字典生成式：`{k: v for ... in ...}`，常与 `zip()` 配合：

```python
items = ['Fruits', 'Books', 'Others']
prices = [96, 78, 85]
lst = zip(items, prices)
print(dict(lst))          # {'Fruits': 96, 'Books': 78, 'Others': 85}

list1 = [(m, n) for m in "ABC" for n in "ABC" if m != n]
print(list1)              # [('A','B'), ('A','C'), ('B','A'), ('B','C'), ('C','A'), ('C','B')]
```

> 元组**没有**生成式；集合有生成式 `{}`。
