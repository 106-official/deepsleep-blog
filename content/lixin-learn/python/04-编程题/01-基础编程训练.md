## 基础编程训练（课外作业 1）

题源：课外作业 1（2023-04）。每题含题目描述与参考代码，注意 `input()` 内**不要加提示信息**，否则按评分规则可能不得分。

### 题 1　公式的 Python 算术表达式

将下列公式用 Python 算术表达式表示，并用公式一计算 $x$、公式二计算 $x_1, x_2$：

```python
import math
t = 3.14
a = 1
b = -2
c = -3
x = (300 + 2/3) * math.sin(3*t) * math.cos(t)
x1 = (-b + pow(b**2 - 4*a*c, 1/2)) / (2*a)
x2 = (-b - pow(b**2 - 4*a*c, 1/2)) / (2*a)
print("x=%.2f" % x)
print("x1=%.2f" % x1)
print("x2=%.2f" % x2)
```

### 题 2　直角三角形判定

输入三行数字 $a,b,c$，判断能否构成三角形且为直角三角形；能则输出 `YES`，否则 `NO`。

```python
a = eval(input())
b = eval(input())
c = eval(input())
if (a + b > c) and (b + c > a) and (a + c > b):
    if (a**2 + b**2 == c**2) or (b**2 + c**2 == a**2) or (a**2 + c**2 == b**2):
        print("YES")
    else:
        print("NO")
else:
    print("NO")
```

### 题 3　输出 [1,n] 内被 7 整除的数

$n$ 须在 $[10,100]$，否则提示"输入有误"；正确则输出被 7 整除的数，逗号分隔。

```python
n = int(input())
if n < 10 or n > 100:
    print("输入有误")
else:
    for i in range(1, n + 1):
        if i % 7 == 0:
            print(i, end=',')
```

### 题 4　素数判断（半路循环 while True）

用户输入非数字提示出错并继续；输入 `n` / `N` 结束程序。

```python
x = 1
while x < 2:
    a = input()
    if a.isalpha() is False:
        a = int(a)
        for i in range(2, a):
            if a % i == 0:
                print("%s不为素数" % a)
                break
        else:
            print("%s为素数" % a)
    elif a == "n" or a == "N":
        x = x + 2
    elif a.isalpha() is True:
        print("输入数字不合法，请重新输入")
```

### 题 16　九九乘法表（矩形 / 下三角 / 上三角）

```python
print('矩形：')
for a in range(1, 10):
    for b in range(1, 10):
        print('%dx%d=%d' % (a, b, a * b), end='\t')
    print(end='\n')

print('下三角：')
for a in range(1, 10):
    for b in range(1, a + 1):
        print('%dx%d=%d' % (a, b, a * b), end='\t')
    print(end='\n')

print('上三角：')
for a in range(1, 10):
    for b in range(1, 10):
        if a <= b:
            print('%dx%d=%d' % (a, b, a * b), end='\t')
        else:
            print(end='\t')
    print(end='\n')
```

### 题 17　垫片面积之和

垫片面积 = 大圆面积 − 小圆面积，$S = n \times \pi(R^2 - r^2)$，$\pi=3.14159$。

```python
R = eval(input())
r = eval(input())
n = int(input())
pi = 3.14159
s = n * pi * (R**2 - r**2)
print("%.2f" % s)
```

```python
pwd0 = '123456'

    print(pwd0)

```

### 题 20　阶乘

$n! = 1 \times 2 \times \cdots \times n$。

```python
n = int(input())
i = 1
fac = 1
while i <= n:
    fac = fac * i
    i = i + 1
print(fac)
```
