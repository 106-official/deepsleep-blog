### 闯关 7 · T1　动物按重量排序输出

输入一系列"动物名 重量"（重量单位 `kg` 或 `t`，数值与单位无分隔），输入 `end` 结束；按重量升序以二维列表输出。

```python
ls = []
while True:
    temp = input()
    if temp == "end":
        break
    ls.append(temp.split())
print(sorted(ls, key=lambda x: float(x[1][:-2]) * 1000 if x[1][-1] == "t" else float(x[1][:-2])))
```

### 闯关 7 · T3　32 位二进制 IP 转十进制

输入 32 位 `0/1` 串，每 8 位转一个十进制字节，用 `.` 连接；长度不足/超出或含非 `0/1` 输出 `data error!`。

```python
ip = input()
ls = ""
for c in ip:
    if c not in ["0", "1"]:
        print("data error!")
if len(ip) != 32:
    print("data error!")
else:
    for i in range(4):
        ls = ls + str(int(ip[i*8:i*8+8], 2)) + "."
    print(ls[:-1])
```

### 闯关 7 · T4　分期付款计算（等额本息 / 等额本金）

输入本金、月数、还款方式、月利率；方式错误输出"还款方式输入错误"。

```python
principal = float(input())        # 贷款本金
months = int(input())             # 分期月数
repayment_type = input()           # 还款方式
monthly_interest_rate = float(input())  # 月利率

if repayment_type == 'ACPI':       # 等额本息
    monthly_repayment = (principal * monthly_interest_rate * (1 + monthly_interest_rate) ** months) \
                        / ((1 + monthly_interest_rate) ** months - 1)
    print(round(monthly_repayment, 2))
elif repayment_type == 'AC':        # 等额本金
    monthly_repayment = principal / months
    accrued_principal = 0
    monthly_repayments = []
    for i in range(months):
        interest = (principal - accrued_principal) * monthly_interest_rate
        monthly_repayment_i = monthly_repayment + interest
        accrued_principal += monthly_repayment
        monthly_repayments.append(round(monthly_repayment_i, 2))
    print(monthly_repayments)
else:
    print("还款方式输入错误")
```

> 等额本息每月还款额 $= \dfrac{P \cdot r(1+r)^n}{(1+r)^n-1}$；等额本金每月本金固定，利息按剩余本金计。

### 阶段测验二 · 1　飞机座位类型判断

座位如 `12A`：前段数字（1–17）为排号，末字符为位置（`a/A/f/F` 窗、`c/C/d/D` 过道、`b/B` 中间）。

```python
a = input()
if 1 <= int(a[:-1]) <= 17:
    if a[-1] in ['a', 'A', 'f', 'F']:
        print('窗口')
    elif a[-1] in ['c', 'C', 'd', 'D']:
        print('过道')
    elif a[-1] in ['b', 'B']:
        print('中间')
    else:
        print('输入错误')
else:
    print('输入错误')
```

### 阶段测验二 · 4　单双序列拆分与降序合并

输入 `n`，将 `1~n` 分奇偶存入 `ls1`/`ls2`，再合并为 `ls3` 降序输出。

```python
n = int(input())
ls1 = []
ls2 = []
for i in range(1, n + 1):
    if i % 2 == 0:
        ls2.append(i)
    else:
        ls1.append(i)
print(ls1)
print(ls2)
ls3 = ls1 + ls2
ls3.sort(reverse=True)
print(ls3)
```

### 阶段测验二 · 5　删除列表中能被 m 整除的元素

```python
n = int(input())
m = int(input())
ls1 = []
for i in range(1, n + 1):
    ls1.append(i)
print(ls1)
for x in ls1:
    if x % m == 0:
        ls1.remove(x)
print(ls1)
```

> 注意：遍历中边删边改列表有风险；更稳妥写法是用 `ls1 = [x for x in ls1 if x % m != 0]`。

### 阶段测验二 · 6　随机数种子筛选

`random.seed(n)` 后生成 `1~n` 随机整数 `m`，输出原列表与不能被 `m` 整除者。

```python
import random
n = int(input())
random.seed(n)
m = random.randint(1, n)
ls = list(range(1, n + 1))
ls2 = []
for i in ls:
    if i % m != 0:
        ls2.append(i)
print(ls)
print(ls2)
```

### 阶段测验二 · 8　千年虫年份修正

输入 6 个整数：值为 `0` 改成 `2000`，否则改成 `1900 + 原值`，最后降序输出。

```python
i = 1
list1 = []
while i <= 6:
    a = int(input())
    list1.append(a)
    i += 1
print(list1)
for m in list1:
    if m == 0:
        n = list1.index(m)
        list1[n] = 2000
    else:
        x = 1900
        n = list1.index(m)
        list1[n] = x + m
list1.sort(reverse=True)
print(list1)
```
