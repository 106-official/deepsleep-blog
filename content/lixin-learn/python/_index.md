# Python 程序设计基础

上海立信会计金融学院《Python 程序设计基础》课程复习资料整理，内容来自期末复习资料合集（闯关训练、阶段测验、期中测验、课外作业、期末真题与复习提纲）。

## 内容说明

- **知识点**：基础语法与数据类型、流程控制、组合数据类型（列表/字典/元组/集合），保留教材公式与代码
- **单选题 / 判断题**：闯关训练与课外作业中的典型题，附参考答案与解析
- **编程题**：课外作业、闯关训练、阶段测验中的大题，含完整参考代码
- **扫描讲义**：阶段测验、期中测验、期末真题等原卷扫描件，按图片化讲义形式保真嵌入
