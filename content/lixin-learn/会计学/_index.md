# 会计学原理

《会计学原理》（基础会计）复习资料与配套习题，按「知识点 → 选择题 → 判断题 → 业务题」组织。

## 内容说明

- **知识点**：8 章核心考点梳理（会计含义与职能、会计假设与基础、会计要素与等式、账户与复式记账、科目与账户、凭证账簿报表、会计账簿、账务处理与财产清查）
- **选择题 / 判断题**：按章节归类的考点精练，每题附参考答案
- **业务题**：会计分录、试算平衡、平行登记等实务训练，附完整参考答案（含 T 型账户与分录）
- **扫描件**：原卷 PDF / Word 文档 / 真题图片扫描，按无损方式归档，供对照练习使用
- 表格使用 Markdown 渲染，公式使用 LaTeX（KaTeX）渲染

## 章节导航

左侧边栏按板块浏览：先看「知识点」打基础，再用「选择题 / 判断题」查漏，最后用「业务题」练手。
