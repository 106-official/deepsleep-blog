## 洗衣设施

### 文翔路校区（松江）
- **公共洗衣房**：每栋宿舍楼一层设公共洗衣房，配备多台投币/扫码洗衣机
- **使用方式**：微信/支付宝扫码支付，约 3-5 元/次
- **吹风室**：一楼设有专属吹风室（吹风机禁止带入宿舍）

### 上川路校区（浦东）
- **U 净 APP 预约**：下载"U净"APP，扫码预约洗衣机，支持在线支付
- **分布**：每层楼或每栋楼特定区域集中放置

>  **洗衣小贴士**：建议错开晚高峰使用洗衣机；内衣袜子手洗更卫生；换季衣物可校外干洗店处理。

## 医疗与报销

### 校医院
| 校区 | 位置 | 服务时间 |
|------|------|----------|
| 文翔路校区 | 校内指定区域 | 工作日 8:00-16:30 |
| 上川路校区 | 校内指定区域 | 工作日 8:00-16:30 |

- **常见病诊疗**：感冒、发烧、肠胃不适等可在校医院就诊取药，价格低廉
- **急诊处理**：非工作时间可在值班室就诊或转诊校外医院

### 校内就诊的费用规则

依据《大学生医疗保健管理规定》，**普通门诊应先在校医疗机构就诊**：

| 项目 | 规定 |
|------|------|
| **挂号** | 凭本人**校园卡免费挂号** |
| **用药量** | 一般 ≤3 日量，慢性病 1–2 周 |
| **校内就诊费用** | 符合规定的医疗费用**个人自负 10%**（直接从校园卡扣），其余由学校承担 |
| **转诊** | 校医认为需转院的开转诊单至学校定点医院，**未经转诊费用自理** |
| **急诊** | 发热、急性腹痛/剧烈呕吐、休克昏迷、严重喘息/胸痛、急性出血、外伤、异物、急性传染病等，可直接去定点或就近医保定点医院 |
| **住院** | 凭住院通知书 + 学生证 + 身份证到校医疗机构开《大学生住院结算凭证》，定点医院记账结算 |
| **零星报销** | 转诊/急诊/休学外地先垫付，凭单据到校医疗机构审核后到财务处报销；外省市急诊住院出院后 **6 个月内**办理 |

> **新生体检**：入校常规体检并建立健康档案，入学三个月为有效复查期。

### 大学生医保（必须自己缴费！）

**不是学校自动办好的**——每年集中参保期需本人缴费，漏缴后果很严重：

| 项目 | 说明 |
|------|------|
| **个人缴费** | **400 元/人·年**（与本市居民医保中小学生标准一致） |
| **缴费时间** | 一般 **11 月下旬至 12 月上旬**（如 2026 年度为 11/24–12/7） |
| **缴费方式** | 微信「随申办」小程序 → 搜"上海立信会计金融学院学费缴纳" → 一网通办学生缴费平台 → 微信支付 |
| **漏缴后果** | 自次年 **1 月 1 日**起，在校内医疗机构及医保定点医院**不能享受医保待遇，就医全额自费** |
| **断保等待期** | 未在集中期参保的，设 **3 个月固定待遇等待期**，等待期内费用不追溯 |

**居民医保待遇（大学生版）**

| 就诊类型 | 起付线 | 基金支付比例 |
|----------|--------|--------------|
| **校内医保定点门诊** | **不计起付线** | **支付 80%**（个人 20%） |
| 门急诊·一级医疗机构 | 300 元/年 | 70%（个人 30%） |
| 门急诊·二级医疗机构 | 300 元/年 | 60%（个人 40%） |
| 门急诊·三级医疗机构 | 300 元/年 | 50%（个人 50%） |
| 住院·一级 / 二级 / 三级 | 50 / 100 / 300 元 | 80% / 75% / 60% |

- **大病保险**：合规个人自负部分再报销 **60%**（低保/低收入 65%）；重症尿毒症、恶性肿瘤、部分精神病、血友病、再生障碍性贫血等纳入保障
- **异地就医**：办理异地备案后可跨省直接结算，备案走「国家医保服务平台」APP 或支付宝/微信小程序
- **医保电子凭证**：未领实体社保卡可申领电子凭证（随申办/支付宝/微信），就医同等效力
- **银行卡**：2023 级（含）前用农行上海分行借记卡，2024 级（含）后用招行上海分行借记卡
