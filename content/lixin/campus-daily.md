# 校内生活指南

---

## 食堂美食

### 文翔路校区（松江）

| 食堂 | 楼层/区域 | 特色 |
|------|-----------|------|
| **第一食堂** | 1F 学生食堂 | 大众餐饮、盖浇饭、面条窗口，价格实惠 |
| | 2F 风味餐厅 | 麻辣烫、石锅饭、铁板烧等风味小吃 |
| | 3F 教工餐厅（学生可去） | 自助选餐，环境较好 |
| **第二食堂** | 1F 学生食堂 | 面点、馄饨、水饺、砂锅 |
| | 2F 特色窗口 | 日式简餐、韩式料理、西餐 |
| **清真食堂** | 独立区域 | 适合回族等有清真饮食需求的同学 |

>  文汇路美食街就在校外，步行可达，各类小吃、奶茶店、餐馆应有尽有，是解馋的好去处。

### 上川路校区（浦东）

| 食堂 | 特色 |
|------|------|
| **学生第一食堂** | 大众餐饮为主，价格亲民 |
| **学生第二食堂** | 二楼有风味特色窗口，选择更多样 |
| **清真食堂** | 满足少数民族需求 |

> 两校区食堂均支持**校园卡**消费，部分窗口支持微信/支付宝。

** 参考价格**：一荤一素约 8-12 元，两荤一素约 12-18 元，丰俭由人。

## 洗衣设施

### 文翔路校区（松江）
- **公共洗衣房**：每栋宿舍楼一层设公共洗衣房，配备多台投币/扫码洗衣机
- **使用方式**：微信/支付宝扫码支付，约 3-5 元/次
- **吹风室**：一楼设有专属吹风室（吹风机禁止带入宿舍）

### 上川路校区（浦东）
- **U 净 APP 预约**：下载"U净"APP，扫码预约洗衣机，支持在线支付
- **分布**：每层楼或每栋楼特定区域集中放置

>  **洗衣小贴士**：建议错开晚高峰使用洗衣机；内衣袜子手洗更卫生；换季衣物可校外干洗店处理。

## 自习好去处

### 校内自习场所

| 地点 | 特点 | 开放时间 |
|------|------|----------|
| **图书馆** | 环境好、座位多、有空调 | 详见图书馆页面 |
| **教学楼空教室** | 安静、人数少 | 一般至 21:30 |
| **考研专属教室** | 专为考研同学设置，固定座位 | 申请制，按年度分配 |

## 医疗与报销

### 校医院
| 校区 | 位置 | 服务时间 |
|------|------|----------|
| 文翔路校区 | 校内指定区域 | 工作日 8:00-16:30 |
| 上川路校区 | 校内指定区域 | 工作日 8:00-16:30 |

- **常见病诊疗**：感冒、发烧、肠胃不适等可在校医院就诊取药，价格低廉
- **急诊处理**：非工作时间可在值班室就诊或转诊校外医院

### 大学生医保

学校统一为在校生办理**上海市大学生基本医疗保险**：

| 项目 | 说明 |
|------|------|
| **报销比例** | 门急诊报销约 70%（校内）、校外定点医院约 50-60% |
| **住院** | 按上海市大学生医保政策执行，报销比例更高 |
| **报销流程** | 校医院就诊直接结算；校外就诊需保留发票、病历等材料，在规定时间内到校医院/学生事务中心办理报销 |
| **寒暑假异地就医** | 需提前备案，保留就医材料返校后报销 |

>  建议每位同学随身携带校园卡和身份证复印件，以备就医使用。

### 常用药店
两校区校门口及周边均有多家药店，常用非处方药可自行购买。
