# 数字校园与信息化服务

入学第一周最该搞定的事：激活校园 ID、连上校园网、装好移动立信。这三件事没弄好，选课、缴费、查成绩全都寸步难行。

---

## 统一身份认证（校园 ID）

**校园 ID = 你的学号**，是所有校内系统的通行证。

| 项目 | 说明 |
|------|------|
| **账号** | 学号（教工为工号） |
| **首次激活** | [cas.paas.lixin.edu.cn/cas/login](https://cas.paas.lixin.edu.cn/cas/login) |
| **忘记密码** | 登录页点"忘记密码"重置，或致电智慧校园建设中心 **50218734** |

> 一个账号打通教务、财务、图书馆、一卡通、邮箱、OA——密码别设太随意，也别设完就忘。

---

## 校园无线网络（免费）

三个校区统一使用两个 SSID：

| 项目 | 说明 |
|------|------|
| **SSID** | **lixin-ap** / **lixin-ap-802.1x** |
| **认证方式** | 学号（工号）+ 统一身份认证密码 |
| **认证地址** | http://202.121.255.3:8080/portal （或打开浏览器随便访问会自动跳转） |
| **费用** | **免费**，入校即自动拥有上网账号 |

> 连上却打不开网页，多半是没跳认证页——手动访问认证地址即可。

---

## 校外访问校内系统（VPN）

在校外要用教务系统、图书馆数据库等校内资源，需通过 **aTrust 零信任平台**：

- 下载安装 aTrust 客户端，用统一身份认证登录
- 说明文档：[xxb.lixin.edu.cn/jszl/57078.htm](https://xxb.lixin.edu.cn/jszl/57078.htm)
- 也可通过数字校园门户外网访问（认证后无感知访问）

> 寒暑假在家查成绩、交作业、缴宿舍电费都要用它，放假前先装好并测试一次。

---

## 移动立信 APP

数字校园的移动端，覆盖 OA、教务、一卡通等绝大部分桌面端功能。

- **安卓**：扫码下载 / 官网下载
- **iOS**：App Store 搜索"移动立信"
- 常用场景：查课表与成绩、校园卡挂失与流水、宿舍电控缴费、办事流程审批

---

## 微信企业号（微门户）

- "上海立信会计金融学院"微信企业号是学校**微门户**，整合各类移动应用
- 加入方式：通过统一身份认证进入"数据中心平台"确认手机号后邀请加入
- 浦东宿舍**电控缴费**入口：企业微信 → 工作台 → 校园一卡通 → 电控缴费
