# 上海立信会计金融学院简介

---

## 学校概述

**上海立信会计金融学院**（Shanghai Lixin University of Accounting and Finance，简称"立信"），是一所以会计、金融为特色的公办全日制普通高等学校。学校由**上海市人民政府**举办，是上海高水平地方应用型高校建设单位。

| 项目 | 信息 |
|------|------|
| **创办时间** | 1928 年 |
| **办学性质** | 公办全日制普通高等学校 |
| **学校类别** | 财经类 |
| **校训** | 立信（校训：信以立志、信以守身、信以处世、信以待人、信以立世） |
| **校区分布** | 上川路校区（浦东）、文翔路校区（松江）、徐汇校区、顾唐路校区 |
| **在校生规模** | 全日制在校生 19000 余人（含专业硕士研究生 450 余人） |
| **院系与专业** | 15 个二级学院、3 个硕士专业学位点、40 个本科专业 |

---

## 历史沿革

| 年份 | 事件 |
|------|------|
| **1928 年** | 由"中国现代会计之父"**潘序伦**先生创办，始名"立信会计补习学校" |
| **1930 年代** | 发展成立信会计专科学校，是中国现代会计教育的发源地之一 |
| **1952 年** | 全国院系调整，学校停办，相关专业并入上海财经学院等高校 |
| **1980 年** | 复校，恢复立信会计专科学校建制 |
| **2003 年** | 升格为上海立信会计学院，开展本科教育 |
| **2016 年** | 与上海金融学院合并，成立**上海立信会计金融学院** |
| **至今** | 发展成为以财经为核心、多学科协调发展的应用型高校 |

> 潘序伦先生倡导的"立信"精神，贯穿学校近百年办学历史，形成了独特的会计文化传统。

---

## 办学特色

### 1. 会计学传统优势
- 被誉为"**中国会计人才的摇篮**"
- 会计学专业为国家特色专业、上海市一流专业
- 系统开设 ACCA、CPA 方向课程，与国际会计体系接轨

### 2. 金融学科协同发展
- 金融学、金融工程等专业发展迅速
- 依托浦东金融中心区位优势，与金融机构密切合作
- 设有金融科技学院，面向数字经济培养人才

### 3. 应用型人才培养
- 强调"理论 + 实务"双导向
- 大量实务课程、案例教学、企业实训
- 与多家会计师事务所、银行、证券公司建立实习基地

### 4. 序伦书院（荣誉学院）
- 选拔优秀学生实施拔尖培养计划
- 小班化教学、导师制、个性化培养方案
- 享有更多学术资源和实践机会

## 院系与专业设置

学校现有 **15 个二级学院、40 个本科专业**，按学院分布如下（以各学院最新"教学一览/培养方案"为准）：

| 学院 | 本科专业 |
|------|----------|
| **会计学院** | 会计学、会计学(ACCA)、会计学(CIMA)、财务管理、审计学、资产评估 |
| **金融学院** | 金融学、金融学(国际化)、信用管理、金融工程、投资学 |
| **工商管理学院** | 工商管理、工商管理(国际企业管理)、市场营销、人力资源管理、物流管理、房地产开发与管理 |
| **国际经贸学院** | 经济学、国际经济与贸易、国贸(国际化)、国际商务 |
| **财税与公共管理学院** | 税收学、税收学(国际税收)、财政学、劳动与社会保障、行政管理 |
| **统计与数学学院** | 金融数学、经济统计学、数学与应用数学、应用统计学 |
| **信息管理学院** | 电子商务、信息管理与信息系统、计算机科学与技术、数据科学与大数据技术 |
| **外国语学院** | 英语、商务英语、日语 |
| **保险学院** | 保险学、精算学 |
| **法学院** | 法学、社会工作 |
| **金融科技学院** | 金融科技、金融工程(中美合作) |
| **人文艺术学院** | 汉语言文学（财经文秘方向） |

> 另设马克思主义学院、体育与健康学院、计算机与人工智能学院、序伦书院、国际财经学院等教学单位。

### 重点学院速览

| 学院 | 规模与特色 |
|------|------------|
| **会计学院** | 办学历史最悠久学院之一；本科生近 4000 人、研究生近 300 人；教职工 165 人（专任 125 人），含全国模范教师 1 名、全国会计领军人才 2 名、宝钢优秀教师 6 名、上海市曙光学者 3 名 |
| **金融学院** | 始建于 1952 年（人行银行学校）；2024 年获批**金融硕士**学位授予权；专任教师 104 人，高级职称 55%、博士 85%、双师型 91% |
| **法学院** | 2016 年组建；专任教师 40 人（教授 4、副教授 9），博士 34 人；设金融法律与政策研究中心、法律诊所等 |
| **保险学院** | 2009 年组建，国内高校**第四家**保险学院；本科生 700 余人；精算学为上海地区首个精算学本科专业，2019 年加入北美精算师协会 UCAP 计划 |

> 各学院站域名多为 `学院缩写.lixin.edu.cn`（会计 kjxy、金融 jrxy、法学 fxy、保险 bxxy、工商 sba 等），师资与培养方案详情以学院官网为准。
