# 实习与就业指南

---

## 实习须知

### 大一可以实习吗？
可以，但由于新生掌握技能有限，一般只能做杂活，工资也较低。如果实习 Title 和地点不错可以考虑，否则不如暑假刷高四六级分数。

### 实习事务所选择
- **八大及以上**事务所值得去
- **八大以下**不建议——不如把四六级分刷高（四六级分数真的很有用，四大EY特攻）
- 不知名小事务所纯属浪费时间

### 实习不必报班
不要被机构忽悠付费报实习班。网上各种低薪兼职（账号运营、代接单等）纯属苦力。

---

## 毕业实习要求

按专业要求开展毕业实习，一般要求：
- 在学校规定的月份内连续打卡 **40 个工作日**
- 撰写一系列文件
- 部分学院安排在大二升大三暑假，部分安排在大三

## 升学方向指南

### 考研
| 项目 | 说明 |
|------|------|
| **准备时间** | 大三上开始准备，大四上（12 月）初试 |
| **本校考研** | 立信有硕士点，部分专业可本校读研 |
| **跨校考研** | 财经类热门院校：上财、华师大、上外贸等 |
| **注意事项** | 考研与毕业实习时间可能冲突，需提前规划 |

>  考研独木桥竞争激烈，建议提前了解目标院校的报录比、考试科目，做好时间规划。大四如有"买学分"空出时间的空间，可集中精力备考。

### 考公 / 考编
| 项目 | 说明 |
|------|------|
| **国考** | 每年 11-12 月笔试 |
| **上海市考** | 每年 12 月笔试 |
| **省考** | 各省时间不同，一般春季 |
| **事业单位** | 全年有招聘，关注各渠道公告 |

> 建议关注相关公众号和学校就业指导中心通知。行政管理、财政学、法学等专业考公优势较大。

### 出国留学
| 项目 | 说明 |
|------|------|
| **语言考试** | 雅思 / 托福，建议大二大三考出成绩 |
| **GPA 要求** | 申请好学校需均分 85+（GPA 3.5+） |
| **实习/科研背景** | 有相关经历是加分项 |
| **申请时间** | 大四上（9 月-次年 1 月）递交申请 |

> 留学建议提前规划，保持 GPA，准备语言考试，积累实习经历。序伦书院的同学有更多学术资源。

### 第二学位
部分专业可以申请第二学位，拓展知识面，增加就业竞争力。

## 专业评价速览

### 经管类
- **会计/审计**：能提供一定就业增益，其他经管专业在上海就业市场差别不大
- **金融学**：学校王牌，就业面极宽
- **财务管理**：偏管钱，适合企业财务部或银行

### 事务所方向
- **审计学**：进入"四大"会计师事务所最对口的专业
- **资产评估**：冷门但壁垒高

### 技术类
- **计算机/数据科学/智能科学**：当下热门方向
- **金融科技**：新金融业态抢着要

### 其他
- **法学**：主打"法律+财经"，考公或金融律师都有特色路线
- **商务英语/英语**：适合外贸、外企或跨行财经英语

## 避坑提醒
- 主动推荐实习/考研岗位的学长可能拿回扣，直接删掉
- 校内外机构渲染焦虑、编故事骗你付费，擦亮眼睛
- **不要偷外卖**——去年有人因此落网
