## 项目介绍

塑造简洁的城市地图，以长沙市为 demo，根据用户的个人喜好推荐最贴近的行程与旅游建议。计划 10 月出 demo，明年寒假前完成。

## 需求信息

**招募角色一：旅游重度爱好者 2 名（预计每周占用 2 小时）**

- A. 有丰富的深度旅游经验，能写出具体的功能改进建议（"场景—痛点—改进方向"），不建议笼统评价。
- B. 对长沙本地熟悉者优先。

**招募角色二：程序设计 1 名（预计每周占用 5 小时）**

- A. 有固定使用的技术栈，建议附已上线项目或 GitHub 链接。
- B. 了解云函数（SCF / 云开发）或 Serverless 架构。
- C. 有地图 SDK（高德 / 百度 / Mapbox）或相关 MCP 使用经验者优先。

## 投递要求

- 旅游爱好者请说明你熟悉的旅游场景与对长沙的了解程度，并附一段"场景—痛点—改进方向"的改进建议；
- 程序设计请附上技术栈、已上线项目或 GitHub 链接，并说明对云函数 / 地图 SDK 的熟悉度。
