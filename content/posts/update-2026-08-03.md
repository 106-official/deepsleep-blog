### 1. Lixin 立信界面 — 官方资料全面补充

在立信问答助手（`/lixin/`）中补充了大量校内官方资料，现在 AI 助手可以基于这些内容回答问题：

**新增 / 扩充内容：**

- **各专业培养计划** — 160 学分框架、通识/学科专业/实践三大模块、学分比例要求
- **辅修与双学位** — 金融学 / 会计学(CPA 方向) / 法学三个辅修专业，160 元/学分，辅修 vs 第二学士学位对比
- **师资与学院介绍** — 全校教职工 1630+ 人、专任教师 1250+、博士学位 720+；15 个二级学院、40 个本科专业
- **选课安排** — 集中选课三轮机制（第一轮抽签 → 第二轮补选 → 第三轮退改选）、16+2 学段制
- **短学段与实习毕业要求** — 毕业实习 8 周 / 4 学分安排在短学段
- **转专业** — 六种转入类型、七种不予转情形、时间表与学分认定规则
- **数字校园** — 统一身份认证、校园网 `lixin-ap`、aTrust VPN、移动立信 APP、校园邮箱（新增独立页面）
- **医保** — 按上海市大学生医保政策重写：400 元/年、校内就诊自负 10%、起付线与支付比例

![立信问答助手](/images/update-2026-08-03/lixin-chat.png)

> 所有资料均来自上海立信会计金融学院官方网站各子站（教务处、后勤、信息化处、研究生处等），数据口径以学校最新通知为准。

### 2. SleepTown — UI 重构

久违的 SleepTown 更新。这次对 UI 做了比较大的改动——**放弃了原来的卡通风格**，转向更简洁的深色卡片设计。

新版本在每种「鱼」（关卡）首次出现时，会在界面中展示该关卡的介绍及应对策略提示，帮助玩家快速理解机制。

### 4. 学习板块 — 网络协议 + CPA + 题库

#### 网络协议（30 讲完整版）

学习路线的 NET 板块补齐了 **30 个网络协议**的详细知识体系，覆盖从 ARP 到应用层的完整协议栈：

| 层级 | 协议 |
|------|------|
| 数据链路 | ARP 地址解析、802.1X 端口认证 |
| 网络 | IP 网际协议、ICMP、IGMP、GRE、RIP |
| 传输 | TCP 传输控制、UDP 用户数据报 |
| 应用 | DNS、DHCP、HTTP/HTTPS、SSH、FTP、SMTP/POP3/IMAP、TLS/SSL、WebSocket |

每个协议均包含工作原理、报文结构（含 RFC 编号与字段详解）、交互流程图和校验要点。

![IP 协议详情页](/images/update-2026-08-03/network-protocols.png)

#### CPA 注册会计师

CPA 会计科目做了内容上的系统补充——以「无形资产」为例，新增了章节定位、考情分析、知识框架和核心精讲（定义与特征、确认条件、初始计量、后续计量、处置与列报），配合目录导航方便定位复习。

连同之前积累的 **3300 道真题**也一并做了增添和整理。

![CPA 无形资产](/images/update-2026-08-03/cpa.png)
