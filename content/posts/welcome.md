## ✨ 欢迎欢迎！

这是 **DeepSleep Blog** 的第一篇文章！

### 🎯 这个博客的特点

- 💰 **完全免费**：基于 GitHub Pages，无需信用卡
- ⚡ **访问速度快**：全球 CDN 加速
- 🔒 **HTTPS 加密**：自动提供 SSL 证书
- 📱 **响应式设计**：支持所有设备
- ✍️ **Markdown 写作**：简洁高效
- 🎨 **主题美观**：使用 PaperMod 主题

### 🔧 技术栈

| 技术 | 用途 |
|------|------|
| [Hugo](https://gohugo.io/) | 静态站点生成器 |
| [GitHub Pages](https://pages.github.com/) | 免费托管 |
| [PaperMod](https://github.com/adityatelange/hugo-PaperMod) | 博客主题 |
| [Cloudflare DNS](https://www.cloudflare.com/) | 域名解析 |
| [GitHub Actions](https://github.com/features/actions) | 自动化部署 |

### 📝 如何写新文章？

1. 在 `content/posts/` 目录下创建新的 `.md` 文件
2. 使用 Markdown 格式撰写内容
3. 推送到 GitHub，自动部署！

```markdown
---
title: "我的新文章"
date: 2026-05-30
tags: ["技术"]
---

文章内容...
```
