## 模拟stata OLS的遍历分析

### 📦 资源简介

这是一个用于 Stata 数据的回归分析工具，支持多种回归分析方法：

| 分析类型 | 说明 | 适用场景 |
|---------|------|---------|
| **Reg分析** | 普通OLS回归 | 连续因变量的线性回归 |
| **Xtreg分析** | 面板数据固定效应回归 | 控制个体/时间固定效应 |
| **Logit分析** | 逻辑回归 | 二元因变量(0/1)的概率预测 |

### 主要功能

- 加载 Stata `.dta` 文件
- 自动识别数值变量
- 控制变量遍历分析
- 固定效应变量处理（生成虚拟变量）
- 组合变量分析
- 按 t 值筛选显著结果
- 结果导出为 CSV
- 运行日志记录

### 🚀 快速开始

**方法一：Windows 用户（推荐）**

1. 双击 `start.bat` 启动程序
2. 程序会自动检测并安装 Python（如果需要）
3. 加载数据并开始分析

**方法二：命令行方式**

```bash
# 启动 GUI
python start.py
# 或直接运行
python regression_gui.py

# 命令行使用
python cli.py -f data.dta -d Y -i X -o results.csv
```

### 📋 使用流程

1. **启动程序**：运行 `start.bat`
2. **加载数据**：选择 `.dta` 文件并加载
3. **选择变量**：
   - 因变量（Y）
   - 自变量（X）
   - 固定控制变量
   - 选定控制变量（可选，遍历范围）
4. **选择分析类型**：Reg / Xtreg / Logit
5. **运行分析**：点击"运行回归"
6. **查看结果**：在界面中查看显著结果
7. **导出结果**：点击"导出结果"保存为 CSV

### ⚠️ 注意事项

- 压缩包文件大小小于 **100MB**，下载前请注意硬盘存储空间
- 请按照压缩包内的教学进行安装
- 需安装依赖：`pip install pandas numpy statsmodels`
- Logit 分析要求因变量必须是二元变量（0或1），不符合会自动跳过
- 只有 t 值大于设定阈值（默认 1.65）的结果才会显示在显著结果中
