## 📖 项目概述

**SleepTown** 是一款基于浏览器的社交推理游戏，灵感来源于经典的"狼人杀"和"Among Us"等游戏。玩家扮演一个鱼塘的管理者，需要通过"问询"机制找出隐藏在鱼群中的坏鱼，保护豪鱼们的安全。

### 🎯 当前版本特色 (v2.2.2.0)

- **🎮 双模式系统**: 自由模式（自定义配置）+ 关卡模式（固定挑战）
- **🏆 关卡模式 sidebar 布局**: learn 风格「左固定章节列表 + 右关卡详情卡片」，移动端抽屉化 (v2.2.2.0)
- **🎭 十种角色系统**: 豪鱼阵营(5种) + 坏鱼阵营(2种) + 中立阵营(3种，含法师D)
- **🔍 多样化线索**: 侦探D、法官D、八卦鱼、梦游D各有独特信息提供方式
- **😈 智能伪装**: 所有坏鱼都会伪装成当前游戏中存在的角色
- **🏆 10个关卡挑战**: 第1章8关 + 第2章2关，支持连续挑战
- **⚙️ 灵活配置**: 支持 6-20 只鱼，自定义角色种类
- **⏭️ 跳过机制**: 可跳过问询或流放阶段

## 🎭 角色系统详解 (9种角色)

### 阵营分类

| 阵营 | 胜利条件 | 数量占比 |
|------|---------|---------|
| **🌊 豪鱼阵营** | 所有坏鱼被淘汰 | ~60% |
| **😈 坏鱼阵营** | 豪鱼数量 ≤ 坏鱼+中立 | ~25% |
| **⚖️ 中立阵营** | 存活至游戏结束 | ~15% |

### 完整角色列表

| 角色 | 阵营 | 特殊能力 | 问询效果 |
|------|------|---------|---------|
| **🐟 摆烂D** | 豪鱼 | 无特殊能力 | "什么也没发生" |
| **🔍 侦探D** | 豪鱼 | 揭示一条真实坏鱼的编号 | "#X 号是坏鱼！"（真实信息）|
| **⚖️ 法官D** | 豪鱼 | 揭示一条非豪鱼的编号 | "#X 号不是豪鱼！" |
| **📰 八卦鱼** | 豪鱼 | 检查相邻鱼是否有非豪鱼 | "有瓜吃！" / "并没有瓜..." |
| **💤 梦游D** | 豪鱼 | 提供3个号码，其中一只是坏鱼/中立 | "#X, #Y, #Z 中有一只不是豪鱼！" |
| **😈 邪恶D** | 坏鱼 | 夜晚杀人；被问询时**完美伪装** | 显示为其他角色的效果 |
| **💀 殉道D** | 坏鱼 | 死亡后立即杀死一只好鱼；会伪装 | 同邪恶D，死亡时触发诅咒 |
| **🎭 恶作剧D** | 中立 | 翻开后减少一次问询机会 | "你的问询机会减少了1次！" |
| **🐋 虎鲸** | 中立 | 每晚随机杀死一条其他的鱼 | "今晚要小心了..." |

### ⚠️ 伪装机制 (v2.1.1.2更新)

**重要规则**：
1. **所有坏鱼都会伪装**：邪恶D和殉道D被翻开时都会伪装
2. **智能伪装目标**：只伪装成**当前游戏中存在的角色**
3. **完美伪装效果**：
   - 显示的角色名称与真角色完全相同
   - 触发的效果也与被伪装的角色一致
   - **没有任何标记可以区分真假**
4. **揭示时机**：只有在游戏结束时才会揭示真相

**示例**：
```
场景：游戏中存在 [摆烂D, 侦探D, 法官D, 恶作剧D]

邪恶D被翻开 → 可能伪装成法官D
  → 显示："#X 号是 ⚖️法官D"
  → 效果："#Y 号不是豪鱼！" （假信息！因为实际是邪恶D伪装的）
```

### 🎮 自由模式

#### 配置选项

**基本设置**：
- 🐟 鱼的数量：6-20 只（默认10只）
- 🎭 角色选择：每个阵营至少选1种角色

**高级选项**（可选展开）：
- ❓ 问询次数：2次(困难) / 3次(标准) / 4次(简单) / 5次(新手)
- 📊 难度调整：简单 / 标准 / 困难

**角色分配算法**：

```javascript
// 根据难度确定阵营比例
switch(difficulty) {
  case 'easy':   goodRatio=0.70, evilRatio=0.15, neutralRatio=0.15
  case 'normal': goodRatio=0.60, evilRatio=0.25, neutralRatio=0.15
  case 'hard':   goodRatio=0.50, evilRatio=0.35, neutralRatio=0.15
}

// 计算各阵营总数
goodTotal = max(goodRoleTypes, floor(count * goodRatio))
evilTotal = max(evilRoleTypes, floor(count * evilRatio))
neutralTotal = max(neutralRoleTypes, floor(count * neutralRatio))

// 为每种选中角色至少分配1个，剩余均匀分配
```

#### ⏭️ 连续挑战系统 (v2.1.1.4新增)

**功能说明**：
- 关卡胜利后显示 **"⏭️ 下一关 →"** 按钮

- 按钮仅在**关卡模式胜利**时显示
- 失败或自由模式下不显示该按钮

**关卡顺序定义**：
```javascript
const stageOrder = ['1-1', '1-2', '1-3', '1-4', '1-5', '1-6', '1-7', '1-8', '2-1', '2-2'];
function getNextStageId(currentStageId) {
  const currentIndex = stageOrder.indexOf(currentStageId);
  if (currentIndex !== -1 && currentIndex < stageOrder.length - 1) {
    return stageOrder[currentIndex + 1];
  }
  return null; // 已通关最后一关
}
```

### 完整游戏循环

### 详细操作说明

#### ☀️ 白天 - 问询阶段

**操作规则**：
1. 初始状态：所有鱼的身份隐藏（❓）
2. 每轮有 **N次问询机会**（默认3次，可配置）
3. 点击任意未翻开且存活的鱼进行问询
4. 问询后该鱼身份揭晓并触发对应效果

**各角色问询效果详情**：

| 角色 | 日志输出 | 特殊效果 |
|------|---------|---------|
| 摆烂D | `😴 #X 号是一条普通的摆烂D` | 无 |
| 侦探D | `✨ #X 号是 🔍侦探D！`<br>`🗣️ #X 号说：#Y 号是坏鱼！` | 提供真实坏鱼编号 |
| 法官D | `✨ #X 号是 ⚖️法官D！`<br>`⚖️ #X 号宣判：#Y 号不是豪鱼！` | 提供非豪鱼编号 |
| 八卦鱼 | `✨ #X 号是 📰八卦鱼！`<br>`📰 "有瓜吃！" 🍉` 或 `"并没有瓜..."` | 检查相邻位置 |
| 梦游D | `✨ #X 号是 💤梦游D！`<br>`💤 #X 号在梦中呓语：#A, #B, #C 中有一只不是豪鱼！` | 提供3个可疑号码 |
| 邪恶D | `⚠️ #X 号是 [伪装角色]...` | 伪装 + 触发伪装角色效果 |
| 殉道D | `⚠️ #X 号是 [伪装角色]...` | 伪装（死亡时触发诅咒） |
| 恶作剧D | `😐 #X 号是 🎭恶作剧D（中立）`<br>`🎭 触发恶作剧效果！**你的问询机会减少了1次！**` | 减少1次问询机会 |
| 虎鲸 | `🐋 #X 号发出低沉的鸣叫...今晚要小心了！` | 无即时效果（夜晚生效）|

**特殊机制**：
- **恶作剧D**：翻开后**减少1次**问询机会（v2.1.1.1修改，原为清空所有）
- **殉道D**：如果被流放或杀死，**立即杀死1只好鱼**作为报复
- **虎鲸**：每夜晚阶段额外随机杀1条鱼（不分阵营）

#### ⏭️ 跳过问询功能 (v2.1.1.2新增)

**激活条件**：
- 至少已使用过1次问询机会
- 仍有剩余问询次数未使用

**效果**：
- 立即结束问询阶段
- 剩余问询机会作废
- 解锁流放模式按钮

**适用场景**：
- 已获得足够信息，不想冒险继续问询
- 想尽快进入流放阶段

#### ⚖️ 流放阶段

**激活条件**：问询次数用完（包括提前跳过）

**操作方式**：点击任意未翻开且存活的鱼

**后果**：
- 被流放的鱼直接淘汰（alive=false）
- 真实身份揭晓给所有玩家
- 如果是**殉道D**，触发死亡诅咒效果

#### 🚫 跳过流放功能

**效果**：本轮不淘汰任何鱼，直接进入夜晚

**适用场景**：
- 信息不足，无法确定谁是坏鱼
- 避免误伤好鱼（特别是摆烂D较多的局面）
- 等待更多夜晚信息

#### 🌙 夜晚阶段

**执行顺序**：
1. **坏人行动**：所有存活的邪恶D和殉道D共同选择1只豪鱼击杀
2. **虎鲸行动**：存活的虎鲸随机选择1条其他鱼击杀（可能重复）
3. **结果公布**：第二天白天开始时显示所有受害者

**特殊情况**：
- 无存活坏鱼 → 夜晚平安无事
- 无存活好鱼 → 坏鱼胜利（游戏结束）
- 受害者可能同时被坏鱼和虎鲸选中

## 🏆 胜负判定

### ✅ 豪鱼胜利条件

满足以下任一条件即判胜：
1. **所有坏鱼都被淘汰**（通过流放或夜晚击杀）
2. 存活的豪鱼数量 > 0 且无任何坏鱼存活

**胜利弹窗显示**：
- 图标：🎉
- 标题："豪鱼胜利！"
- 内容："你是豪人！成功找出了所有威胁，SleepTown 再次恢复了宁静！"
- 按钮："再来一局" + "下一关"（仅关卡模式）+ "修改配置" + "返回模式选择"

### ❌ 失败条件

满足以下任一条件即判负：
1. **所有豪鱼都被消灭**（死亡或流放）
2. **豪鱼 + 中立阵营 ≤ 坏鱼阵营**

**失败弹窗显示**：
- 图标：💀
- 标题："失败！"
- 内容："混乱占据了上风，SleepTown 陷入了黑暗..."
- 按钮："再来一局" + "修改配置" + "返回模式选择"

### ⚠️ 核心数据结构 (gameState)

```javascript
gameState = {
  phase: 'setup' | 'day' | 'night' | 'exile' | 'gameOver',
  day: number,                              // 当前天数（从1开始）
  inquiriesLeft: number,                    // 当天剩余问询次数
  maxInquiriesPerDay: number,               // 每天最大问询次数（通常为3）
  fishes: Array<{
    id: number,                             // 鱼的唯一标识（从0开始）
    role: string,                           // 真实角色（见角色列表）
    revealed: boolean,                      // 是否已被翻开
    alive: boolean,                         // 是否存活
    disguisedAs: string | null              // 伪装成的角色（仅坏鱼使用）
  }>,
  totalFish: number,                        // 总鱼数
  mode: 'freemode' | 'stagemode',           // 游戏模式
  currentStage: string | null,              // 当前关卡ID（如 '1-1'），仅关卡模式
  config: object,                           // 游戏配置对象
  gameMode: 'inquiry' | 'exile',            // 当前操作模式
  logs: Array<{message, type, time}>        // 游戏日志记录
};
```

### ⚠️ 常见编程错误与解决方案

#### ❌ 错误1：关卡模式启动后显示"undefined"

**原因**：`initializeStageGame()` 创建新gameState时遗漏了 `currentStage` 属性

**错误代码**：
```javascript
gameState = {
  // ... 其他属性
  mode: 'stagemode',
  // ❌ 缺少 currentStage: gameState.currentStage,
  config: config
};
```

**正确代码**：
```javascript
gameState = {
  // ... 其他属性
  mode: 'stagemode',
  currentStage: gameState.currentStage,  // ✅ 必须保留
  config: config
};
```

#### ❌ 错误2：Hugo模板渲染问题

**症状**：页面显示空白或404

**可能原因**：
1. `content/play/sleeptown/freemode.md` 包含了HTML内容
2. front matter中 `type` 和 `layout` 字段冲突
3. CSS语法错误导致模板解析失败

**解决方案**：
```yaml
---
title: "SleepTown 自由模式"
date: 2024-01-01
layout: sleeptown  # ✅ 仅保留layout字段
---
# 后面不要有任何HTML内容！
```

#### ❌ 错误3：CSS样式在 {{ end }} 之后

**错误结构**：
```html
{{ end }}
<style>
/* CSS代码 */
</style>
```

**正确结构**：
```html
<style>
/* CSS代码 */
</style>
{{ end }}
```

#### ❌ 错误4：按钮样式冲突

**症状**：关卡模式按钮悬浮时显示禁用样式

**原因**：CSS选择器优先级问题，`.stagemode-btn:hover:not(:disabled)` 未生效

**解决方案**：
```css
.stagemode-btn {
  background: linear-gradient(135deg, #f39c12 0%, #e67e22 100%);
  color: #fff;
  cursor: pointer;  /* ✅ 明确设置为pointer */
}

.stagemode-btn:hover:not(:disabled) {
  transform: translateY(-2px);
  box-shadow: 0 8px 24px rgba(243,156,18,0.4);
}
```

#### ❌ 错误5：游戏结束后"下一关"按钮不消失

**原因**：`resetGame()` 函数未重置按钮状态

**解决方案**：
```javascript
function resetGame() {
  closeModal('game-over-modal');
  document.getElementById('next-stage-btn').style.display = 'none';  // ✅ 重置按钮
  // ... 其他重置逻辑
}
```
