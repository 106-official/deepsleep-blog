## 📖 项目概述

**SleepTown** 是一款基于浏览器的社交推理游戏，灵感来源于经典的"狼人杀"和"Among Us"等游戏。玩家扮演一个鱼塘的管理者，需要通过"问询"机制找出隐藏在鱼群中的坏鱼，保护豪鱼们的安全。

### 🎯 游戏特色

- **🎭 三种角色系统**: 摆烂D、侦探D、邪恶D，各有独特能力
- **🔍 侦探线索**: 侦探D可以提供真实的坏鱼信息
- **😈 坏鱼伪装**: 邪恶D被问询时会伪装成其他角色，可能给出假信息！
- **☀️⌙️ 昼夜循环**: 白天问询/流放，夜晚坏鱼杀人
- **🎮 灵活难度**: 支持 6-20 只鱼，自动平衡阵营比例

## 🎭 角色系统详解

### 角色列表

| 角色 | 阵营 | 数量占比 | 特殊能力 |
|------|------|---------|---------|
| **🐟 摆烂D** | 豪鱼 | ~55% | 无特殊能力，普通的好鱼 |
| **🔍 侦探D** | 豪鱼 | ~25% | 问询时揭示一条真实坏鱼的编号 |
| **😈 邪恶D** | 坏鱼 | ~20% | 夜晚杀人；被问询时伪装成其他角色 |

### 数量分配规则

```
总鱼数: N
坏鱼数: B = max(2, floor(N / 3))  [N≤7时为2]
侦探数: D = max(1, floor(好鱼数 × 0.25))
摆烂数: S = N - B - D

约束条件:
✅ 好鱼数量 >= 坏鱼数量 × 2
✅ 至少有1个侦探
```

**示例配置**:

| 总鱼数 | 坏鱼 | 侦探 | 摆烂 | 好鱼总数 |
|--------|------|------|------|---------|
| 6 | 2 | 1 | 3 | 4 |
| 10 | 3 | 2 | 5 | 7 |
| 15 | 5 | 3 | 7 | 10 |
| 20 | 7 | 4 | 9 | 13 |

## 🎮 游戏流程

### 完整游戏循环

```
┌─────────────────────────────────────────────┐
│                游戏开始                       │
│                                             │
│  1. 选择鱼的数量 (6-20只)                  │

│  │    ├─ 摆烂D → 无事发生              │    │
│  │    ├─ 侦探D → 给出真实坏鱼线索 ⭐    │    │
│  │    └─ 邪恶D → 伪装 + 可能给假信息 ⚠️ │    │
│  │                                    │    │
│  │  问询次数用完后 → 可进入流放模式     │    │
│  └─────────────────────────────────────┘    │

│  │                                    │    │

│  │    ├─ 流放到坏鱼 → 太棒了！🎉      │    │
│  │    └─ 流放到豪鱼 → 可惜...😢        │    │
│  └─────────────────────────────────────┘    │
│                                             │

└────────────────────┬────────────────────────┘

┌─────────────────────────────────────────────┐
│              🌙 夜晚阶段                      │

│                                             │

│              ↓                              │
│           回到白天阶段 (新的一轮)             │
└─────────────────────────────────────────────┘
```

### 详细规则说明

#### ☀️ 白天 - 问询阶段

1. **初始状态**: 所有鱼的身份都是隐藏的（显示为 ❓）
2. **问询次数**: 每轮白天有 **3次问询机会**
3. **操作方式**: 点击任意未翻开且存活的鱼
4. **结果展示**:
   
   **问询到摆烂D**:
   ```
   😴 #X 号鱼是一条普通的摆烂D，什么也没发生
   ```
   
   **问询到侦探D**:
   ```
   ✨ #X 号是 🔍侦探D！
   🎯 侦探告诉你：#Y 号是坏鱼！（真实信息）
   ```
   
   **问询到邪恶D**:
   ```
   ⚠️ #X 号是 [伪装角色]...
   
   如果伪装成摆烂D:
   😴 #X 号是一条普通的摆烂D，什么也没发生
   
   如果伪装成侦探D:
   🗣️ #X 号（伪·侦探）：#Y 号是坏鱼！（假信息！）
   ```

#### ⚖️ 流放模式

1. **激活条件**: 问询次数用完（3次都用掉）
2. **操作方式**: 点击任意未翻开且存活的鱼
3. **后果**:
   - 被流放的鱼直接淘汰（死亡）
   - 真实身份揭晓给所有玩家
   - 无法撤销！

#### 🌙 夜晚阶段

1. **触发时机**: 白天结束后（无论是否进行了流放）
2. **执行者**: 所有存活的坏鱼（邪恶D）
3. **目标选择**: 从存活的好鱼中随机选择1只
4. **结果公布**: 第二天白天开始时公布

**特殊情况**:
- 如果没有存活的坏鱼 → 夜晚平安无事
- 如果没有存活的好鱼 → 坏鱼胜利（游戏结束）

## 🏆 胜负判定

### ✅ 豪鱼胜利条件

满足以下任一条件：
1. **所有坏鱼都被淘汰**（通过流放或...其他方式）
2. 游戏结束时，存活的好鱼数量 > 0 且无坏鱼存活

**胜利提示**: "豪鱼胜利，你是豪人！"

### ❌ 坏鱼胜利条件

满足以下任一条件：
1. **存活的好鱼数量 < 存活的坏鱼数量**
2. **所有好鱼都被消灭**

**失败提示**: "坏鱼胜利，你是坏人！"

## 💡 游戏策略建议

### 新手入门策略

#### 🎯 第一阶段：收集信息（前2-3次问询）

1. **优先问询中间位置的鱼**
   - 避免一开始就问询边缘位置
   - 保持一定的随机性，不让坏鱼猜到你的策略

2. **记录每条线索**
   - 侦探提供的线索是**真实的**，要重点标记
   - 伪侦探提供的信息要**反向思考**
   - 注意：如果两条线索指向同一条鱼，那它很可能是好鱼（坏鱼不会互相指认）

3. **观察模式**
   - 如果连续问出多个"摆烂D"，说明运气不太好
   - 如果很快遇到"侦探"，好好利用这个信息

#### ⚖️ 第二阶段：做出判断（第3次问询后）

1. **综合分析所有线索**
   - 列出所有已知的坏鱼候选
   - 排除明显的好鱼（被侦探指认的，如果只有一个侦探的话）

2. **选择流放对象**
   - 选择嫌疑最大的鱼
   - 不要随意流放，每次流放都很关键

#### 🔄 进阶技巧

1. **概率思维**
   - 10条鱼中有3条坏鱼，问询到坏鱼的概率是30%
   - 连续3次都问不到坏鱼的概率约34%，所以不要灰心

2. **反伪装识别**
   - 如果某条鱼自称侦探并指认了另一条鱼
   - 但后来发现被指认的鱼其实是好鱼
   - 那么这条"侦探"很可能是伪装的坏鱼！

3. **夜晚生存法则**
   - 如果侦探已经暴露身份，他很可能成为夜晚的目标
   - 保护已知的侦探（虽然你无法直接保护）

## 🔧 技术实现细节

### 核心数据结构

```javascript
gameState = {
  phase: 'setup' | 'day' | 'night' | 'exile' | 'gameOver',
  day: number,                          // 当前天数
  inquiriesLeft: number,                 // 剩余问询次数
  fishes: Array<{
    id: number,
    role: 'slacker' | 'detective' | 'evil',
    revealed: boolean,                  // 是否已被翻开
    alive: boolean,                     // 是否存活
    disguisedAs: string | null           // 伪装的角色（仅坏鱼使用）
  }>,
  totalFish: number,
  badFishCount: number,
  goodFishCount: number,
  mode: 'inquiry' | 'exile',           // 当前操作模式
  logs: Array<{message, type, time}>,  // 游戏日志
  gameHistory: Array                   // 游戏历史记录
};
```

### 关键算法

#### 1️⃣ 角色分配算法

```javascript
function allocateRoles(totalFish) {
  let badCount = calculateBadFish(totalFish);
  let goodCount = totalFish - badCount;
  let detectiveCount = Math.max(1, Math.floor(goodCount * 0.25));
  let slackerCount = totalFish - badCount - detectiveCount;
  
  const roles = [
    ...Array(badCount).fill('evil'),
    ...Array(detectiveCount).fill('detective'),
    ...Array(slackerCount).fill('slacker')
  ];
  
  return shuffleArray(roles); // Fisher-Yates 洗牌算法
}
```

#### 2️⃣ 坏鱼伪装算法

```javascript
function evilDisguise(fish) {
  const disguiseOptions = ['slacker', 'detective'];
  fish.disguisedAs = disguiseOptions[
    Math.floor(Math.random() * disguiseOptions.length)
  ];
  
  if (fish.disguisedAs === 'detective') {
    // 70%概率给出假信息，30%概率不给出信息
    if (Math.random() < 0.7) {
      const fakeTarget = selectRandomGoodFish();
      return `#${fakeTarget.id + 1} 号是坏鱼！`;
    }
  }
}
```

#### 3️⃣ 胜负检测算法

```javascript
function checkGameEnd() {
  const aliveGood = fishes.filter(f => f.alive && f.role !== 'evil').length;
  const aliveBad = fishes.filter(f => f.alive && f.role === 'evil').length;
  
  if (aliveBad === 0) {
    endGame(true);  // 豪鱼胜利
    return true;
  }
  
  if (aliveGood < aliveBad || aliveGood === 0) {
    endGame(false); // 坏鱼胜利
    return true;
  }
  
  return false;  // 游戏继续
}
```
