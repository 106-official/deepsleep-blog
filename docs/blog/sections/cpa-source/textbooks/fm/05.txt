一、投资项目现金流量的构成
在估算投资项目现金流量时, 因该项目而产生的税后增量现金流量是相关现金流量。

一般来讲, 项目现金流量同分为三部分
( 1) 项目建设期现金流量
( 2) 项目经营期现金流量
( 3) 项目寿的期末现金确量
( 一) 项目建设期现金流量
项目建设期现金流量主要涉及购买资产和使之正常运行所必需的直接现金流出, 包
括设备购置及安装支出、垫支营运资本等非费用性支出。另外, 建设期现金流量还可能
包括机会成举。
( 三) 项目经营期现金流量
项目经营期现金流量主要包括新项目实施所带来的税后增量现金流人和流出。行收
管理人员及辅助生产部门等费用, 如果不受新项目实施的影响, 可不计人; 若有天, 则
必须计人项目经营期的现金流出。但项目以债务方式筹资带来的利息支付和本金偿还以
及以股权方式筹资带来的现金股利支付等, 均不包括在内, 因为折现率中已经包含了该
项目的寿资成本。
( 三) 项目着能期来现金流量
项目寿命期末现金流量主要是与项目终止有关的现金流量, 如设备变现税后净现金
流入、收回营运资本现金流人等。另外, 可能还会涉及弁置文务等境量流出
二、投资项自现金流量的估计方法
估计投资方案所需的净经营性长期资产总投资, 以及该方案每年能产生的经管现金
净流量, 会涉及很多变量, 并且需要企业多个部门的参与。例如, 销售部门负资预测管
价和销量, 涉及产品价格弹性、广告效果、竞争者动向等; 产品开发和技术部门负责信
计投资方案的净经营性长期资产总投资, 涉及研制费用、设备购置、】房建筑等; 生广
和成本部门负责估计制造成本, 涉及原材料采购价格、生产工艺安排、产品成本等; 贬
务部门负责为销售、生产等部门的预测建立共同的基本假设条件, 如物价水平、折现举
可供资源的限制条件等, 并协调参与预测工作的各部门人员, 便之能相互衔孩与配谷
防止预测者因个人偏好或部门利益而高估或低估收人和成本。
在确定投资方案相关的现金流量时, 应遵循的最基本的原则是; 只有增量现金流
才是与项目相关的现金流量。所谓增量现金流量, 是指接受或拒绝某个投资方案后, 企
业总现金流量因此发生的变动。只有那些由于采纳某个项目引起的现金支出增加额,
是该项目的现金流出; 只有那些由于采纳某个项目引起的现金流人增加额, 才是该项目
的现金流人。

个向题

例, 某公司打算就建一个年间, 开请一家答间机构进行可行性分析, 支付答询费
方元。在进行投登分析时, 这笔答词费是古是相关成本呢?答案应写是香定的。该笔支
出已经发生, 不公司是否案纳新建一个车间的方案, 它部已无法收回, 与公司未来部
冠玩金量无关。
如果将非相关成本纳人投贷方案的总成本, 则一个有利的方案可能因此变为不利的
方案, 一个较好的方案可能因此变为较差的方案, 从而造成决策错误。
2. 不要总视机会成本
在投贷方案的选择中, 如果选择了一个投资方案, 则必须放弃投资于其他方案的机
会。其他投资机会可能取得的收益是实行奉方案的一种代价, 被称为这项投资方案的材
会成本。
例如, 上述新建车间的投资方案, 需要使用公司拥有的一块土地。在进行投资分析
时, 因为公司不必动用资金去购置或租用土地, 可否不将此土地的成本考虑在内呢?答
案因情况前异。因为该公司若不利用这块土地来兴建车间, 则它问将这块土地出售或出
租, 并取得一定的收入。只是由于在这块土地上兴建车间才放弃了这笔收人, 而这笔收
人代表兴建车间使用土地的机会成本。计算投资方案占用公司自有土地的机会成本, 核
心在于量化公司因将土地用于该项日而放释的最大潜在收益。机会成本并非实际支出。
面是隐性成本, 需基子答代方案的最佳用还价倾计算。如果土地附置、无其他任何收苍
途径, 机会成本为, 但着存在其他收益途径( 如出程、出售或用于其他项目) , 机会成
本即为这些途径中接现行市价计算的收益最高的价值
机会成本不是我们通常意义上的“ 成本” , 它不是一种支出或费用, 而是失去的收
益。机会成车总是针对具体方案的, 离开被放弃的方案就无从计量。
3. 要考虑投资方案对公司其他项目的影同
马我] 系的一个新的员日后, 该项白可能对公司的其他项自造成有利或不和的
影啊。

第四节投资项目折现率的估计
任何投资项目都有凤险或不确定性。针对投资项目的风险, 可以通过调整折现率
资本成本进行衡量, 再计算净现值。
一、使用企亚鲁前加权平均资本成本作为投资项自的资本成本
便用企业当制的资本成本作为项目的资本成本, 应具备两个条件: 一是项目的经营
风应与企业当前资严的平均经营风盛相同; 二是公可强续米用相间的贷本结构为新项巨
筹贷。
( 一) 项目经营风险与企业当前资产的平均经营风险相间
用当前的资本成本作为折现率, 隐答了一个重要假设, 即新项目是企业现有资产的
复制品, 它们的经营风险相同。这种情况是经常会出现的, 例如, 固是资产史新、现有
生产规误的张等。
如果新项目与现有项目的经营风险有较大差别, 就必须小心从事。例如, 北京首单
公司是从事传统行业的企业, 其经营风险较小, 最近进入了信息产业。在评价其信息产
业项日时, 便用公司目前的资本成本作折现单就不合适了, 因为新项目的经营风验和其

有资产的平均经营风险有显者差别。
( 二) 继续果用相间的资本结构为新项自筹资
所谓企业的加权平均资本成本, 通常是根据当前的数据计算的, 包含了资本结构因
素。有关企业当前资本成本的计算我们已经在第四章贷本成本中讨论过。
如果假设市场是完善的, 资本结构不改变企业的平均资本成本, 则平均资本成本反
映了当前贷产的平均经营风险。
如果承认资本市场是不完善的, 资本结构就会改变企业的平均资本成本。例如, 当
前的资本结构是债务古40备, 而新填自的资本结构是倾劳古70%。田于贝债比里上并

同的作用, 使得企业平均资本成本发生变动。因此, 继续使用当前的平均资本成本作为
折现率就不合适了。
息之, 在等经营风险限设成险本结构不变设设明显不能成立的, 不能使用企艺当

第力节投份角目的领感分材
敏感分析是投资项目评价中常用的一种研究不确定性的方法。它在确定性分析的基
础上, 分析不确定性因素对投资项目最终经济效益指标的影响及其程度。一般可选择主

要参数( 如销售收入、经营成本、生产能力、初始投贤、寿命期、建设期、达产期等
进行敏分析。
一、敏感分析的作用
( 1) 确定影响项自经济效益的数感因素。我出最敏感的主要变量内素。进一步分析
预测或估算其影响程度, 找出产生不确定性的根源, 采取相应有效措施。
( 2) 计算主要变量因素的变化引起项目经济效益指标变动的骗度, 便决策者全画了
解项目投资可能出现的经济效益情况, 以减少和避免不利因素的影响, 改善和提高项
的投资效果。
( 3) 通过各种方案敏感度大小的对比, 区别敏感度大或敏感度小的方案, 选种敏感
度小的( 即风险小的) 方案作为投资方案。
( 4) 通过对可能出现的最有利与最不利的经济效益变动范用的分析, 为决策者预进
可能出现的风险程度, 并对原方案采取某些控制指施或寻找可替代方案, 为最后偏定
行的投资方案提供可靠的决策依摇。
二、杂器分析的方法
投资项目的敏感分析, 通常是在假定其德变量不变的情况下, 测定某一个变量发生
转定变化对净玩值( 或内含报前率) 的影响
( 一) 最大最小法
最大最小法的王要步骤是
( 1) 预测每个变量的预期值。计算净现值时需要使用预期的初始投资、营业现金汤
入、营业现金流出等变量。
( 2) 根据变量的预期值计算净现值, 由此得出的净现值称为基准净现但。
( 3) 选择一个变量并段设其他变量不变, 令净现值等于0, 计算选是变量的临界值。
如此往复, 试每个变量的临界倾。
通过上述步集, 可以得出使项目净现值由正值变为0的各变量最大( 或最小) 值
以括助决策者认识项目的特有风险。
