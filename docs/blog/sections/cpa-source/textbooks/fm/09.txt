一、长期债务筹资的特点
债务筹资是指通过负债等集资金。负债是企业一项重要的资金来源, 几乎没有一家
企业是只是自有资本, 而不运用负微就能满足资金需要的。债务筹资是与音通成筹筑在
质不同的筹贷方式。与后者相比, 债务筹资的特点表现为; 筹集的资金具有使用上的时
间性, 需到期楼还; 不论企业经营好环。需固定支付债务和息。从面形成企业店定的
担; 其资本成本一般比普通股筹资资本成本低, 且不会分改投资者对企业的控割权
长期边债是指期限避过1年的负债。长弗负馈的优点是; 同以解决企业长期资金的不
足, 如满足发展长期性固定贫产的需要: 由于长期负债的归还期长, 债务人可对债务的
归还作长期安排, 还债水力或风险相对较小。长期块馈的缺点是: 长期筑做寿筑一般资
本成本较高, 即长期负债的利率一般会高于短期负债利率; 负债的限制较多, 即债权人
经常会向债务人提出一感限制性的条件以保证其能够及时、足额偿还债务本金和文付系
息, 从而形成对债务人的种种约束。
目前在我回, 长债务筹瓷主要有长期借款和长期债券两种方式

( 二) 长期借款的条件
金融机构对企业爱改登款的原则是: 按计切发放、择优扶相、有物贷保证、按归

( 1) 独立核算、自负盈亏、有法人资格。
( 2) 经信方间和业劳范由符合国象产业数策, 借款用途属于银行贷款办法规定的
范由。
( 3) 信款企业具有一定的物资和财产保证, 担保单位具有相应的经济实力。
( 4) 具有偿还贷款的能方,
( 5) 财务管理和经济核算制度健金, 资金使用效益及企业经济效益良好,
( 6) 在银行设有账户, 可供办理结算。
具备上还条件的企业欲取得贷款, 先要向银行提出申请, 陈述借款原因与金额、用
款时间与计划、还款期限与计划。银行根据企业的借款申请, 针对企业的财务状况、信
用情况、盈利的稳定性、发展前景、借款投资项目的可行性等进行审查。银行审查同意
贷款后, 再与借款企业进一步协商贷款的其体条件, 明确贷款的种类、用途、金额、利
率、期限、还款的资金采浊及方式、保护性条件、违约责任, 等等, 并以借款合同的形
式将其法律化。借款合同生效后, 企业使可取得惜款。
( 三) 长期借款的保护性条款
田了长期信欢的期限长、风虚大, 按照国际便例, 银行迪常对借款金业提出一些
助于保证份款按时足额偿还的条件。将这些条件写进贷款合同中, 就形成了合同的保护
性条款。归纳起来, 保护性条款大致有如下两类
1. 一般性保护条
一般性保护条款应用于大多数借款合同, 但根据具体情况会有不同内容, 主要包括:
( 1) 对借款企业流动资金保持量的规定, 其目的在于保持借款企业资金的流动性和偿位
能力; ( 2) 对支付现金股利和再购人股票的限制, 其目的在于限制现金外流: ( 3) 对净
经营性长期资产总投资规模的限制, 其目的在于减小企业日后不得不变卖同定资产以位
还量款的向能性, 保持信款企业资金的流动性; ( 4) 限制其他长期债务, 其目的在手
止其他贷款人取得对企业资产的优先求偿权; ( 5) 借款企业定期向银行提交财务报表
其日的在于及时掌握企业的财务情况; ( 6) 不准在正常情况下出售较多资产, 以保持企业
正常的生产经营能力; ( 7) 如期缴纳税费和清偿其他到期债务, 以防被罚款而造成现金流
失; ( 8) 不准以任何资产作为其他承诺的担保或抵押, 以盖免企业负相过重; ( 9) 不准
现应收票据或出售应收账款, 以避绝或有负债; ( 10) 限面租告质定资产的和模, 共月东
不仅在于防止企业负担巨额租金以致削弱其偿债能力, 还在于防止金业以租赁固定资产
的办法操脱对其净经营性长用资产总投资和负债的约束。

( 四) 长期信款的成本
长期借款的利息率通常高于短期借款的利息率, 但信誉好或抵神品流动性强的借
企业, 仍然可以争取到较低的长期借款利率。长期借款利率有固定利率和浮动利率两种。
浮动利率通常有最高、最低限, 并在借教合同中明确约定。对于借款企业来研, 若坝淡
市场利率将上升。应与银行签订固定利率合同; 反之, 则应签引浮动利率台问。
除了利息之外, 银行还会向借款企业收取其他费用, 如实行周转信贷协定所收取的
承诺费、要求借款企业在本银行中保持补偿余额所形成的同接费用。这些费用会提高长
期借款的成本。
( 五) 长测情款的会还方式
长期借款的偿还方式不一, 包括: 定期支付利息、到期一次性偿还本金的方式; 效
同短期借款那样的定期等额偿还方式; 平时逐期偿还小额本金和利息、期末偿述剩余的
大额部分的方式。
( 六) 长期借款筹资的优点和缺点
与其他长期负债等资相比, 长期借款筹资的优缺点主要有
1, 长期信款寿贫的优点
( 1) 筹资速度快。发行各种证券筹集长期资金所需时间一般较长, 做好让芽发行的
准备以及发行行证券都需要一定时间。面向金融机构借款与发行证券相比, 一般借款所常
时间较短, 可以迅速地获取资金。
( 2) 借款弹性好。企业与金融机构可以直接接触, 可油过直接商淡来确定借款的的
间、数量、利息、偿付方式等条件。在借款期间, 如果伦业情况发生了变化, 也可与金
融机构进行协商, 修改借款合同。借款到期后, 如有正当理由, 还可建期归还。
2长加借效寿资的缺点
( 1) 限制条款较多。企北与金融机构签订的借款合同中, 一般都有纹多的限制条款
这些条款可能象限制企业的经营活动。
( 2) 筹资金新有限。企业能从金融机构筹集的资金数量比致有限, 一一段难以取得

( 一) 债筹序终
公司公开发行债券通常需要由债券评信机构评定等级。赁券的信用等级对于发行公
司和购买人都有重要影响。这是因为: ( 1) 债券评级是度量违约风险的一个重要指标
债券的等级对于债务筹资的利率以及公司债务资本成本有着直接的影响。一般说来, 策
信等级高的债券, 能够以较低的利学发行: 资信等级低的债券, 风险较大, 只能以较高
的利率发行。另外, 许多机构投资者将投资范制限制在特定等级的债券之内。( 2) 债秀
评级方使投资者进行债券投资决策。对广大投资者尤其是中小投资者来说, 由于受时间
知识和信良的限制, 无法对众多值等进行分析和选择, 因此需要专业机构对券还本付
总的可幕程度进行客观、公止和权威的评定, 为教贷者决束提供参考。.
国际上流行的债券等级是三等九级。AAA级为最高级, AA级为高级, A级为上甲
级, BBB级为中级, BB级为中下级, B级为投机级, CCC级为完全投机级, CC级为最
大投机级, C级为最低级。
根据中国人民银行的有关规定, 凡是向社会公开发行的企业债券, 需要由经中国人
民银行认可的资信评级机构进行评信。这些机构对发行惯芽企业的企业素质、财务质量、
项自状况、项自前景和偿值解力进行评分, 以此评定信用级别。
( 三) 债筹偿迁
1. 债券的偿还时间
债券偿还时间按工实际发生与规定的到两日之间的关系, 分为列期偿还、提前偿还
与端后偿还三类。
( 1) 到期偿还。到期偿还又包括分批偿还和一次偿还两种。如果一个企业在发行同
一种债券的当时苏为不同编号或不同发行对象的倾芬脱定了不同的到期日, 这种质穿感
是分批偿还债芽。因为各批债券的到期日不同, 它们各自的发行价格和票面利率也可能
不相同, 从而导致发行费较高。但由于这种债券使于投资者挑选最合遗的到期日, 因面
使于发行。另外一种就是最为常见的到期一次偿还的债券。
( 2) 提前偿还。提前偿还又称提前赎回或收回, 是指在债寿尚未到期之前就子以忙
还。只有在企业发行债券的契约中明确规定了有关允许提前偿还的条款, 金业才可以进
行此项操作。提前信述所支付的份格进常要高子领芬的画但, 开障接近到期日而经常
下降。具有提前偿还条款的微券可使企业筹资有较大的弹性。声伦业贷金有结余时。
可提前煤回债芽: 当预利率下降时, 也可提前域回债券, 而店以较低的利率来发行
新债贷。
( 3) 滞后偿还。债券在到期日之后偿还叫滞后偿还。这种偿还条款一般在发行时
使订立, 主要是给于持有人以延长持有债发的选择权。滞后偿还有转期和转换两种元
式。转期指将较早到期的债券换成到期日较晚的愤芽, 实际上是将债务的期限延长
常用的办法有两种: 一是直接以新债券免操国债芽: 二是用发行新债券得到的资金来
赎回旧债券。转换通常指股份有限公司发行的惯芽可以疫一定的条件转换成发行公言
的成累。

3. 债穿的付息
债券的付息主要表现在利总率的确定、付息频率和付息方式三个方面。
( 1) 利息率的确定。利息掌的确定有固定利率和浮动利率两种形式。浮动利率一
指由发行人选择一个基雅利率, 按基准利率水平在一定的时间间隔中对债务的利率进行
调整。
( 2) 付总颜率。付总预率感高, 资金流发生的次数越多, 对投贷者的吸引力献大

股权再融资对企业产生的影响主委包括
1, 对公可资本结构的影明
迪常, 权益资本成本高于债务资本成本, 采用股权再融资会降低资产负债率, 并可
能会使资本成本增大; 但如果股权再融资有助于企业目标资本结构的实现, 增强企业的
财务稳健性, 降低债务的进约风险, 就会在一定程度上降低企业的加权平均资本成本,
增加企业的整体价住。
2. 对企业财务状况的影审
在企业运营及盈利状况不变的情况下, 采用股权再融资筹集资金会降低企业的财务
杠秆水平, 并降低净资产报酮率。但企业如果能将股权再融资筹集的资金投资于具有良
好发展丽景的项目, 获得正的投资活动净现值, 或者能够改善企业的资本结构, 降低资
本成本, 就有利子增加企业的价值。

就配股而司, 由于全体股东具有相同的认购权利, 控股股系只要不放弃认购的权利

4. 代理理论
企业中的般东、债权人、经理人员等请多利益相关者的目标并非完全一致, 在追求
目身利益最大化的过程中有可能会以牺牲另一方的利益为代价, 这种利益冲突关系反映
在公可股利分配决策过程中表现为不同形式的代理成本: 反映两类投资者之间利益冲突
的是股东与倾权人之间的代理关系; 反映股权分散情形下内部经现人员与外部投资者之
间利益冲突的是经理人员与股东之间的代理关系; 反映股权集中情形下控制性大股东与
外部中小股东之间利益冲笑的是控股股东与中小股东之间的代理关系。
( 1) 股东与债权人之间的代理冲。企业股东在进行投资与筹资决策时, 有可能关
增加自身的财高而选择了加大债权人风险的政策, 如股东通过发行债务支付股利或为发
放股利而拒绝净现但为正的我资项自。在股东与债权人之间存在代理冲窦时, 债权人为
保护自身利益, 希望企业聚取低股利支付率的股利政策, 通过多图存少分配以保证有较
为充裕的现金留在企业以防发生债务支付困难。因此, 债权人在与企业签订借款合同时,
习惯于定约束性条款对仓业发放股利的水平进行制约。
( 2) 经理人员与股东之间的代理冲突。当企业拥有较多的自由现金流量时, 企业经
理人员有可能把贷金我贷子低回报项自, 或为了取得个人私利而追求额外津贴及在职洋
费等, 因此, 实施高股利支付率的股利政策有利于降低因经理人员与股东之间的代理冲
笑面1发的这种目田现金流量的代理成本。实施多分配少留存的股利数策, 联有利于打
制经理人员随意支配自由现金流量的代理成本, 也有利于满足股东取得股利收益的愿望
( 3) 控股股东与中小股系之间的代理冲突。如果所有权与控制权集中子一个或少数
大段东手中, 企业管理层通常由大股东直接出任或草接指派, 管理层与大股东的利益是
于一致。由于所有权集中使控股股东有可能也有能方通过各种手段侵害中小股东的利益,
控胶股东为取得控制权私利而产生的与中小股东之间的代理冲突使企业股利政策也呈现
出明显的特征。当法律制度较为完善, 对外部投贤著的保护受到量视时, 有效地降低了
大股东的代理成本, 可以促使企业实施较为合理的股利分配政策。反之, 法律制度建设
滞后, 对外部投资者的保护程度较低时, 如果控股股东通过利益侵占取得的控制权私利
机会较多, 会使其忽视基于所有权的正常股利收益分配, 甚至因过多的利益侵古商缺乏
可供分配的现金。因此, 处于对外部技资者保护程度较弱环境中的中小股东希望伞业采

一、股票分割
股慕分割是指将面额较高的股票交换成面额教低的股票的行为。例如, 将原来的一
股股票交换成两股股票。股票分却不属于某种股利方式, 但其所产生的效果与发放股煮
股利近似, 故而在此一并介绍。
胶票分割时, 流通在外的股数增加, 每股面额下降。普通股股数增加会引起每股收
益和每股市价( 依定市盈率不变) 的下降, 但公司价值不变, 股东权着总额以及股东权
益内部各项目相互间的比例也不会改变。这与发放股票股利时的情况既有相同之处, 又
有不同之处。
