弟一节 标准成本及其用定
标准成本法是为了克服实际成本计算系统的缺陷( 尤其是不能提供有助于成本控制
的确切信息的缺陷) , 面研究出来的一种会计信息系统和成本控制系统。
实融标准成本法一般有以下儿个步骤: ( 1) 制定单位产品标准成本; ( 2) 根抓
实际产量和成本标准计算产品的标准成本; ( 3) 汇总计算实际成本; ( 4) 计算标准
成本与实际成本的差异; ( 3) 分析成本差异发生的原因( 如果将标准成本纳人账第
体系, 还要进行标准成本及其成本差异的账务处理) ; ( 6) 向成本负责人提供成本拉
制报告。
一、标准成本的敌总和作用
( 一) 标准成本的极念
标准成本是通过精确的调查、分析与技术测定而制定的, 用来评价实际成本、衡量工作
效率的一种目标成本。在标准成本中, 基本上排除了不应该发生的“ 浪费” , 因此被认为是
一种“ 成该成本” 。标准成本和估计成本同属于预计成本, 但后者不具有衡量工作效率的尺
度性, 王要体现可能性, 供确定产品销售份格使用。
“ 标准成本” 一词在实际工作中有两种含义;
一种是指单位产品的标准成本, 它是根据单位产品的标非清耗量和标准单价计算出
来的, 准确地说应称为“ 成本标准"。可表示为:
成本标准要单位严品标准成本=原位产品标洲消耗量X标准卑们
另一种是指实际产量的标准成本总额, 是根据实际产品产量和单位产品成本标准计
算出米的。可表示为;
标准成本( 总额) =实际严量x单位产品标准成本
( 二) 标准成本的作
标准成本要体现企业的目标和要求, 主要用于衡量产品制造过程的工作效率和控电
成本。也可用于存货和份货成本计价。

二、标准成本的种类
( 一) 理机标准成本和正需标准成本
标准成本按其制定所依据的生产技术和经营管理水平, 分为理想标准成本和正常标
非成本。
理想标准成本是指在最优的生产条件下, 利用现有的规模和设备能够达到的最低成
本。制定理想标准成本的依据, 是理论上的业绩称准、生产要素的理想价格和向能实现
的最高生产经营能力利用水平。所请“ 理论业绩标准” , 是指在生产过程中是无技本很费
时的生产要素消耗量, 最器练的工人全力以处工作、不存在废品损失和停工时间等条件
下可能实现的最优业绩。所谓、“ 最高生产经营能力利用水平” , 是指理论上可能达到的设
备利用程度, 只扣除不可避免的机琴修理、改换品种、调整设备等时间, 面不考虑产品
销路不佳、生产技术故障等造成的影响。这里所说的理想价格, 是指原材料、劳动力等
生产要素在计刻期间最低的价格水平。因此, 这种标准很难成为现实, 即使哲时出现也
不可能持久。它的主要用途是提供一个完关无缺的目标, 揭示实际成本下降的带力。因
其提出的要求太高, 不宜作为考核的依据。
正常标准成本是指在效率良好的条件下, 根据下期一般应该发生的生产妥素消耗址、
计价格和预计生产经营能力利用程度制定出来的标准成本。在制定这样标准成本的, 把生产
经营活动中一般难以灌免的损耗和低效率等情况也计算在内, 使之切合下期的实际情况, 成
为切实可行的控制标准。要达到这种标准不是没有困雄, 但是可能达到的。从具体数量上
看, 它应大于理想标沛成本, 但又小于历史平均水平, 实施以后实际成本更大的可能是逆差
而不是取差, 是要经过务力才能达到的一种标准, 因而司以调动职工的积极性。
在标准成本系统中, 广泛使用正常标准成本。它具有以下特点: 它是用科学方法根
据客观实验和过去实践经充分研究后制定出采的, 具有客观性和科字性; 它蹴排除了谷
种偶然性和意外情况, 又保留了目前条件下难以避免的损尖, 代表止常情况下的消耗求
平, 其有现实性: 它是应该发生的成本, 可以作为评价业绩的尺度, 成为督促职工去务
力争取的目标, 具有激励性; 它可以在工艺技术水平和管理有效性水平变化不大时持强
便用, 不需寒经常修订, 其有稳定性。
( 二) 现行标准成本和基本标准成本
标准成本按其适用期, 分为现行标准成本和基本标准成本。
现行标准成本, 是指根据其适用期间应该发生的价格、效率和生产经营能力利用私
度等预计的标准成本。在这些决定因素变化时, 需要按照政变了的情说加以修可。这
标准成本可以成为评价实际成本的依据, 也可以用来对存货和钥货成本计价。基本标准
成本是指一经制定, 只要生产的基本条件无重大变化, 就不予变动的一种标准成本。所
调生产的基本条件的重大变化是指产品的物理结构变化, 重要原材料和劳动力价格的中
要变化, 生产技术和工艺的根本变化等。一且这些条件发生变化, 就需要修基本称准
成本。由于市场供求变化导致的售价变化和生产经营能力利用程度的变化, 或者由于工
作方法改变而引起的效率变化等, 不属于生产的基本条件变化, 不需要修订基本标准成
本。基本标准成本与各期实际成本对比, 可反映成本变动的趋势。如果基本称准成本不
按各期实际进行动态修订, 就不直用来直接评价工作效率和成本控制的有效性

三、标准成本的定
制定标准成本, 通常首先确定直接材料和点接人工的标准成本, 其次确定制造费片
的称佳成本, 蒙后总辑定甲很严品的际准成系
制定一个成本项目的标准成本, 一般需要分别确定其用量标准和价格标准, 两者相
粮后得出凌成本项目的单位产品标准成本。
用量标准包括单位产品材料消耗量、单位产品直接人工工时等, 主要由生产技术部
有主持制定, 司时吸收执行标准的部可及职工参加。
研格标准包括标准的原材料单价、小时工资率、小时制造费用分配氧等, 由会计部
门和有关其他部门共同研究确定。米鸡部门是材料价格的贵往部, 人方资原部对小
时工资率负有责任, 各生产车间对小时制造费用分配率承担责任, 在制定有关价格标准
时要与有关门协商。
无论是价格标准还是用量标准, 都可以是理想状态下的或正营状卷下的标准, 据止
得出理想的标准成本或正常的标准成本。下面介绍正常标准成本的制定。
( 一) 直接材料标准成本
直接材料的标准消耗量, 一般采用统计方法、工业工程法或其他技术分析方法确定。
它是现有技术条件生产单位产品所需的材料数量, 包括必不可少的消耗以及各种难以进
免的损关。
且接材料的价格标准, 是频计下一年度需要支付的进料单位成本, 包括发票价格
运费、检验和正常报耗等成本, 是取得材料的完全成本。

第一节作业成本法的概意与特点
一、作业成本法的产生背景及其管义
( 二) 作业成本法的产生背景
随着“ 机器取代人” 的自动化制造时代来临, 企业的经营环境正在发生巨大改变
伴随这种改变, 产品或劳务的成本结构亦发生重大改变, 其特征就是直接人工成本比主
大大下降, 制造费用( 主要是折旧费用等固定成本) 比重大大增加, 因此, 制造费用分
配的科学性将很大程度上决定产品成本计算的准确性和成本控制的有效性。
传统的成本计算方法通常是完全成本法, 全部益费用来用单一的分配标准( 例如
产量、人工工时、机器工时等) 分配俗不同的产品。其存在两个重要路
一个缺陷是将商定制盖费用分准给不同种类的严品。接照这种做法, 随着产量的培
加, 单位产品分摊的固定制造费用下降, 即使单位变动成本不变, 平均成本也会随产
增加而下降。在销售收入不变的情况下, 增加生产量可以使都分固定制造费用被存货
收, 减少当期钥情成奉, 增加当期利润, 从而剥激经理人员过度生产。变动成本法是针
对这个缺点提出来的。
另一个缺陷是产生误导决策的成本信息。在传统的成本计算方法下, 制盖费用通常
技直接人工工时或产量等以产量为基础的分配标准进行分配。实际上, 有许多制造费用
项目不是产量的函数, 而与生产批次等其他变量存在因果关系。按烈产量基础分配标准
分配全部制造费用, 会产生扭曲的成本信息, 误导决策。作业成本法是针对后一个缺陷
提出来的。
( 二) 作业成本法的含文
作业成本法是将间接成本和辅助器用更准确抛分配到产品和爱务中的一种成本计算
方法。依据作业成本法的观念, 企业的全部经营活动是由一系列相互关联的作业组成的
企业每进行一项作业都要耗用一定的资源; 与此同时, 产品( 包括提供的服劳) 破一
列的作业生产出来。产品成本是全部作业所消耗资源的总和, 产品是将耗全部作业的成
集。在计管产品成本时, 首先接经营活动中发生的各项作业来归集成本, 计算出作2成

二、作业成本法的被心概总
作业成本法的核心概念是资源、作业和成本动因
( - ) 资游
资源是指作业耗费的人工、能源和实物资产( 例如车床和广房) 等。任何一项产品
的形成都经由一系列作业完成, 完成每一项作业都需要消耗资源。例如生产一部手机,
需要消耗的贷源有人工资源、芯片、触摸显示屏以及其他各种电子组件、电力资源、流
水线机器等, 工人利用流水线等工艺流程完成加工、组装、检验、包装等作业, 最终生
产出手机产品。
( 二) 作业
作业是指企业中特定组数( 成本中心、部门或产品线) 重复执行的任务或活动。例
如, 签订材料来购合同、将材料运达仓库、对材料进行质量检验、办理人库手续、登记
材料明细账等。每一项作业, 是针对加工或服务对象重复执行特定的或标准化的活动。
例如, 细承工) 的牛工作业, 无论加工何种规格型号的轴承外套, 都须经过将加工对高
( 工件) 的毛坯固定在车床的卡盘上, 开动机器进行切削, 然后将加工完毕的工件从卡盘
上取下等相向的特定动作和程序。
一项作业可能是一项非常具体的活动, 如车工作业; 也可能泛指一类活动, 如机加
工牛间的牛、铣、创、磨等所有作业可以统称为机加工作业; 甚至可以将机加工作业
产品组装作北等统称为生产作业( 相对于产品研发、设计、销售等作业面言) 。由若十个
相互关联的具体作业组成的作业集合, 被称为作业中心。
执行或完成任何一项作业都需要耗费一定的资源。完成一项作业所消耗的资源的成
本构成该作业的成本。资源成本可以直接追湖至特定的作业时, 该资源成本为作业的育
接计人成本; 资源成本需要分配计人不同作业成本时, 该资源成本为作业的间接计入
成本。

设备的折旧费等咸本, 一般可以言接归属于检验作业; 而能海成本往往不能百接计入
需爱根据设备额定功率( 或根据历史资料统计的每小时平均耗电数量) 和设备开动时间
来分配。这里, “ 设备的额定功率乘以开动时间” 就是能激成本的动因。设备升动导致能
源成本发生, 设备的功率乘以开动时间的数值( 即动因数量) 越大, 耗用的能源越多
接“ 设备的额定功率乘以开动时间” 这一动因作为能源成本的分配基础, 可以将检验专
用设备耗用的能源成本分配到检爱作业当中。
2. 作业成本动法
作业成本动因是衡量一个成本对象( 产晶、服务或顾客) 需要的作业量, 是产品成
本增加的动因素。作业成本动因计量各成本对象耗用作业的情况, 并被用来作为作
成车的分配基础。例如, 每批产品完工后都需进行质量检验, 如果对任何严品的每一批
次进行质量检验所发生的成本相同, 则检验的“ 次数” 就是检验作业的成本动因, 它是
产品检验成本增加的驱动因素。某一会计期间发生的检验作业总成本( 包括检验人工成
本、设备折旧、能源成本等) 除以检验的次数, 即为每次检验所发生的成本。某种产点
应承担的检验作业成本, 等于该种产品的批次乘以每次检验发生的成本。产品完成的批
次越多, 则需要进行检验的次数越多, 应承担的检验作业成本越多; 反之, 则应承担的
检验作业成本移少。
三、作业成本法的特点
作业成本法的主要特点, 是相对于以产量为基础的传统成本计算方法而言的。
( 一) 成本计算分为两个阶段

第一阶段, 将作业执行中耗费的资源分配( 包括追湖和间接分配) 到作业, 计算作
