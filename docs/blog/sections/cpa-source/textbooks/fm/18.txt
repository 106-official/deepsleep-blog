三、全面预算的编制程序
全面预算的编制, 涉及企业经营管理的各个部门, 只有执行人参与预算的编制, 才
笔使算成为他] 自器务力完成的自标, 面不是外算独加于他的银
全面预算的编市程字如下
( 1) 企业决策机构根据长期规划, 利用本量利分析等工具, 提出企业一定时期的忘
目际, 并下达现切指标
( 2) 教基层成本经而人员自行导编算, 使算北收为问都、为付合头哪
( 3) 各部门汇总部门预算, 并初步协调本部门摸算, 瓣制出销售、生产、财旁等
预算;
( 4) 预算委员会中登、平衡各预算, 孔尽出公同的冠员算
( 5) 经过总经理批准, 审议机构迪过或者数回修改员算
( 6) 主要预算指标报告给量事会或上级主管单位, 讨论通过或者驳回修改
( 7) 批准后的预鼻下达给各部1状行。

( 一) 培量我算法
墙量预算法又称商整预算法, 是指以历史期实际经济活动及其预算为基荷, 结合我
算期经挤活动及相关影响因素的变动情况, 通过调繁历史期经济活动项自及金额形成预
算的预牌解方法。
增量预算法的前提条件是: ( 1) 现有的业务活动是企业所必的: ( 2) 原有的各功
业务都是合挥的
增量预算法的缺点是当预算期的情况发生变化时, 预算数额会受到基期不合理因素
的十扰, 可能导致预算的不准确, 不利于调动各部门达成预算目标的积极性。
( 二) 等基预算法
等基预算法, 是指企业不以历史期经济活动及其预算为基础, 以零为起点, 从实防
需要出发分析预算期经济活动的合理性, 经综合平衡, 形成预算的预算编制方法。采用
基负算法在编制费用预算时, 不考虑以往期同的爱用项自和费用数额, 主要根据预
期的需要和可能分析费用项自和费用数额的合理性, 综合平衡编制费用预算。运用零基
预鼻法解制费用算的具体步骤是
( 1) 极据企业预算期利润目标、销售目标和生产指标等, 分析预算期各项费用项目。
并损润费用水平
( 2) 拟订项算期各项费用的预算方案, 权衡轻重缓意, 划分费用支出的等级并排列
先后限序
( 3) 根据企北预算期预算费用控制总额目标, 按照费用支出等级及原序, 分解落实
相应的费用控制目标, 编能相应的费用预算,
是用冬基算法编费用算的优点是不受面费用期自帮用水学的药, 象
活动各部门降低费用的积极性, 但其缺点是得制工作量大
冬基预算法适用于企业各项预算的编制, 特别是不经常发生的预算项自或预算编氧
基础变化较大的预算项自。
二、肉定执鼻法与弹性预算法
按业务量基础的数量特征的不同, 营业预算的编制方法可分为固定预算法和弹性预
算法两大类。
( 一) 同定预算法
因定预算法又称静态预算法, 是指在编制预算时, 只以预算期内正常、可实现的某
一固定的业务量( 如生产量、销管量等) 水平为唯一基础来编制预算的方法。固定预算
方法仔在适应性差和可比性差的缺点, 一般适用于经营业务稳定, 产品产销量稳定, 能
准确预测产品需求及产品成本的金业, 也可用于编制固定费用预算。
( 二) 弹任预算法
弹性预算法又称动态预算法, 是在成本性态分析的基础上, 依据业务量、成本和利
润之间的联动关系, 按照项算期内相关的业务量( 如生产量、销售量、工时等) 水平计
算其相应预算项自所消耗贷源的执算编制方法
理论上, 该方法适用于编制全面预算中所有与业务量有关的预算, 但实务中主要用

算成本; 混合成本中的阶梯成本和曲线成本, 可接总成本性益模型计算填列。不必用
学方法修正为近似的直线成本。但是, 运用列表法编制预算, 在评价和考核实际成本时
往往需要使用内插法来计算“ 实际业务量的预算成本” , 比较麻烦
( 三) 弹性族算差并
弹性预算差异, 是指固定预算数额和实际数额之间的差异, 可分解为作业量差异及
收入和支出差异这两类若异。理性风算差异不仪矿行了实亦2分生水子和面定观界业
量水平不同导致的差异, 也分析了实际业务量水平下实际收人和支出与应实现收人和文
出的差异。

三、定期预算法与滚动预算法
按预算期的时间特征不同, 营业预算的编制方法可分为定期预算法和滚动预算法两类
( 一) 定期表算法
定期预算法是以固定不变的会计期间( 如年度、季度、月份) 作为预算期间编制孩
算的方法。采用定期预算法编制预算, 保证了预算期间与会计期间在时期上配比, 便于
依据会计报告的数据与预算的比较, 考核和评价预算的执行结果。但不利于前后各个期
间的预算衔接, 不能适应连续不断的业务活动过程的预算管理

第一节企业组织结构与责任中心划分
一、企的集权与分核
集权和分权是企业经营管理权限的分配方式。集权是把企业经营管理权较多集中在
企业上层的一种组织形式, 分权是把企业的经营管理权适当地分散在企业中下层的一科
经织形式。
集权和分权虽然可以看作两种不同的组织结构形式, 但实际上是上级与下级在权力
分配上的比重和协满问题。采取分权的企业有一些决策也是交给上级主管作田的, 特易
是面对一些不经常发生的和关于企业整体发展的问题时。采取集权的企业也并不表示不
让下级参与块策制定。实际上, 在集权下, 下级在某些事务上也拥有一定的灵活性
集权的主要优点是使于提高决策效率, 对市场作出迅速反应, 容易实现自标的一至
性, 可以避免重复和资源浪费; 缺点是容易形成对高层管理者的个人崇拜, 形成独裁
导致将来企业高管更替困难, 影响企业长远发展。分权的优点是可以让高层管理者将主
要稿力集中子重要事务, 权力下放, 可以充分发挥下属的积极性和主动性, 增加下属的
工作满足题, 便于发现和培养人才, 下属拥有一定的决策权, 可以减少不必要的上下沟
通, 并可以对下属权限内的事情迅速作出反应; 缺点是可能产生与企业整体目标不一致
的委托代理同题。
二、料层组结格
科层组织结构中, 存在两类管理机构, 一类是直线指挥机构, 如总部、分部、车间、
工段和班组等; 一类是参保职能机构, 如研究开发部、人方赞源部、财务部、营销部及
售后服务部等。与此相对应, 存在两类管理人员, 一类是直线人员, 如总经理、分部经
理、牛间主任、工段长和班组长等; 一类是参谋人员, 如人力资源部部长、财务部部长
营销部部长等。前者是主体, 后者是辆助, 企业生产经营的决策权力主要集中在最高层
的且线导手中。
在这类组织结构中, 企业的生产经营活动主要由直线人员统一领导和指挥, 他们有
权在自己的职责范圈内间下级发布命令和指示, 并负全面的领导责住。职能部门则设
在直线领导之下, 分别从事专业管理, 是各级直线领导的参谋部。职能部门所拟定的计
划、方案以及有关指不等, 均应由直线领导批准后下达执行, 职能部门对下级领导者和
下属职能部门无权直接下达命令或进行指挥, 只能起到提供建议、客询以及进行业务指
导的作用。
科层组织结构的优点是, 各个飘能部门自标明确, 部门主管容易控制和规划。此外,
同类专业的员工一起共事, 易子相互学习, 提高技能。此外, 内部贷源较为集中, 由同

三、事业部制组织结构
事业部制是一种分权的组织结构。在这种组织结构中, 它把分权管理与独立核算结
合在一起, 在总公司统一氨导下, 按照产品、地区或者市场( 客户) 来划分经营单位
( 即事业部) 。各个事业部实行相对独立的经营和核算, 具有从生产到销售的全部职能
它是在总公司控制下的利润中心, 总公司以各事业部为单位制定利润预算。同时, 各个
事业部又是产品责任单位和市场责任单位, 有自己的产品和孩立的巾杨。事业部制的管
理原则可以概括为三个; 集中决策、分敲经普、协调控。
事业部可以按照产品、地区或者客户等内容划分。按照产品划分事业部是最为常
的形式。例如, 广东美的集团股份有限公可就接照产品切分为家用空调、厨房电器、洗
衣机、冰箱、中央空词、生活电器、热水器、环境电器、部品九大事业部, 具中部品手
业部主要包括压缩机和微型电机两大产品。国外通用汽车公司、福特汽车公司、日本松
下电器公司等, 也都是按照产品类别来划分事业部的。银行等一般孩照客户来则分事业
部。而按照地区来划分事业部则是在产品销售区域很广、工广很分散的情况下来取的一
种组织形式
事业部制的主要特点是: ( 1) 在总公司之下, 企业按照产品类别、地区类别或者
客类别设置生产经营事业部; ( 2) 每个事业部设置各自的执行总经理, 每位执行总经理
都有权进行采购、生产和销售, 对其事业部的生产经营, 包括收人、成本和利润的实域
负全部责任; ( 3) 总公司在重大问题上集中决策, 各个事业部独立经营、独立被算、目
负盈亏, 是一个利润中心; ( 4) 各个事业部的益亏直接影响总公司的盈亏, 总公司的利
润是各个事业部利润之和, 总公司对各个事业部下达利润指标, 各个事业部必须保证头
现总公可下达的利海指称。
