# CardArena 苏丹宫廷风卡牌设计（黑金暗夜 × 八角星徽）

- 日期：2026-08-02
- 状态：已获用户确认，进入实现
- 目标：为 CardArena 卡牌设计一套《苏丹的游戏》风格的巴洛克宫廷视觉体系，随博客明暗主题自动切换

## 背景

CardArena 是博客娱乐中心的卡牌对战游戏（`/play/cardarena/`）。此前界面已统一为苏丹宫廷风（深红 × 鎏金 × 阿拉伯纹样），但卡牌仍是简单的方框样式。本设计将卡牌升级为《苏丹的游戏》原作风格的华丽卡面。

《苏丹的游戏》卡牌视觉语言：
- 四品级（黄金 / 白银 / 青铜 / 岩石），品级决定卡面底色与描边
- 巴洛克手绘 + 西域宫廷风情
- 深红 × 鎏金主色调，阿拉伯几何纹样
- 卡牌包含「类型（要做什么）」与「品级（对象等级）」两个要素

## 设计定稿（v3，已确认）

### 总体结构（自上而下）

```
┌──────────────────────────┐
│ ◆ 四角卷草纹角饰（L形金线）   │
│    品级缎带（居中小字）      │  ← 黄金/白银/青铜/岩石
│  ◆     费用宝石（圆形）    ◆ │  ← 左上角圆形径向高光宝石
│      ┌──────────────┐      │
│      │  八角星徽    │      │  ← 中央阿拉伯八角星（双方形叠加+中心圆+四向小圆）
│      │  (随从/法术)  │      │
│      └──────────────┘      │
│     卡名（居中大字）         │
│     描述（居中多行小字）     │
│   ── 金线分隔 ──            │
│    攻 / 血（随从卡大号）     │  ← 法术卡无此行
└──────────────────────────┘
```

### 视觉要素

1. **卡面底色**（随主题切换）
   - 深色主题「黑金暗夜」：`linear-gradient(160deg, #0d0806, #1d100c 48%, #0a0504)`，鎏金描边 `#d4af37`
   - 浅色主题「浅金羊皮纸」：`linear-gradient(165deg, #fdf6e3, #f0e2bd 55%, #e8d5a6)`，深金描边 `#a3863f`

2. **品级缎带**：卡顶居中小字，`letter-spacing: .42em` 宽字距，下方 1px 渐隐金线。品级决定整卡描边色与数值光色：
   - 黄金：`#e8c64a` / 数值 `#f6e7ae`
   - 白银：`#dfe2e8` / 数值 `#e4e6ec`
   - 青铜：`#d9a86e` / 数值 `#dbb486`
   - 岩石：`#a8a39d` / 数值 `#b3aea8`

3. **费用宝石**：左上角圆形（`border-radius: 50%`），径向高光渐变 + 外圈光晕 + 投影，内放费用数字。深色版金底深字，浅色版浅金底深字。

4. **四角卷草纹**：四个 L 形金线角饰（`border` 双线裁剪），随品级变色。

5. **中央八角星徽**：阿拉伯几何纹样 SVG（双方形叠加 45° + 中心圆 + 四向小圆 + 中心菱形），随品级变色，作为随从卡与法术卡共用的卡面徽记。

6. **攻血区**：仅随从卡显示，底部金线分隔 + 大号 `1.18rem` 数值 `攻 / 血`，带光晕（深色）或高对比（浅色）。

### 品级映射规则（已有，保留）

- 法术卡按费用：`cost>=4` 金，`cost>=2` 银，否则铜
- 随从卡按战力（attack+health）：`>=8` 金，`>=5` 银，`>=3` 铜，否则石
- 随从卡战场样式沿用同一品级配色（`.ca-minion-tier-*`）

### 主题适配

- 卡牌样式通过 CSS 变量 + `[data-theme="dark"]` 切换，与页面其他区域（`.ca-*`）同步
- 所有纹样 SVG data-URI 中的描边色按主题提供两版（浅色 `#a3863f` 系 / 深色 `#d4af37` 系）

## 迭代记录 v3.1（2026-08-02 极繁主义卡牌升级，已实现）

对角色选卡卡牌按「极繁主义」方向追加设计（主题：苏丹宫廷 × 黑金暗夜；参考：Bicycle Baroque 密镶花饰/金箔/绳编内框）：

1. **去汉字**：中央徽记由角色名首字（守/仲/预…）改为纯几何三层八角星组（外星 86px + 内星 52px 旋转 22.5° + 中心宝石 14px，CSS mask-image 绘制），徽记区零文字
2. **英文化**：8 角色新增 `titleEn` 英文宫衔（ROYAL GUARD 等）置顶缎带；手牌卡品级缎带改 GOLD/SILVER/BRONZE/STONE；背面印版「ON DUTY」
3. **极繁装饰**：conic-gradient 12 段放射光芒暗纹、双层内框、四角双线角花 + 内嵌菱形、顶饰金线 + 中心菱形、数值宝石框（菱形边框 + 虚线内框）、费用宝石放射星芒环
4. **丝滑翻转**：移除 flip-bounce transform 动画（与 transition 冲突致跳帧），翻转仅由 `.ca-role-inner` transition（0.65s cubic-bezier）驱动；闪光层动画保留在 `::after`
5. **对比度修正**：浅色主题缎带改用品级深色（`--ca-tier-color`），修复亮色叠浅金纸仅 1:1 的问题

验证：rAF 帧采样确认翻转单调连续（每帧 8-10°、无跳帧）；明/暗双主题视觉、布局溢出、JS 报错全部通过。

## 迭代记录 v3.2（2026-08-02 极繁深化 v5.13：界面/徽章/随从卡/战斗特效，已实现）

用户追加需求：1) 进一步繁化徽章、界面、背景；2) 对战界面卡牌 UI 同步繁化，攻击伤害特效、角色/随从死亡化灰烬、换人/出战新角色时从角色牌区翻开翻转移动到出战角色区（立体感）；3) 随从卡繁化 + 统一卡牌长方形大小。

### 新增构件（CSS `cardarena.css` 追加至 1698 行）

- **三个 SVG mask 变量**：`--ca-mask-corner`（72×72 四角纹章：双 L 线+弧形卷草+菱形+三珠）/ `--ca-mask-halo`（120×120 八珠光环）/ `--ca-mask-star`（160×160 八角星），全部非十进制编码、background 上色随主题变色
- **舞台外框** `.ca-stage::before/::after`：四角纹章（4 角 mask）+ 边线珠串（repeating-linear-gradient）
- **分区面板** `.ca-roster/.ca-board/.ca-hand/.ca-log::before`：inset 4px 细线内框 + 四角金珠；`.ca-board` 升级（min-height 172px、放射/暗纹背景）
- **徽章光环层**：`.ca-role-halo`(124px)/`.ca-card-halo`(100px)/`.ca-minion-halo`(74px) 旋转八珠光环（`ca-spin` 55s）+ `.ca-*-ring` 双虚线圆环
- **随从卡全新极繁样式** `.ca-minion`：112×150 统一长方形、conic 放射暗纹、品级缎带（英文 GOLD/SILVER…）、八角星徽记区、菱形宝石数值框（`<b>` + 双层菱形）、关键词金线分隔、五层框阴影、hover 上浮
- **出战区繁化**：`.ca-hero::after` 内框+金珠、`.ca-hero-en` 英文宫衔（Playfair + 0.42em 字距 + 左右渐隐金线）、`.ca-hero-star` 八角星水印

### 战斗特效系统（UI 状态快照对比驱动，引擎零改动）

引擎只发 `update` 事件；UI 在 `renderAll` 中对比 `prevState` 快照（存值深拷贝）检测变化：

| 变化 | 特效 |
|---|---|
| hero/minion 掉血 | 红色伤害飘字 + 受击白闪 `.ca-hit` + 金色冲击波 `.ca-fx-impact` + 攻击者前倾 `.ca-lunge`（仅玩家操作，`pendingAction` 提供） |
| health 上升 | 绿色治疗飘字 `.ca-fx-heal` |
| minion 从 board 消失 | 22 粒金棕灰烬 `.ca-ash` 上飘旋转 + 烟尘 `.ca-ash-puff`（位置用 `captureRects` 预捕获的旧 rect） |
| `activeIndex` 变化 | `.ca-ghost` 3D 幽灵卡（WAAPI `element.animate` rotateY 0→180 + 位移）从角色牌区翻飞向出战区，落地 14 粒金尘 `.ca-spark` + `.ca-hero-enter` 下压抬升 |
| 新 minion | `.ca-minion-enter` 翻转立起入场 |

**关键设计**：所有 fixed 特效元素 append 到 `document.body`（不在 `#cardarena-app` 内），AI 回合同一宏任务内多次 `renderAll` 不会清掉播放中的特效；`setTimeout` 定时清理。

## 迭代记录 v3.3（2026-08-02 抽牌翻牌特效，已实现）

用户追加需求：抽牌（获取手牌）时增加「牌从界面右侧翻转到手牌区」的特效。

### 实现

- **快照扩展**：`snapSide` 增加 `hand: side.hand.slice()` 字段（此前快照只有 hero/minions）
- **抽牌检测**：`analyzeFx` 中新增 `gainedCards(oldHand, newHand)`——按卡牌 id 计数值对比计算「净新增」牌数（正确处理重复牌与「打出 1 张 + 抽 2 张」场景），`fx.draw = { side, count }`；换人（`fx.swap`）时跳过避免与幽灵卡重叠
- **幻影牌特效 `playDrawFx`**：最多同时飞 3 张，每张幻影卡 `.ca-draw-ghost`（68×96 双面：正面金边+品级缎带 GOLD+八角星徽 / 背面 ON DUTY 印版）从视口右侧外（纵向错落成扇形）WAAPI 3D 翻转飞入——`perspective(700px) rotateY(120deg→0deg)` 卡背朝外翻至正面，落地前微弹，到达手牌区最后一张位置后淡出 + 5 粒金尘
- **金色拖尾**：`.ca-draw-ghost::after` 水平渐隐光带（150px 金色光线）随牌飞行
- **双主题**：明暗两套卡面/缎带/星徽配色，`[data-theme="dark"]` 覆写

### 触发场景

| 场景 | 特效 |
|---|---|
| 回合开始抽 1 张 | 1 张幻影牌飞入 |
| 预言家被动（每回合多抽 1） | 2 张错落飞入 |
| 打出「抽牌术/占卜」（抽 2） | 2 张错落飞入 |
| 亡语抽牌 | 1 张飞入 |
