游戏规则 v3.3.0

重要：伪装机制 (v2.1.1.2更新)

所有坏鱼阵营角色被翻开时，都会完美伪装：

  • 邪恶D 和 殉道D 都会伪装
  • 只伪装成当前游戏中存在的角色（更智能的伪装）
  • 显示的角色名称与真角色完全相同
  • 触发的效果也与真角色一致
  • 没有任何标记可以区分真假
  • 只有在游戏结束时才会揭示真相

这意味着你看到的任何信息都可能是假的！多问几个人交叉验证！

白天 - 问询机制

  1. 你有 3 次问询机会
  2. 点击任意鱼进行"问询"
  3. 该鱼的身份会被揭示并触发对应效果
  4. 可以随时选择结束问询进入流放阶段
  5. 问询次数用完后可进入流放模式或跳过流放

流放阶段

  1. 在流放模式中选择一只可疑的鱼进行流放
  2. 被流放的鱼会揭示真实身份并淘汰
  3. 也可以选择跳过流放（本轮不淘汰任何鱼）

夜晚阶段

  1. 坏鱼杀死一只豪鱼
  2. 虎鲸额外杀死一条随机的鱼
  3. 第二天公布受害者

胜利条件

豪鱼胜利: 所有坏鱼都被淘汰
失败条件:
• 所有豪鱼都被淘汰（死亡/流放）
• 或：豪鱼 + 中立阵营 ≤ 坏鱼阵营数量

鱼的数量

范围：6-20只鱼，推荐10-15只

SleepTown 完整规则 v3.3.0

角色介绍（十二种角色）

摆烂D（豪鱼阵营）

普通的好鱼，翻开后无事发生。

侦探D（豪鱼阵营）

告诉你一条真实坏鱼的编号。

法官D（豪鱼阵营）

宣判一只非豪鱼的编号。

八卦鱼（豪鱼阵营）

检查相邻号码，有非好鱼回复"有瓜吃！"，没有则"并没有瓜..."

梦游D（豪鱼阵营）NEW

翻开及每次问询后提供3个号码，其中一只是坏鱼或中立！例如："3、5、8号中有一只不是豪鱼！"

验尸官（豪鱼阵营）NEW

翻开后验尸：随机揭示一只已死亡鱼的真实身份，从尸检中还原真相。（若尚无尸体则无收获）

邪恶D（坏鱼阵营）

每晚会杀死一只豪鱼。被翻开时会完美伪装成当前游戏中存在的其他角色。

殉道D（坏鱼阵营）NEW

死亡后（被流放或杀死）会立即杀死一只好鱼作为报复！同样会伪装成存在的角色。

恶作剧D（中立阵营）

翻开后会减少一次问询机会！（v2.1.1.1修改：原为清空所有机会）

法师D（中立阵营）NEW

每晚令一只鱼的特性失效！问询时会告知昨晚影响了谁。

虎鲸（中立阵营）

每夜晚都会随机杀死一条其他的鱼（不分阵营）！

幽灵（中立阵营）NEW

翻开后当夜会额外带走一条随机的鱼（不分阵营），制造混乱。

胜利条件

豪鱼胜利: 所有坏鱼都被淘汰
失败条件:
• 所有豪鱼都被淘汰（死亡/流放）
• 或：豪鱼 + 中立阵营 ≤ 坏鱼阵营数量
