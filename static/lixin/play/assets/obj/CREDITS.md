# assets/obj/ 物件贴图来源

本目录包含 Lixin 地图编辑器 v0.4 新增的物件贴图：树木、花草、装饰等。

这些精灵图使用 AI 图像生成工具按像素艺术风格生成，提示词强调 "64-bit game pixel art"、透明背景、无水印/无文字/无签名。生成后使用 Pillow 进行后处理：

- 自动抠除背景，输出带透明通道的 PNG；
- 擦除右下角可能出现的生成工具水印；
- 按每个物件定义的占地格数（w×h）等比缩放到底部居中的 32×32 网格尺寸。

因此这些素材在项目中可自由使用；如需替换，只需保持文件名与 `OBJ_DEF` 中的 `file` 字段一致，并确保为透明 PNG 即可。
