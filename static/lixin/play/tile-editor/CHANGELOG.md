# Lixin 地图编辑器更新日志

> 编辑器版本独立于 RPG 游戏版本维护。

## v1.0 — 2026-09-01

- 界面重构为 Campus Studio：品牌栏、紧凑工具区、清晰的编辑画布与响应式图层抽屉。
- 地表 / 结构分页选择，地表与物件支持搜索；长素材列表改为单行横向浏览。
- 图层和对象改为折叠分组，支持名称 / 坐标搜索、图层显隐与点击对象定位。
- 新增 40 步撤销 / 重做，覆盖绘制、擦除、结构增删、路灯与地图尺寸操作。
- 新增 JSON 导入 / 导出、游戏预览、保存状态提示与常用键盘快捷键。
- 修复路灯列表显示 `undefined×undefined`，路灯改为只显示坐标与大灯标记。

## v0.9

- **笔刷统一为「拖拽成矩形」**：不再为道路/水域/桥梁/围墙/建筑单独设置矩形按钮，全部收进笔刷的「地表」与「结构」两组。
  - 地表（草/路/水/碎石/各写实地面等）：单击铺一格，按住拖拽 = 整块矩形填充，松开生效，写入逐格地形 `overrides`。
  - 结构（道路/水域/桥梁/围墙/建筑）：拖拽成矩形写入对应结构层；桥梁覆盖水域时可通行、建筑松开后可输入名称；路面细分柏油/水泥/鹅卵石/土路四种。
- 工具栏精简为：🖌 笔刷 / 💡 路灯 / 🌲 物件 / 📍 检视 / 🧽 橡皮擦 五项，操作更顺手。

## v0.6

- 重洗枫树/棕榈树/白桦贴图灰白噪点：`assets/obj/t_maple.png`、`t_palm.png`、`t_birch.png` 经两轮 Pillow 后处理——先抠边框连通的灰背景层，再清除经半透明缝隙连通到外部的灰雾与内部小面积灰白斑点（连通分量面积判定）。白桦白色树皮等大块浅色主体完整保留，树冠缝隙还原为透明、游戏中不再显灰点。
- 柏油路相交与转弯图案衔接（游戏 RPG 渲染侧实现）：`drawPathTile` 的 road 分支改为按每格**四周邻居是否也是路**（`roadGrid` 预构建 + `roadAt`）决定——路缘仅在「外侧不是路」时绘制（交叉口/转弯处自然断开，不再画出路缘"墙"），车道中线仅在直行段绘制、交叉口断开避免硬穿；斑马线按行车方向平行绘制。相交与转弯处路面连续自然衔接。

## v0.5

- 新增「📍 检视」工具：
  - 单击格子弹出气泡，显示该格「第 N 行 / 第 M 列」；
  - 气泡内提供「下侧增加行」「右侧增加列」按钮，点击即在所指格子【之后】插入一行/一列（复用 insertRows/insertCols，下方内容自动平移）；
  - 在该工具下按住拖动 = 平移地图视角，**保留原缩放大小只移动视口**（通过滚动容器实现），不再误绘。
- 修复橡皮擦不能清除路灯的 bug：`findTopStructure` 原本不含 `lamps` 层导致大小路灯无法删除；现新增 `removeLampAt`，橡皮擦优先删所指格的路灯（大灯/小灯均可），再删地形覆盖与最上层结构。
- 去除贴图背景灰白噪点：对 `assets/obj/*.png` 重新后处理——用外框 alpha 判定背景模式，对半透明/不透明灰蒙层按**饱和度**（低饱和灰 = 背景，高饱和彩色 = 主体）做从边缘 flood-fill 抠除，并清空透明区 RGB，避免灰底在游戏中挡住其它贴图。白/浅色主体走「已透明」分支不受影响。

## v0.4

- 修复插入行/列逻辑：改为在指定位置【之后】插入，严格大于该位置的结构/覆盖才整体平移，不再是末端追加。
- 贴图按钮统一中文名：地形、路面、物件全部使用中文显示，不再出现英文 key。
- 新增贴图悬浮预览：鼠标悬停在地形/物件按钮上时弹出 64×64 预览图。
- 新增写实像素风物件贴图系统：
  - 树木占多格（橡树 3×5、松树 2×6、枫树 3×5、柳树 4×5、棕榈 2×6、白桦 2×5），仅树干底部挡路；
  - 花草单格小巧不挡路（郁金香、玫瑰、雏菊、薰衣草、向日葵、三叶草、草丛、蕨类、芦苇、苔藓）；
  - 装饰（岩石、灌木、蘑菇）。
- 物件使用透明 PNG 贴图，经后处理去除背景与水印，游戏中不占满整格、不遮挡背后贴图。
