# Lixin 地图编辑器

> 编辑器版本：**v0.9**（与 RPG 游戏主版本独立维护）

为立信校园 RPG 提供的可视化地图编辑器。前端单页 + 零依赖 Node 后端，保存结果写入 `../map-data.json`，游戏刷新后自动加载。

---

## 快速启动

```bash
cd static/lixin/play/tile-editor
node server.js
```

浏览器打开 http://localhost:8787

---

## 功能一览

| 工具 | 操作 |
|------|------|
| 🖌 笔刷 | **统一矩形填充**：选「地表」后单击铺一格、按住拖拽成矩形松开即整块写入逐格地形（多种写实草地 + 水域 + 道路 + v0.3 写实地表图集 + v0.8 鹅卵石/红砖/木板/沙地/瓷砖/青苔石等单文件地面贴图）；选「结构」后拖拽生成对应矩形区域（道路/水域/桥梁/围墙/建筑），桥梁覆盖水域时可通行、建筑松开后可输入名称 |
| 💡 路灯 | 单击放置路灯，可选大灯 |
| 🌲 物件 | 单击放置树木/花草/装饰/建筑板块；树木占多格（如 3×5、2×6），花草单格小巧，v0.8 新增长椅/喷泉/雕像/街灯/邮筒/花盆/水井/帐篷/遮阳伞/旗帜/草垛/宝箱/小桥/树篱/传送阵与 6 种建筑样式板块，均使用透明写实像素风贴图 |
| 📍 检视 | 单击格子弹出气泡显示其「第 N 行 / 第 M 列」，并提供「下侧增加行」「右侧增加列」按钮（在所指格子之后插入）；按住拖动 = 仅平移地图视角，缩放不变 |
| 🧽 橡皮擦 | 可直接擦除逐格覆盖/物件/**路灯（大灯小灯均可）**，再删除所指最上层结构；点击多格物件任意占地格即可删除整株 |

**视图**：
- 滚轮 / 顶部按钮缩放，支持“适应窗口”。
- 顶部“地图尺寸”可右加列、下加行，或在指定行/列后插入新行列；结构层与逐格覆盖会自动偏移。
- 鼠标悬停在贴图/物件按钮上可预览对应贴图。
- 右侧列表展示各结构层数量，并可逐项删除。

## 数据格式

`POST /api/map` 与 `GET /api/map` 使用同一 JSON 结构：

```json
{
  "cols": 176,
  "rows": 132,
  "paths": [{"x": 10, "y": 20, "w": 5, "h": 2, "type": "concrete"}],
  "lakes": [{"x": 30, "y": 30, "w": 6, "h": 4}],
  "bridges": [{"x": 33, "y": 30, "w": 2, "h": 4}],
  "walls": [{"x": 50, "y": 50, "w": 10, "h": 1}],
  "buildings": [{"x": 60, "y": 60, "w": 4, "h": 3, "type": "building", "name": "图书馆", "emoji": "🏢", "color": "#8a8a92"}],
  "lamps": [{"x": 12, "y": 22, "big": false}],
  "overrides": {
    "120,80": {"t": "grass_spring"},
    "121,80": {"t": "t_oak", "w": 3, "h": 5}
  }
}
```

- `overrides` 中 `t` 为地表类型或物件类型。
- 物件覆盖格可携带 `w` / `h` 表示占地格数；缺省时为 1×1。
- `cols` / `rows` 为空时游戏使用默认尺寸。

## 自定义贴图

编辑器与游戏共用 `assets/tiles/` 目录下的 32×32 像素地表贴图：

- `floors.png`：18 列 × 3 行
- `grassdirt.png`：2 列 × 4 行

如需替换，保持文件名与格数不变，或在游戏和编辑器的 `TEX_ATLAS` 中修改对应帧坐标。
